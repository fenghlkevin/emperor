# 战后恢复与出征核阅修复、完整新局复测

2026-10-21，`develop` 工作区。前次报告的 **T01、T02、T03 均已实现**。没有降低兵装、征兵或训练价格，没有退还阵亡损失，也没有增加开局银粮。玩家核准恢复计划后，系统会优先安排真实的战后恢复支出，避免结余长期被可选建设占用。

本轮最终验证：**142 条新局路线、74,520 旬推进，887 项业务测试、42 组运行时类型契约通过；新增界面 6 组完整工作流与原有 14 项桌面验收通过。**

## 已完成的三项改动

### T01：有额度上限的优先恢复计划

兵部尚书新增“战后恢复”；出征、守城和撤守战报均可进入核阅。新战役开始时记录中央军的真实兵员、兵装、训练基线，战后只对实际缺额提出恢复计划。

玩家核准后：

- 不预扣全额，也不发放补偿。每旬最多实付 **1,400 两**，按真实价格分批购买兵装、招募和训练。
- 可选地方治理支出临时限为 **350 两/旬**，不改写原治理预算。目标完成、主动停止或授权额度不足下一批时解除限额；玩家后来修改的预算不会被旧值覆盖。
- 至少保留 **7,000 两**及现有更高保留线，并为常规亏损留出缓冲。恢复安排在常规收支和供粮结算之后；缺粮、欠债、战役或京城危机时暂停，不自动借债。
- 救急购粮仍可使用正常治理预算；本旬已经支付的救急不会因 350 两的可选支出限制而产生非法预算记录。
- 先用空闲劳力。玩家可授权必要的产业抽调，也可选择仅用空闲劳力、不足就等待。产业抽调许可为每业 10%，实际只抽取当批缺少的人数，承担相应生产损失。
- 总支出受核准额度约束，停止不退款，读取存档或重复结算不能重复扣款、复制装备或补员。

兵装仍遵守原产购与驻地规则；计划不凭空生产原本不能在中央采购的特殊兵装。其他驻军仍由兵部按真实驻地办理补充。阵亡人口不会复活，恢复兵员来自重新征募的平民。

### T02：兵员、兵装、训练分别显示与恢复

恢复页有“进度 / 核准 / 兵装”固定分页，分别显示三项实际进度、当前报价、累计实付及授权上限。默认将恢复战前训练纳入计划；玩家也能明确选择“只补兵员与兵装”。

计划训练继续走原来的付费训练规则，与手动训练共享每旬限次，不设免费训练保底。选择不训练时，回执明确显示“训练未纳入本次授权”，不会把人数补满标作战力恢复。新战损发生后也不会继续显示旧计划“已恢复”的状态。

训练恢复指引可从大将军页面查阅，但该入口只读；恢复额度仍由兵部尚书核准，兵部侍郎也不能越权办理。

### T03：出征核阅显示真正的风险与重建代价

朝堂和兵部原有出征入口共用新核阅页，保留现有落印步骤，不禁止玩家挑战强敌。两页分别核对：

| 兵力与训练 | 钱粮与重建 |
| --- | --- |
| 实际出征与敌方本地人数 | 本次额外整备银、补给粮 |
| 明确的敌我兵力比例、劣势提示 | 全损后按当前价补员、补装的估算 |
| 双方训练与中央预备队 | 国库与重建资金缺口 |
| 当前空闲劳力 | 需从产业抽调的人数、训练另付说明 |

敌军本地人数不包含可能援军；兵力比例不伪装成确定胜率。主将亲卫退场即判负、阵亡按兵种核销的规则继续保留。当前新局自动编阵的 1,600 对 4,480 场景会显示 **35.7%** 的兵力比例，清楚区分几百两的出征补给与约三万两的重建费用。

### 恢复效果与战争代价

主要战损在第 19 旬发生。下表“完成”指实际计划完成，包括所选训练目标，而非仅补齐人数。

| 情形（三种子） | 完成旬 | 从受损起耗时 | 恢复实际支出 | 债务峰值 |
| --- | ---: | --- | ---: | ---: |
| 中央军全损，核准完整恢复 | 51 | 32 旬，约 11 个月 | 30,361～30,417 两 | 0 |
| 中央全损，加半年极端高税失误和三州旱灾 | 51 | 32 旬 | 30,619～30,654 两 | 0 |
| 实际自动编阵出征败战后，核准恢复 | 50 | 31 旬 | 28,999～29,048 两 | 0 |
| 实际小兵力败战，加三州旱灾后恢复 | 23 | 4 旬 | 1,905～1,911 两 | 0 |
| 中央全损，只授权补员和兵装 | 46 | 27 旬 | 30,041～30,097 两 | 0 |
| 中央全损，但仅授权 1,000 两 | 暂停等待重新核阅 | 不越权追加 | 991～998 两 | 0 |

正常完整恢复的三个种子均保住 7,000 两应急金。战灾和极端高税叠加仍产生 33～34 旬暂时动乱、生活水平最低 54；没有免费消除苛税后果，但不再拖成永久债务死局。仅补兵装的路线训练最终为 15，页面明确显示尚未恢复战力。

默认治理加手动逐批恢复的对照仍需约 5.7～6.4 年才能恢复训练，新计划缩短至约一年内。新计划按战前实际库存定目标；旧手动对照使用开局库存，且多年后的工业采购能力不同，不能把费用差异误读为改价。

### 正常发展与真实国际局势

- **26 条全面发展基线**的国库、债务、常规净收入、粮食、人口、生活与建筑数量均与前次报告完全一致，说明未授权恢复时没有暗改原经济规则。
- 18% / 20% / 22% 税的正常发展路线均保持无债务、无缺粮。短期失误可补救；长期高税仍会引发民乱和亏空，特赦不能替代降税治理。
- 七类单州灾害、三州同时旱灾、十州同时旱灾及过度采购仍通过；没有为了恢复军备牺牲正常救灾。
- 六条 20 年完整国际局势路线全部完成。默认组分别经历 3、1、4 次自动守城；核准恢复组实际核准 3、1、3 次恢复计划。两组最终均为 9 州、无债务，生活水平 69。恢复组国库为 **429,425～433,159 两**，仍真实承担了整军支出，不自动改写战果或收复失地。
