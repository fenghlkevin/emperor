## 基础玩法

采用炉石普通卡牌对战的完整回合结构：本方连续操作，点击结束回合后切换对方。玩家可自由安排出牌、部队攻击与主将技的顺序，只受军令、场位和行动次数限制。

同步指令、双方锁定后同时结算和每人只做一个动作后换人均已撤回，不进入本项目的目标玩法。平衡问题在固定回合结构内，通过卡牌、自动组牌和AI解决。

| 项目 | 目标规则 |
|---|---|
| 起手 | 先手3张，后手4张，双方可以换牌 |
| 后手补偿 | 额外1张0费调兵令，本回合临时获得1点军令，不增加永久上限 |
| 初始军令 | 首个己方回合1点，之后每个己方回合上限增加1并恢复，通常上限10 |
| 回合抽牌 | 每个己方回合开始抽1张，包括首回合 |
| 本方操作 | 可连续出多张牌、使用主将技，并让多张己方部队依次攻击 |
| 普通部队 | 登场回合不能主动攻击；下个己方回合起，每回合通常攻击一次 |
| 突袭 | 登场回合可以攻击部队，不能攻击主将 |
| 交锋 | 每次主动攻击立即结算，部队之间同时造成攻击与反击伤害，然后处理退场 |
| 护卫 | 有护卫时普通攻击优先选择护卫；计策和登场效果按牌面选目标 |
| 容量 | 双方各7个部队位，手牌上限10 |
| 换人 | 点击结束回合；对方完整操作结束后再轮回本方 |

起手3／4张、后手幸运币补偿及先手首回合再抽一张，参照暴雪[起手换牌说明](https://hearthstone.blizzard.com/en-us/news/21363040/opening-moves-mulligans)。突袭的当回合目标限制参照暴雪[突袭说明](https://hearthstone.blizzard.com/en-us/news/21658543/non-printable)。游戏内将法力表现为军令、幸运币表现为调兵令。

军令充足不代表每个动作都要花军令：攻击不额外扣军令，所以军令为0时仍可能有部队能够攻击。调兵令可以临时跨过当前费用档，例如第2回合2军令加调兵令，可使用3费牌；这种标准补偿保留，通过牌卡本身校准强度。

## 开局无牌可出的处理

旧卡表的普通兵和前锋最低2费，配合1点初始军令时，先手首回合无法部署部队。问题在费用曲线，不需要改变回合顺序或把起始军令提高到3。

修订如下：

- 将已有真实前锋改为1费的低费部队。仍替换一个原实体牌位、使用实际兵员，不额外赠兵或装备。
- 沿用前锋进入起手的保底，两方都适用，计入先手3张／后手4张，不在手牌之外额外赠送。它是本游戏自动组牌的开局保障，不声称炉石原规则也保证1费牌。
- 其余卡牌按1、2、3费前期牌，中期主力与后期强牌配置费用曲线；不能只堆3～7费兵种。
- 前锋的攻命按1费预算重新制定，旧2费2攻7命不能直接降费套用。训练、统领和城防的加成也要重新检查，避免1费部队因叠加属性超过正常中费牌。
- 换牌提示保留低费牌、换掉当前用不上的高费牌。自动组牌和换牌策略对玩家与外国一致，不根据对手隐藏手牌定向发牌。

这是卡牌与组牌修订，回合仍按炉石流程执行。部队在敌方回合可能被击败，不能保证每张新上场部队一定轮到攻击；生存能力通过费用、生命、护卫和反制牌设计处理。

## 与现有军队的衔接

主将、子队将领、实际兵力、装备、亲卫与军粮继续使用现有游戏数据。只保留现有训练度，不增加士气。普通部队、武将和前锋仍共用真实兵员与牌额，不能复制将领或凭空生成士兵。

外国使用持久化人物并按相同条件生成武将牌；不在战斗时临时抽一张随机强将来补平衡。难度主要调整决策质量，不额外加敌军生命、攻击或军令。

军队造牌、预备兵和来源结算是本项目与经营系统的衔接，需要明确标为项目规则。基础出牌、回合、攻击和后手补偿按上述炉石式结构固定，不因某种军阵失衡再次改成另一套行动玩法。

空牌处理也回归抽空疲劳：每次实际尝试抽空牌库时，主将受到递增疲劳伤害，依次1、2、3……；不再采用第16轮双方统一掉血。它对小军牌库和补充兵的影响须连同牌库容量、计策占比、抽牌技能一起验证。

## 平衡修订顺序

1. 补齐低费曲线与合理的费用／攻命预算，先修高生命低费兵、低费突袭和高费登场伤害的超额收益。
2. 按最终卡牌强度校准训练和人物加成，保证增长有价值，但不让所有低费兵因固定加成都变成超额强牌。
3. 校准护卫、单体解牌、范围伤害、抽牌与治疗的成本，让后手有正常反制工具。主将技同样计入每回合的费用组合。
4. 用固定的3／4张起手、1点初始军令和标准调兵令重新推演，同一军队交换先后手，按兵种、训练、主将和兵力分组报告。
5. 正式引擎接入后验证来源守恒、攻击操作、保存恢复和真实界面。现有UI保留，按钮仍为结束回合。

此前162000局整回合模拟使用3军令开局、双方4张起手和旧高生命卡表，属于旧候选失败的证据；不能推导出炉石式回合本身无法平衡。同步与交替行动的结果只保留为已撤回方案的历史记录，不作为目标玩法的验收结果。

本次修订没有重跑新卡表整局统计，没有把任何旧百分比当成新规则胜率。后续需在完整卡牌数值明确后，使用同一AI、新种子和正式引擎逐步验证；不能仅凭采用炉石框架就声称已达到公平目标。
