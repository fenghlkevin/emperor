左图为本会话最初认可的原型，右图为实际 Electron 战斗画面。保留沙场、木铜卡框、上下主将、竖旗生命、左侧回合、右侧青玉按钮、扇形手牌和底部军令。后续确认的七部队位与真实人物要求已落实。

对照项目实现
场景与布局落日沙场、雕木桌面、带旧纸纤维与铜饰刻纹的实物卡框、厚度阴影与青玉操作区；适应窗口保持16:9。
主将本人既有肖像和姓名；外国随机人物固定身份并使用相应区域资源。
战场原型四位改为已确认的七位，场上卡框正置；主将圆框与部队攻命不互相遮挡。
卡面场上：5:7竖向长方形，插画按原始比例裁切；窄名称条、底角攻命。手牌：较长完整卡、费用珠和自然扇形；普通无技能部队满幅立绘，带技能部队保留纸面，攻命位于插画／说明交界；计策使用12幅独立插画。
操作反馈命中区域固定，内部牌面抬起；标题高于主将，提示条置于左侧；就绪绿光、合法目标高亮、实时伤害预览。
动画上场抬起、飞入、落定尘光；上场后立绘呼吸、衣甲流光与粒子持续循环；主将技和计策具有蓄势、亮牌、飞行与命中效果；攻击先蓄势／冲刺，命中才扣血，保留刀光冲击圈与伤害数字；结束按钮玉光循环与点击扩散。支持快速和减少动态效果。
人物牌册100人可检索，费用攻命、本人肖像、专属技能与生平依据按ID关联；查看不代表已取得。

这是实机与原型的视觉对照，不声称不同插画、本人肖像和新增七场位能与原型逐像素重合。运行 npm run preview:card-battle 可直接验收操作和动画。
