# 玩法平衡调整与复验 · 2026-10-17

本轮针对[前次验收](playability-balance-audit-2026-10-17.md)的寿元尺度、财粮自然积累和兵装采购门槛调整。规则集中在`src/balance-rules.mjs`，兵装价格仍由`src/troop-kits.mjs`统一提供；界面、模型、类型及相关说明同步更新。

## 已实现规则

| 项目 | 调整后行为 |
| --- | --- |
| 寿元与年龄 | 初始20岁、2160旬寿元；36旬一年、自然跨旬减1。普通独寝与安寝至明均无额外寿元费，正常可在位60年到80岁。首次相伴不额外扣寿元，连续相伴依次0/2/4/8/16/24/32，此后32；夜间不再额外扣3。过劳仍额外扣30，出行、丹药等特殊费用保留。 |
| 商业增长 | 营业高于初始化基准的差值除以600，增益上限10%，替代原来的除以100、上限100%。基础税率与产业税基不变。 |
| 财政压力 | 繁荣公共服务费=`round(Σ各州 人口×0.0013×max(0,生活−50)/100)`，只计入一次行政支出。生活提高后支出随人口与生活增长。新局本国中央其他收入400两/旬，避免新增维持费挤空开局。 |
| 粮仓周转 | 安全库存=每旬口粮×min(36,18+有效粮仓×2)。仅灾后期初超出安全库存的部分每旬损耗8%，向上取整；当旬新产粮不损耗，库存不硬截断。购粮与调粮仍全额即时入仓。 |
| 装备采购 | 每人份刀盾12、长枪10、轻骑28、重骑40、弓10、弩16、骆驼30、象60、弓骑32两；招募4两/人另计。产地、库存、占用、伤亡扣装规则保留。敌国使用相同采购价，并据实有装备与现金征兵。 |

本轮没有提高战利银掩盖采购问题，没有改技能成长、特殊工程工期、初始兵力或兵种战斗系数。军事压力仍存在，初始中央军自动进攻仍会失败。

## 兼容与记账

新增`balanceRulesVersion:1`，与存档外层2、内政8、皇帝量纲1、套装1并存。兼容范围内缺标记的存档补1；不重算既有寿元、年龄、现金、粮食、装备、旧其他收入或终评，不补偿历史睡眠消耗。未知平衡版本拒绝。旧档只从后续动作和结算采用新规则。

供粮事实记录新增可选`storageLoss`，历史缺失按0处理。守恒为`期初−陈粮损耗＋产出=实际消耗＋期末`，缺粮=需求−实际消耗。财政预算与常规结算共用公共服务费公式，展示字段`publicServiceCost`已包含在行政费中。

固定创建时间与随机源，种子1、7、41；不注资、不修改忠诚、不补免费装备。普通政令支付办公成本；模型直接自动处置紧急战争，实际界面的属性门槛另测。按年JSON读写并完整校验存档。以下15组与前次使用相同策略。

15组全部完成，共7560次旬推进、0运行错误，样本内供粮缺口和期末债务均为0。20年后的初代仍为40岁、寿元1440；10年后为30岁、寿元1800。原来同时间库存约数百万石，现在约58万–70万石；无需经营的现金积累显著下降。被动封赏路线期末预算已为−227至−145两/旬，说明后续仍需主动调整财政，不能把过去积累理解为永久盈余。

首都书院补测360旬：第6旬开工、第160旬启用，期末国库184,361两；河北边境工程失地停工规则保留，安全选址仍有实际价值。

全州委任原税率补测720旬：种子1期末国库0、债务117,498两，预算−779两/旬。它是持续委任支出与繁荣维持费下的财政压力；2000两保留线只限制委任下令，不保证后续常规支出不低于该线。主动预算路线3个种子均完成720旬，仅使用2次税率政令（各州从12%调至14%），期末国库33,303–58,350两，全程债务为0、供粮缺口为0。部分种子期末年度生活增长后预算仍为负，仍需后续年度检查，不能无限忽略收支。

## 战争与采购

同一AI、相同真实初始兵装，各3次：初始1600人进攻南诏均战败；合法调剑南驻军后6920人出战均获胜，阵亡873、战利银1384。按实际兵种损耗补装需18,042两，较前次最低单价估算也超过148,410两的门槛明显降低，但战争依然消耗财政。初始中央军全部战损补装25,888两。百人普通兵装现需1000–4000两，可用开局10000两实际采购；特殊兵装仍有产地与溢价限制。

这些样本用于对照成本，不代表玩家战术上限或所有敌国难度已平衡。产业500亩开发的静态税收回本仍约250旬，未在本轮改动。训练3–6年满值、边境工程风险等原报告其他议题仍保留。
