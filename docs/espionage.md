# 礼部图鉴与兵部秘谍

礼部侍郎查阅入口使用国政卷轴样式，正文独立滚动，关闭按钮固定可见。各外国显示邦交、友善及钱库、粮仓、部队、兵器套装、人口、州郡、国威图鉴。未经谍报的内部数据统一显示 `***`。

兵部尚书的「秘谍」可派遣空闲待命官员。翰林院研习人员和已有秘谍任务的人员不可派遣；任务期间不可调任或参加研习。选择目标时显示费用：1000两基础费用，加上双方国家中心坐标每15度距离500两的档位费用（试行距离规则）。派遣立即记入国库支出，9旬后结算并释放人员。中途召回立即释放，进度作废、费用不退。

成功率为45%加智力/200，上限90%；成功记录完成当旬的数据快照。失败友善降低10（最低0），原情报保留，人员返回。图鉴注明快照旬数和距今旬数，不随目标国家后续发展变化。任务和报告存放于 domestic.espionage，旧档无此字段可直接读取，派遣时按需初始化。
