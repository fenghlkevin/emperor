# 奥秘组合、代价与反制

2026-10-23。规则5、奥秘卡表1、AI1。下列为正式引擎功能边界，不是公平率或随机实战结论。首版两张奥秘均2费，每副最多两张，与普通计策／武器共享30张预算；军令来自已部署主将军阵，不重复配兵、训练或占装。

| 组合与触发 | 实际收益与代价 | 反制／边界 | 检查位置 |
|---|---|---|---|
| 先警戒，再设伏 | 先增加3甲，再对来袭部队造成3伤；即使来袭者随后阵亡，已增加护甲仍保留 | 共占4军令、两张牌及两个活动槽位；不能把被中止的攻击伤害补算回来 | 11步教学、原有秘密引擎顺序模型 |
| 先设伏击杀小部队，再警戒 | 第一支部队阵亡，原本主将攻击中止；后续警戒保持匿名待命 | 小部队可试探；下一支存活部队的独立合法攻击才再次检查警戒，不能一击消耗两张不再符合条件的奥秘 | 11步教学真实对手两次攻击 |
| 高命或护甲盾承受设伏 | 部队生命大于3可存活；护甲盾抵挡这次3伤后消失，随后按触发后的真实护甲攻击 | 仍消耗本次攻击次数与护甲盾，护甲不能按旧预览绕过；3命或更少且无盾会阵亡 | 新组合护甲盾模型、原16项引擎高命模型 |
| 持武器主将攻击 | 御前警戒可增加3甲，防守主将按新护甲承伤 | 限定“部队来袭”的设伏不触发，继续隐藏；攻击仍按正式武器规则耗1耐久 | 原规则5引擎／界面与守城武器回归 |
| 精准射击等计策／主将技 | 可以使用合法伤害或其他效果处理局面，不触发这两种攻击奥秘 | 没触发不能推断对方没有奥秘；仍正常支付军令与技能次数，不能任意选择奥秘区作部队目标 | 11步教学、三类真实主将技组合模型 |
| 同名第二副本 | 第一张真正揭示离场后，可再支付2费布置另一张，产生更晚顺序号 | 活动区已有同名时正式动作拒绝，无扣费或新增记录；每副总计仍最多2张，不会复制卡片 | 新同名重布置模型 |
| 沉默／冻结／部队强化 | 对合法部队仍按原规则执行；冻结会阻止该部队主动攻击 | 奥秘不是部队，不能被这些目标型计策直接选中，沉默不移除军令；没有新增反奥秘特权 | 新奥秘目标拒绝模型与原冻结／合法性模型 |
| 设伏击杀历史人物，遗计抽牌遇空库 | 真正遗计继续结算，疲劳可导致攻击方主将先败；原攻击及后续不符合条件的奥秘均停止 | 对局结束不能强行完成原先主将伤害；遗计由真实历史ID对应定义驱动，公开原因链保留设伏→死亡→疲劳 | 新历史遗计／疲劳组合模型 |

教学世界的固定起手、四支无护卫靶队、数值及对手脚本在规则说明中逐项标明，不替换实战AI或正常洗牌。训练对手也通过 `advanceWar` 执行支付、布置、攻击及回合结束；没有在结算阶段直接注入伤害、秘密揭示或胜利。19条正式动作记录包括11次玩家动作和8次对手动作。
