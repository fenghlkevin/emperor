# 皇帝原版内政指标关系

整理日期：2026-10-16。本篇按“哪些数值影响哪些结果、何时生效”整理 DOS 原版内政。证据标记与 [时间与行动规则](时间与行动规则.md) 一致。以下原版公式主要为静态确认；仅明确标为【原版实测】的项目已有受控 DOS 执行结果。

主要依据：[内政规格](../../../reverse/emperor/replica-design/03-domestic-and-economy.md)、[第三轮字段订正](../../../reverse/emperor/validation-round3/special-fields/README.md)、[月费用实测](../../../reverse/emperor/validation-round3/runtime/README.md)。旧报告曾误认内乱、暴动、饥荒字段和民忠输入位置，本篇采用订正后的关系。

## 先分清几种容易混淆的指标

|指标|原版用途|不能混同为|
|---|---|---|
|国库资金|国家可收支的资金存量，可为负|收支分类累计数|
|财富积分|地区升降生活等级的累计量，可为负|可直接消费的地方银两；修改器曾标“现金”|
|生活等级|贫穷、尚可、小康、富裕、极富，对应0至4|连续的0至100生活指数|
|四业职业人口|农、牧、商、工人数，各自参与产出|总人口或产出分母的实时别名|
|产出人口分母P|人均产出、费用和部分损失的公式输入|任意时刻的四职业人数之和|
|总人口字段|另一聚合字段，外邦征兵等会读取|P；原版并非所有函数都即时同步它们|
|积粮指标|六项内政指标之一，参与民忠及人口增长路径|已证明具有“石”单位的实物库存|
|开发容量、开发量、行业效率|三个独立存储层次|同一开发率的三种写法|
|安定、治安、民忠|分别参与不同检查和公式|一个可互换的满意度数值|

【攻略】四业写作“农牧运矿”；【原版静态】人口字段按农、牧、商、工识别，开发量对应农田、牧原、运输、矿区。它们是配对关系，不能因此认为运输开发量就是商人人数。

## 指标怎样连成经营循环

以下箭头表示已定位函数中的输入输出关系，不表示所有数值每次点击都会重算。

```text
职业人口＋行业效率＋本期剩余产出比例
        ＋商人分支的体能加成
                  ↓ 半年生产
             原始人均产出
                  ↓ 受民忠×2封顶
             本期人均产出q
              ↙             ↘
税率＋税额系数＋P          税率＋当前生活等级
        ↓                         ↓
     国家税收              地区财富积分增减
        ↓                         ↓
      国库                    生活等级升降
        ↓
每月人口、官员、爵位、民夫、军队、建筑费用
        ↓ 若阶段推进时负资金且符合月份条件
     额外补征 → 财富积分下降＋国家民忠修正下降

税率＋官员智慧＋六指标平均＋生活等级＋其他修正
                  ↓ 民忠重算
                 民忠 → 再影响产出上限与人口增长
```

【待证】开发量、建筑等级到行业效率及六指标的全部换算链尚未在本轮材料中完整对应。因此不能在图中补一条“市集等级直接乘税收”的确定公式。

## 收支按不同周期发生

|周期|主要变化|对玩家判断的影响|
|---|---|---|
|半月|工程推进、灾害与民变损失、训练衰减、增援、待分摊款入账|同样的半年产出可能因期间损失而不同|
|月|符合模式的自动开发、维护与薪俸等费用|半年收入到来前仍须准备周转资金|
|半年，进入1月与7月|生产、税收、财富等级、职业人口增长|不能把半年税额当月收入，更不能当半月收入|

【原版静态】月费用早于当月可能发生的半年税收；普通上旬进入下旬不会重复收半年税。完整时序见时间篇。

## 生产与税收

### 人均产出

【原版静态】令n为各职业人口，e为各行业效率，m为剩余产出百分数字节。先从各m扣除本半年累计产出罚值，再计算：

```text
农产出 = 截断(e农×n农 / 100) × m农
牧产出 = 截断(e牧×n牧 / 100) × m牧
商产出 = 无符号整除((截断(e商×n商 / 100) × m商) × (体能＋50), 100)
工产出 = 截断(e工×n工 / 100) × m工

P非0时：原始q = 四业产出之和无符号整除P，再按有符号16位解释
P为0时：原始q = 0
本期q = min(原始q, 民忠×2)
```

商人分支读取的是**体能**，不是营业。产出结算后四项剩余比例恢复100，累计产出罚值清0。原版字节扣减无下限保护；异常情况下会回绕，不能把上述公式视为任意修改数值下都正常。

直接关系：职业人数和效率进入行业产出；体能对商人分支有额外作用；灾害与民变累计罚值影响本期产出；民忠限制最终人均产出。行业效率与开发量如何完整联动仍需进一步对应。

### 半年税额

【原版静态】全国税率t为全局参数，c为地区税额转化系数，P为产出人口分母：

```text
地区税额 = 截断(截断(P / 100) × q × t × c / 100)
国家本次半年税额 = 各受统治地区税额之和
国库 += 国家本次半年税额
```

c的精确中文界面名未证。式中的先除后乘不能交换，P不足100时前一项可能直接截断为0。

【攻略】“税收只看税率和已开发国土面积”是过度简化。已确认的税额直接读取P、q、t、c；q又受效率、职业人数、体能、灾损和民忠影响。开发影响收入的完整中间链仍待补。

## 税率同时影响国库与居民财富

【原版静态】设当前生活等级为L，半年财富变化为：

```text
财富变化 = q − 截断(q×税率 / 100) − (L×15＋60)
财富积分 += 财富变化
若积分小于−100，则改为−99
随后检查一次生活等级升降
```

相同q下，提高税率会增加直接税额，同时降低地区税后积累；民忠公式还会受到税率影响。因此不能仅用当前税额推断长期收益。

【计算示例，源于静态公式，非DOS实测】q=120、税率20时，贫穷L=0的变化为36，小康L=2为6，极富L=4为−24。生活等级越高，同样产出越难维持正积累。该公式直接体现的是固定需求项每级加15，不能据此确认攻略“每升一级所需土地翻倍”的完整说法。

### 生活等级阈值

【原版静态】一次检查最多升或降一级：

|当前等级|升级所需积分|降级条件|
|---|---:|---:|
|贫穷0|≥60|不再降级|
|尚可1|≥65|≤−40|
|小康2|≥70|≤−50|
|富裕3|≥80|≤−60|
|极富4|不再升级|≤−70|

升级扣去对应正阈值；降级减去对应负阈值。例如小康积分−55，降至尚可后积分−5。积分200从贫穷检查一次也只升至尚可，剩140，不连续跳到更高等级。

## 民忠连接税率 官员与民生

【原版静态】民忠重算使用：

```text
税率项 = (50−税率)×2
官员项 = 智慧<59时为0，否则截断((智慧−59)×25 / 10)
六指标均值 = min(截断((安定＋治安＋体能＋营业＋积粮＋防御) / 6), 100)

民忠 = 截断((税率项×35＋官员项×15＋未知输入×10
             ＋六指标均值×20＋截断(生活等级/4)×20) / 100)
       ＋国家修正＋地区额外修正
民忠最低为0
```

未知输入为地区R+96，地区额外修正为R+94，国家修正为E+2BE。已确认公式没有统一100上限；其他路径如每月自动开发增加民忠时另有100上限，不能互相替代。

生活等级先除4并截断，等级0至3的该项均为0，等级4才贡献20到分子。不能改写为每升一级民忠固定加5。

六指标重算前，相关函数还会按一个未完全命名的国家字段扣体能，再加入已完成特殊设施的效果。此处尚无完整“每座普通建筑提高多少指标”的确认表。

|指标|已确认的关联|尚不能作出的结论|
|---|---|---|
|安定|进入六指标均值；影响内乱触发与解除|高安定必定阻止一切灾害|
|治安|进入均值；影响暴动触发与解除|与安定可完全互换|
|体能|进入均值；直接影响商产出分支|只影响军事或校场|
|营业|进入均值|已证明它就是商产出直接倍率|
|积粮|进入均值；达到100会改变人口增长共享变量|低于固定积粮值就必发生饥荒|
|防御|进入均值|本篇已恢复全部攻城与减伤作用|
|官员智慧|进入民忠公式；自动开发增量另依赖任务函数|已完整证明清廉、忠诚的贪污与叛变阈值|

【攻略】刺史忠诚高于90、清廉高于85是经验建议；“每四个月轮换”同样不能作为精确法定周期写入原版规则。

## 人口增长与转业

【原版静态＋指令模拟】半年人口增长有跨地区共享变量缺陷：初值沿用第一遍税收循环最后一个受统治地区的财富变化；第二遍人口循环中，遇到积粮≥100的地区才改为100，后续低积粮地区继续沿用该值。

```text
遇到积粮≥100：共享值X=100；否则不改X
增长参数r = 截断((民忠＋截断(X/2))×15 / 10)
各职业人口 += 截断(截断(各职业人口/100)×r / 100)
```

【指令模拟】四职业各1000、民忠40、共享初值−40、积粮依次20/100/20时，三个地区每项职业分别变为1003/1013/1013。该结果说明地区顺序会影响人口增长，不能用“按本地积粮各算各的”替代。尚无完整半年DOS端到端证明。

【原版静态】转业是另一辅助：通常从非目标行业各迁移3%到目标行业；特殊模式非零时为30%。四业各1000、普通模式目标农业时，结果为农1090，其余各970，总量4000。此为静态公式推演，不是新增人口，也不证明所有菜单的调用时点。

【待证】人口增长如何通过全部聚合刷新与效率重算，最终造成“人口更多、生活反而下降”，仍需补齐中间调用。现有公式已能说明人口既影响生产也影响费用，但不足以量化该反馈的完整过程。

## 月支出与负资金补征

【原版静态；月费用合计已有实测】

|月支出项|公式或规则|
|---|---|
|人口项|各受统治地区P之和除以2并截断；准确中文账目名待核，不能直接叫主动补贴|
|职位薪俸|在职每人40，散官每人20|
|爵位薪俸|王600、公300、侯160、伯80、子30、男10、无0；与职位工资叠加|
|民夫项|国家相应人口字段×4|
|军队项|地方兵与中央兵合计×4|
|建筑维护|前六类普通建筑每级10，行宫每级200；另加状态恰为1的特殊设施模板费用|

【原版实测】一组原档夹具六项费用分别为建筑720、人口5522、官员1460、爵位3170、劳役2668、军队6384，合计19924；国库1000000变980076。该用例证明这组费用结果，不等于所有经济分支均动态通过。

【原版静态】国库允许负数。半月地区推进开始时，若国库为负且当前不是6月或12月，则执行补征：各受统治地区财富积分减3、最低−99，并检查等级；国家民忠修正减1；国库增加各地区P×3之和。增加建筑、军队或高爵位官员都会提高持续费用，不能只看一次性成本。

特殊设施工程完成写状态2，而月维护只识别状态1；这些已定位分支应分别保留，不能改成“所有非零状态都收费”。状态转换及每种设施效果仍待完整对应。

### 分摊入账与补助

【原版静态】阶段推进把待入账款除以P并截断，加入地区财富积分，然后清待入账款并检查等级。P=10000、待入账9999时，积分增加0，款额仍被消费。该字段的精确菜单来源尚需对应。

【攻略】“不要用补贴改善民生”可理解为效率建议，不能扩大成“所有补助绝无效果”；已知分摊路径受人口分母和整数截断影响。

## 驻军与民变

【原版静态】以下比例分母为P，不应随意换成报表总人口：

|状态|新触发的必要条件|活跃状态解除条件|
|---|---|---|
|内乱|受统治、当前无内乱、截断(士兵×100/P)<20，且安定<50|兵占比>25，或安定>60|
|暴动|受统治、当前无暴动、相同比例<20，且治安<50|兵占比>25，或治安>60|

满足触发条件后仍要累计概率并过随机门，不是立即必发。每次符合检查累计门限加10；单次扫描只触发首个成功地区。兵占比恰20不满足上述触发条件；恰25不能靠兵比解除，安定或治安恰60也不能靠该项解除。

民变爆发还会降低地区民忠额外修正和皇帝快乐；活跃时每半月损失人口、开发和建筑，并累计产出罚值。内乱每半月罚值加1，暴动加2，进而影响下一次半年产出与税额。

【攻略】约1比4驻军是经验建议，与上述20%触发和严格大于25%解除的滞回阈值应分开。它不等于“达到四分之一就必定平乱”。

## 灾害与饥荒

【原版静态】灾害、饥荒、内乱和暴动有各自状态字段，单个“情势”显示码不能覆盖全部状态。

|灾害|每半月已确认的阶段损失|产出罚值|
|---|---|---:|
|旱灾|死亡P的1‰，转劳役5‰，四项开发各损失8‰|+1|
|水灾|死亡2‰，转劳役5‰，开发各损失8‰|+1|
|蝗害|该阶段分支未调用人口与开发损失辅助；不能推出全流程无其他损失|+4|
|瘟疫|死亡4‰，转劳役5‰，开发各损失4‰|+1|
|严寒|死亡1‰，转劳役2‰，开发各损失5‰|+2|
|地震|本段主要清标志；一次性事件损失需另查|不据此填0|

【原版静态】饥荒触发检查的是已有灾害且灾害进度≥30，再经过随机门；此检查并非直接以积粮为门槛。活跃饥荒每半月死亡P的5‰、转劳役1%、各开发损失5‰。解除进度每次加8再过随机门，因此不应写成固定若干半月必结束。

以上损失大部分仍是静态恢复，未全部逐项DOS差分。各灾害触发概率的全部来源、建筑防灾关系和一次性损失仍待补齐。

## 工程与军队的直接关系

【原版静态】工程每半月累计量增加一次固定增量，达到需求即完成。普通建筑相应等级加1，完成时归还相关投入额度并整理队列。开工造价、重复建设与全部菜单限制未完整恢复，因此攻略“工人数×月数”的工程说明只能保留为粗略理解。

【原版静态；衰减有实测】地区训练大于0时每半月减1。增援落实前先发生该衰减，再按留守兵与增援兵人数加权合并训练；兵员和装备从中央转到地方。驻军提高安全保障，同时每名兵每月增加4的军队费用。

外邦另有按人口比例重算兵员的分支，不能套用成玩家每半月自动补兵。兵力、训练与装备进一步影响战争和外交，完整算法留在战争外交专题。

## 攻略与原版证据对照

|攻略说法|当前整理结论|
|---|---|
|税收与生活水平无关|税额不直接读取等级项，但等级参与财富积累与民忠，而民忠封顶q；不能概括成完全独立|
|税收只取决于税率和开发面积|省略多个已确认输入，不作为完整规则|
|市集超过100%才能全部变现|尚未完整对应到原版效率与流通算法，保留待证|
|优先开发人数多的行业|合理的玩家策略候选，但开发效果、效率、民忠上限和容量都可能限制收益|
|生活升级土地需求翻倍|尚未确认；已知财富需求项每级加15，不能互相替代|
|刺史忠诚90、清廉85可保证安全|经验阈值，不能写成已经验证的概率边界|
|四分之一驻军足够|区分预防与解除；严格阈值见驻军表|
|存档“现金”可直接视为地方钱|相关字段实际是生活等级积分，不能按两结算|

## 待补关系与建议核验顺序

1. 开发容量、开发量、职业人数如何生成行业效率；市集与运输的准确参与位置。
2. 普通建筑等级到六指标的重算公式、上限和调用时点，特殊设施状态与效果。
3. 官员任务开发效果、清廉的贪污路径、忠诚的叛变路径，分别对应菜单及概率。
4. 人口聚合字段在增长、征兵、灾损、转业后的刷新顺序，解释人口增长与生活回落的完整链。
