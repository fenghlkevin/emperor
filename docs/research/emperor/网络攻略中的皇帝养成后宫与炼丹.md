# 网络攻略中的皇帝养成后宫与炼丹

整理日期：2026-10-16。对象为C&E的DOS《皇帝》。本篇只整理公开网络攻略和用户原文，不使用程序分析，不把玩家经验提升为确定算法。来源A至F及转载关系见 [来源登记](网络攻略来源与去重.md)，分歧统一放在 [养成与结局冲突清单](养成后宫炼丹结局攻略冲突清单.md)。

## 皇帝养成

### 先分清能力和消耗资源

|项目|攻略描述的获得方式或用途|阅读时要区分|
|---|---|---|
|智慧|御书园修习；A称影响高智慧举子出现|修习收益、开发效果和招募效果不是同一公式|
|武术|武道场修习；A称影响高武力举子出现|皇帝本人武术与带兵将军武力分别讨论|
|魅力|琴棋阁修习；A称影响后宫人物才貌|与名臣招募的关联及概率方向有分歧|
|才艺|百剧院修习；A称增加特殊建设选择|解锁哪些建筑、具体门槛仍待资料|
|当前体力|办事消耗，独寝或后宫恢复|恢复量不等于上限提升|
|体力上限|狩猎可提高，部分丹药也可提高|狩猎是常用渠道，不能概括为绝对唯一渠道|
|健康、快乐|活动与事件分别改变|不是剩余寿命的另一种显示|
|寿命与年龄|药物可增寿，长期游玩会变老|年龄、在位年数、剩余寿命不能混用|

基础入口和作用据[A个人修为、宫殿及炼丹节](sources/user-guide-2026-10-16.txt)。能力用途存在相反解释，见Y01、Y02；上表保留A的说法，没有裁定正确版本。

【玩法归纳】玩家要同时决定今天能办多少事、长期练哪种能力，以及怎样保留足够寿命。恢复体力只能解决眼前的行动预算；若恢复活动还有其他代价，就需要一起权衡。

### 活动安排

|活动|A记载的主要效果|尚未统一的细节|
|---|---|---|
|四项修习|对应能力成长，每次记体力减20|转载中出现减40；开局性向是否改变成长速度|
|狩猎|提高健康和体力上限|季节、猎物与提升量|
|金龙殿独寝|体力加150、健康加5|白天与夜间的时间和寿命成本|
|后宫休息|恢复体力和快乐|恢复能力、健康与寿命代价|
|微服出巡|访查民情|快乐、耗时与事件结果|
|探望太后、召见子女|影响孝道与慈父评价|重复操作计分方式与可用期限|

出处：[A操作节](sources/user-guide-2026-10-16.txt)。这些是攻略中的活动表，不能据此推出所有场景都具有相同耗时。

## 后宫与子女

### 人物发现和培养

【攻略记载】A描述通过安排宫女发现人物、册封留用，再在紫宸殿调整名分，也可将皇后以外的嫔妃打入冷宫。A同时提供历史美人名单，但人物介绍混合文学与传说，不能当作历史事实。[A第十节及操作节](sources/user-guide-2026-10-16.txt)

A给出的能力说法为：

```text
能力 = 外貌×3 − 88 ＋ 职务附加 ＋ 经验
```

这是该攻略的候选解释，未确认是否适用于全部人物和全部恢复场景；职务附加、成长量和其他文章的说法不能直接拼接。

【玩家策略】B倾向先培养少数人物，认为容貌、名分和相处经验关系恢复能力；D也偏向集中培养，并指出怀孕会影响可选择的人物。佳丽收集、恢复体力和生育因而可能产生不同的选择。[B齐家篇](https://www.xycq.org.cn/forum/thread-8693-1-1.html)、[D后宫与紫宸殿段](https://chiuinan.github.io/game/game/intro/ch/c33/emperor.htm)

### 家庭互动与生育流程

|环节|攻略可支持的内容|不据此补出的内容|
|---|---|---|
|受孕|与后宫互动有关，存在待产状态|精确年龄资格、概率与固定孕期|
|出生|攻略描述有出生通知及子女记录|同一时点所有待产者都会自动处理|
|召见子女|影响慈父评价|只要反复点击就必定无限计分|
|太后互动|影响孝道评价，需在其去世前安排|固定某年某月必定去世|
|公主和亲|家庭人物与外交产生联系|子女必能任官、封地或进入下一代可玩流程|

【单篇观察】D称下午政务安排可能影响产子处理，并描述多位待产时通过再次进出紫宸殿继续处理。这是界面与事件时机的观察，不等于产子必须由玩家在现实时间里等待。[D紫宸殿段](https://chiuinan.github.io/game/game/intro/ch/c33/emperor.htm)

【玩法归纳】本轮材料中，子女最清楚的用途是家庭评价及和亲。禅让结局提及太子，并不能单独证明存在完整继承养成系统。生育与人物年龄也让家庭安排成为有期限的选择。

### A攻略配方索引

下表仅归纳用户原文，按材料集合书写；没有证明投料先后是否影响结果，也没有补齐原文没给出的剂量。

|配方|A记载的效果|
|---|---|
|AB、EF|加当前体力，原文未写数值|
|AEG、ACF、BEH、CEF、DFG|健康、快乐各加10|
|ADFG、ACDF、ACEH、BCDH、BEGH|四项能力各加2|
|ABCEF、ABCEH、ACDFG、BDEGH、BDFGH|体力上限加30|
|ABCDEFGH|增加寿命|

出处：[A第七节](sources/user-guide-2026-10-16.txt)。这不是合并各攻略后的“标准丹方”。C、D存在不同配方和剂量，重点对照见Y07、Y08。

### 炼丹的经营位置

【攻略记载】药材来自外交贡品，青炉房提供炼制、服用、试药和弃药。由此可把流程概括为“外交获取材料—选择配方—等待或处理炼制结果—服用并观察属性”。贡药关系门槛见既有外交冲突K09。[A操作、外交及炼丹节](sources/user-guide-2026-10-16.txt)

【玩法归纳】长期收药需要维持外交来源；为了延寿而使用材料，与为了省去修习时间而提升属性，是不同的资源安排。全部吞并、长期保留保护国和追求某种结局，可能需要不同的收药时机。

### 漏洞与常规配方分开

A报告顺序服药可使其他药物继承增寿效果；B另报告孕期晋封可增加子女。这里只登记为玩家漏洞报告，不当作稳定配方或正常生育流程。其版本、保存状态、操作顺序和复现条件未齐全。[A游戏BUG节](sources/user-guide-2026-10-16.txt)、[B齐家篇](https://www.xycq.org.cn/forum/thread-8693-1-1.html)

后续若继续收集丹方，优先记录游戏版本、皇帝年龄、药名集合、炼成数量、服用前后属性和此前是否使用过漏洞。仅有“加150”或“加30”不能脱离年龄和计量口径比较。
