# 本朝终章与史官评传

2026-10-26。采用第六版局部书卷布局。七种终局原因保持不变，另新增十四种人物终评；两者独立，暴君等属于可实际达成的评价结局，不伪造为新的死因。

## 演出与入口

- 寿元已尽：宫灯长寂，寝殿暮色、灯光渐灭。
- 禅让：传玺归闲，朝堂传玺、暖光流动。
- 升仙：功成归天，帝王眺望天阙、分层流云。
- 病逝：雨歇深宫，蓝调寝殿、雨幕。
- 遇刺：惊驾成殇，风雨御辇、斜雨与光影。
- 服毒：一盏长辞，丹房酒盏、流动烟雾。
- 亡国：故国烟尘，残城落旗、烟尘与余烬。

原画来自专门生成的背景；升仙独立原画，其余六种共用分格场景图集。均使用正式组件 src/ending-cinematic.mjs，CSS 不依赖样片。文字为连续史官评传，右起竖排、逐字落墨，使用简单逗号句号；左侧局部压暗，不遮挡右侧主体。

结局经 persistCandidate 保存成功后，在提交动作收尾后自动播放。失败保存不启动演出。演出期间可以暂停、重览、直接阅全文、回卷首、横向滚动或直接进入终评；Esc 进入终评。完整文字写毕后显出帝号/史评。演出不写存档、不扣资源、不推进回合。加载旧终局不强制重播，终评提供“重观结局演出”。降低动态效果设置直接给出全文并停用动效。

## 人物评价规则

规则依优先顺序匹配，具有独立评述。以下数字是开发说明，不放入演出正文。

|评价|条件|
|---|---|
|文成圣帝|结束原因为升仙；正式升仙操作仍要求原有全部功业条件|
|商纣之鉴|本朝记录处斩至少5次、亡国、终局内政不足30；明确类比商纣王，并非把玩家改名为商纣王|
|暴君|本朝记录处斩至少3次、生活不足40、秩序不足45；不指控具体囚臣无罪|
|亡国之君|亡国，且未先命中上面两种重刑评价|
|未竟之君|在位未满十年，未先命中特殊结局；正文说明仅作阶段评价|
|文成武帝|内政至少75、版图控制至少20、智慧武术各至少400、本朝胜仗至少3次|
|中兴之主|有先朝归档且先朝内政不足45、本朝内政至少75|
|仁德之君|内政至少75、所记录本朝处斩为0、孝道育亲各至少80|
|开疆武帝|版图控制至少20、胜仗至少5次、内政至少45|
|穷兵之君|本朝交战至少10次、存在我方阵亡、内政不足45|
|昏庸之君|内政不足35且秩序不足40|
|守成之君|旧有综合评分至少60|
|功过之君|旧有综合评分至少40|
|困局之君|以上均未命中|

以上为项目文学评价规则，不宣称复原历史谥法或原版DOS结局表。商纣之鉴优先于暴君；亡国不会仅因国土为零就被称为暴君。没有处斩记录不会猜测暴虐。

## 事实与兼容

刑部实际处斩时在 dynasty.endingRecord 中增加本朝计数，与原状态一并原子保存；预览仅修改候选副本。计数不依赖最近100条刑部日志，不会因裁剪丢失。继位归零，新朝独立统计。新游戏/继位 coverage=complete，旧档迁移 coverage=partial 且从本次开始计数，评传注明缺录不臆断。

新终评保留既有 version=2、四项评分、称号和历史类比矩阵，增加可核验 assessment 快照。旧版终评可继续读取；不修改先朝归档。文中仅在已有依据时写四艺、家庭、长城皇陵和封禅，不把所有君主一律写成圣君。玩法面板、存档数据及终评仍显示实际数字，演出使用人物评述。
