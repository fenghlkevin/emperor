# 当前版新局容错复测（2026-10-21）

结论：**正常发展、一般灾害和短期财政失误已有明显余量，未复现“一次小失误就永久破产”。但中央军重创后的默认恢复流程仍偏苛刻：地方治理持续占用结余，补齐兵员也不会自动恢复训练。** 此轮保留游戏规则，只补充测试、修正审计公式并记录问题与解决方案。

采用 **118 条独立路线、64,800 次推进**的最终结果，随机种子为 1、7、41。冻结版本另有 38 项运行时契约、873 项业务回归、14 项真实桌面验收通过。路线完整执行不代表所有玩法都应该成功：长期苛税导致民乱和亏空属于预期后果。

- 国内恢复对照跳过外国战略结算，保留自然灾害等国内系统；国际组单独开启完整外国经营与战争。因此国内组的恢复时间不能直接当作持续遭到外敌进攻时的保证。

## 短期失误

| 失误 | 补救 | 三种子结果 |
| --- | --- | --- |
| 30% 税维持一年 | 恢复 20%，保留原军队 | 无新增债务、无民乱；20 年末国库 454,531～472,064 两 |
| 50% 税维持半年 | 恢复 20%，保留原军队 | 会出现暂时动乱，但没有债务死循环；最终国库 429,903～450,036 两 |
| 50% 税维持一年 | 恢复 20%，不裁军 | 曾产生债务和民乱，之后可清债；最终国库 206,220～224,954 两 |
| 新局一次购买 2,500 套刀盾兵装备 | 实付 28,314 两，仅剩 1,686 两，之后正常委任 | 三种子均未借债、断粮或民乱；10 年末仍有 109,230～138,201 两 |
| 小兵力出征失利 | 120 人真实阵亡，实际补装与补员 | 支出约 1,161～1,164 两，3 旬内补齐人数和兵装；训练仍需另外恢复 |

50% 属于极端税率，短期动乱仍应保留；本轮证明的是可以补救，并非极端加税没有后果。长期 27% / 29% 税配合反复特赦仍会引发持续动乱和亏空，与“长期苛税引起民变”的要求一致，不应继续放宽到能够长期滥用。

## 灾害容错

七类单州灾害分别测试洪涝、旱灾、山崩、疫病、失火、盗匪、民乱，每类三个种子，均继续运行 10 年。三州同期旱灾另做不额外补助与实际付费补助的对照，再补充十州同时旱灾。

| 压力场景 | 债务峰值 | 未满足供粮旬数 | 动乱旬数 | 最终国库 |
| --- | ---: | ---: | ---: | ---: |
| 七类单州灾害，共 21 条路线 | 0 | 0 | 0 | 104,912～145,823 两 |
| 三州同期旱灾，不额外拨付灾害补助 | 0 | 0 | 0 | 104,204～153,978 两 |
| 三州同期旱灾，每州实际补助一次 | 0 | 0 | 0 | 101,460～146,037 两 |
| 十州同时发生完整周期旱灾 | 0 | 0 | 0 | 133,820～148,631 两 |
| 120 人出征失利，加三州同期旱灾 | 0 | 0 | 0 | 105,273～150,421 两 |

“未额外补助”保留正常委任与应急供粮，并非完全停止治理。自然“民乱”灾害在灾期内记作灾情，表中动乱旬数专指 `status.situation === 'unrest'`，不能据此说该路线没有发生民乱事件。

三州补助实际支出约 6,973 两，缩短灾期并减轻剩余生产损失。灾害本身没有把正常经营国家推入无法恢复的状态；没有必要为了容错直接取消灾损或免费赈灾。补助对财政、民间粮食与国家库存的收益不能混为一谈，也不保证每次补助都会提高十年后的现金余额。

## 战争及战后恢复

### 真实战争与严重战损

| 路线 | 观察结果 |
| --- | --- |
| 三条完整国际局势路线，各 20 年 | 分别自动守城 3、1、4 次；最终均为 9 州，无债务和持续动乱，国库 443,427～469,282 两，无迁都 |
| 新局中央军自动编阵，AI 代操进攻南诏 | 我方 1,600 人，对方 4,480 人；三种子均败并损失全部出征兵员。仅补给花费 255～256 两，不能据此理解为战争很便宜 |
| 上述真实败战后，默认治理预算、实际补装补员 | 兵装补回约需 27,277～27,357 两，第 216～239 旬才补齐人数和库存；十年末训练仅 14～17 |
| 全国兵员、对应兵装损失 25% | 实际补回约 198,568～198,734 两，第 294～315 旬补齐；无债务、断粮或民乱，十年末国库 74,198～108,530 两 |
| 全国 25% 战损，加半年 50% 税及三州旱灾 | 生活水平最低 54，暂时动乱 33～34 旬，但无债务或未满足供粮，最终恢复；第 277～285 旬补齐人数与库存 |

AI 代操败战不是所有手动战术必败的证明。全国 25% 战损是严重压力夹具，存活的其余军队仍可使用；“恢复全部原有库存”也不等于“此前国家完全无法防御”。这些严重战损有真实代价，应保留代价，重点应改善恢复支出的顺序和说明。

### 已验证的补救对照

统一在第 19 旬损失中央军全部 1,600 人及对应装备，保留 7,000 两治理保留线，不增加任何资金，也不降低兵装价格。

| 恢复方式 | 补齐兵员、库存 | 中央训练达到原有 60 | 说明 |
| --- | --- | --- | --- |
| 默认治理预算 1,400，只补员补装 | 第 218～244 旬 | 十年内未自动恢复，最终仅 15～17 | 人数恢复不能代表战力恢复 |
| 默认治理预算 1,400，补齐后付费训练 | 第 218～244 旬 | 第 223～249 旬 | 训练额外实付 320 两 |
| 暂调治理预算至 350，补齐后付费训练，再恢复预算 1,400 | 第 36～40 旬 | 第 41～45 旬 | 补员补装实付 29,430～29,963 两，训练 320 两，三种子均无债务、断粮或动乱 |

从受损时点计算，默认流程需要约 **5.7～6.4 年**才能恢复训练；重新分配预算后约 **7～9 个月**。后者是已有规则下实际执行成功的方案，表明当前主要问题是默认恢复优先级，而非必须给玩家免费复活军队。国库保留线约束治理和本轮主动采购，不承诺阻止灾损扣款，个别路线现金会短暂低于 7,000 两。

## 剩余问题与解决方案

### T01 / P1：战后恢复与自动建设争抢结余

**证据：** 同样的中央军全损，预算切换把完整恢复时间从第 223～249 旬缩短到第 41～45 旬。默认流程虽然没有永久破产，恢复空档对不熟悉全国治理预算的新玩家仍然过长。真实出征败战也复现了相近的长恢复期。

**方案：** 在战报中提供“优先恢复军备”的既有确认页操作。经玩家选择后，在有粮、能支付常规开支的前提下，暂时将可选地方发展预算限制在约 350 两，把剩余结余用于有总额上限的补员、补装和训练；达到目标或玩家取消后恢复原预算。继续实际支付全部银粮、使用真实劳力，不自动举债、不冻结必须的救济。可先针对中央军低于战前 50% 的重创触发提示，避免每场轻微损失都打断发展。

**验收：** 使用本报告三种子，在同样全损夹具下仍保留 7,000 两治理保留线，恢复中央军人数、必要装备与训练的目标为一年以内；正常发展与救灾路线不得因此缺粮或增加债务。350 两只验证了本轮中央军全损情形，不能未经复测直接推广成所有战争的固定最优预算。

### T02 / P2：补齐人数后缺少训练恢复引导

**证据：** 中央军全损会停止长期训练；重新征兵后训练为 15～17，即使十年末国库充足也不会自行达到原来的 60。额外 320 两、5 次实际训练即可恢复，因此难点主要是玩家是否发现还要重新训练。

**方案：** 战报与军备恢复页同时显示“兵员 / 可用装备 / 训练”三项进度，补员完成后明确呈现训练差额、一次训练价格以及长期训练开关；让玩家在恢复计划中选择是否继续训练。训练计划可记录玩家原有意愿，在重新有兵时提示恢复，不能把人数补满标作战力已恢复。

**验收：** 零兵停止、重新征兵和训练衰减的费用、上限规则保留；恢复计划明确标记未达训练目标的部队。本轮中央军全损场景实付训练后可在 5 旬达到原目标。

### T03 / P2：低补给报价容易遮蔽一次重大战败的重置成本

**证据：** 当前出征确认页有敌方本地兵籍、训练、留营和主将退场规则，但主要风险说明是通用文字。本轮自动编阵 1,600 对 4,480，补给报价只有 255～256 两，实际败战后的补员补装约 2.7 万两。新玩家容易低估“点一次出征”的损失上限。

**方案：** 在现有出征核阅页加入显著的敌我实际兵力与训练对比、中央预备队、全损后按当前价格估算的补员补装费用，兵力明显不足时显示明确风险提示。将领、兵种、地形仍影响结果，不给虚假的确定胜率，也不禁止玩家挑战。使用既有户部风格配图和固定分页布局，不增加滚动区。

**验收：** 上述 1,600 对 4,480 的场景必须在落印前清楚体现约 36% 的兵力比例与潜在重建费用；装备和劳力不足时明确列出缺口，重复预览不得扣钱或耗费体力。

## 测试执行与限制

- 本轮修正了旧审计探针的静态税压平衡系数：当前规则应为 `18 / 0.08 = 225`，旧脚本仍使用 300。只修正检查工具，未修改游戏税压规则。
- 初版战损测试只用空闲人口征兵，部分路线遇到正常的“可征平民不足”报价拒绝后提前停止。已保留原始诊断，改为合法授权产业抽调并重跑全部军事路线。最终采用的 118 条路线全部完成，拒绝后未完成的尝试不纳入路线数和推进数，也不当作游戏崩溃。
- 物资和财政边界、旧档不重置、官职效果映射、建筑与产业劳力、治理预算、真实采购、灾害生产和兵装损失等仍由业务回归与 15 组补充探针、13 组边界探针复核。额外零农牧劳力、零存粮的长期饥荒夹具不属于正常灾害概率，也未纳入 64,800 次路线推进。
- 桌面 14 项覆盖新局、政令实付、存档重载、扩城管理、训练限次，以及 1440×1000、900×680 下的配图、统一样式和无滚动布局；不代表逐个验收了全部游戏页面。
- 当前工作区补跑全量回归为 874 项：873 通过，1 项因并行新增的“悠悠”初遇图片当时尚不存在而失败。图片随后已经到位；对资源使用、巡游人物、巡游事件三个测试文件重新执行，31 项全部通过。未替换或跳过该断言，本轮也未修改人物素材。不能将这次初始全量运行记作 874/874 通过。
- 数值复验已完成；T01～T03 是仍需实现的改善项。本轮没有把建议当作已上线修复，也没有为凑“全部通过”而修改游戏难度。
