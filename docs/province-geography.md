# 州县地理归类

2026-10-19。覆盖当前43个州县及外国腹地，统一配置于 `src/province-geography.mjs`。使用现有平原、河海、丘陵、高山四类，不新增沙漠或草原类别。

归类是结合本剧本区域范围、代表腹地及主要地貌作出的游戏近似，不按首府一点代替整个区域，不声称复原古代疆界。河海型用于河网低地、河口和沿海港埠腹地；岛屿并不自动归为河海型，日本、爪哇、吕宋按多山地貌归为高山。低起伏高原及山前盆地有时归入丘陵型；相关说明明确标识草原、荒漠等未单独建模的性质。平原分类也不意味着湿润或肥沃。

初始化总人口、各职业人数及75%劳动力比例不变。新局采用调整后的地形，按现有地形经济表建立初始用地、上限与特色加成。地图、州县详情、工部、户部、灾害及新生成战场统一读取州县的 `terrain`。正在进行的旧战役保留自己的战场快照，不追溯重绘。

## 旧档迁移

新增 `domestic.geographyVersion:1`。缺少该标记的旧档先校验已有地形经济快照，再更新州县归类。发生地形变化时，保留原城市土地、已开发面积、已付费在建项目、人口、用工基准、钱粮及实际历史流水。仅更新地形与未来适用的地形容量记录，既有面积和在建承诺作为保留底线，不裁减、不退款、不重收建设费用。旧的超限产业不能突破保留上限；土地已达到保留后的最终上限时不能继续扩城。读档不会重复放大保留量。

已有正确地理版本的档案不再重新分类；非法版本、配置不一致、损坏的旧快照会拒绝载入。省份被占领或改属后仍按原省份ID保持地形。未来再次修改归类需配套新版本迁移，不依赖所属国家推断。

## 资料与近似边界

- [美国国会图书馆国家研究：中国地理](https://countrystudies.us/china/32.htm)：核对中国地形、流域与高原山系的大范围关系。
- [国家地理：亚洲自然地理](https://education.nationalgeographic.org/resource/asia/)：核对亚洲高原、山地、草原、荒漠与河流区域。
- [CIA World Factbook 地形列表（MIT镜像）](https://start.csail.mit.edu/mirror/cia.gov/library/publications/the-world-factbook/fields/2125.html?countryCode=&countryName=&regionCode=)：交叉核对现代地区的主要自然地貌，仅作为地形背景，不将现代国界当作剧本疆界。
- [日本国土交通省：日本国土与气候](https://www.mlit.go.jp/river/basic_info/english/land.html)：核对日本列岛以山地为主的地貌。
- [UNESCO：阿克苏姆](https://whc.unesco.org/en/list/15)：核对其位于埃塞俄比亚北部高地。
- [CIA 柬埔寨地理档案](https://www.cia.gov/readingroom/docs/CIA%20THE%20WORLD%20FACTBOOK%2020%5B16170477%5D.pdf)：交叉核对湄公河低地与周缘山地关系。

四类地形无法完整表示干旱、纬度、土壤、海拔与混合地貌。本次只调整归类及说明，土地比例、四业比例和加成数值仍沿用[地形经济规则](terrain-economy.md)，不额外添加气候或资源系统。
