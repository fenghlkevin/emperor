# 内政数据结构与当前规则

统一约定见[数据字典](data-dictionary.md)、[存档版本兼容](save-compatibility.md)和[旬结算顺序](turn-settlement.md)。本文侧重内政字段和报表口径。

目标：户部侍郎查看国家内政，由欧亚国家、全国汇总下钻到城州。所有页面引用同一份存档数据，不为各表复制独立数字。已有宫廷入口继续工作，侧栏“内政”提供快捷入口。

## 存档层级

`GameSave(version:2)` → `domestic(schemaVersion:8)` → `countries[] / provinces[]`。

类型定义：`src/game-types.d.ts`。创建、校验、汇总、结算：`src/domestic.mjs`。界面：`src/domestic-ui.mjs`。地理数据与玩法数据分开，地图坐标在固定剧本定义中，进度只保存指标及归属。

存档保留键 `emperor.save.v1`，但仅接受内容 version 2、内政 schemaVersion 8 和有效九兵种套装军备；不再支持 version 1 或 schema 1–7 自动升级。当前版本内可按各模块初始化器补齐支持的缺失字段，不能据此推断任意旧档都兼容。`stats.treasury / prestige` 为界面镜像，载入及结算以本国财政和皇威为准，不是第二套账本。旧起居注字段仅兼容保留。

## 基本字段

| 实体 | 属性 | 单位与约束 |
| --- | --- | --- |
| 国家 | id、name、capital、provinceIds、relations | 稳定 ID；领土引用州 ID；relations 为旧显示兼容值 self/neutral/ally/hostile；当前协议以 diplomacy 为准 |
| 国家 | prestige | 皇威，0–500 |
| 国家财政 | treasury、debt | 国库银两、国债，两；非负整数 |
| 国家财政 | taxRate、otherIncome、centralExpenses | 税率 0–1；其他收入和中央九类支出均为两/旬 |
| 州 | id、countryId、name、terrain、area | 唯一 ID；国家归属；平原/河海/高山/丘陵；总土地/亩 |
| 州人口 | total、professions | 人；职业人口合计不能超过总人口 |
| 职业 | farmers、herders、merchants、workers、soldiers、militia | 农人、牧人、商人、工人、士兵、民伕；其他居民由总人口减去职业人口得到 |
| 四类产业 | developedArea、capacityArea、productivity | 农业、牧业、商业、工业；开发面积/亩，可开发容量/亩，生产率/0–100 |
| 民生 | stability、security、activity、fitness、defense、loyalty | 安定、治安、营业、体能、防御、民忠，均 0–100 |
| 民生 | grainReserve | 实物存粮/石，非负；积粮值和可供旬数从存粮派生 |
| 州况 | situation、livingStandard、cash | 情势 stable/unrest/disaster/war；生活水平/0–100；地方经济现金/两，可为负 |
| 军事 | military.training、troopKits.depots | 训练0–100；九兵种装备按驻地保存人份库存与占用；无 equipment/arsenal 散件账本 |
| 建设 | temples、markets、palaces、yamen、granaries、walls、trainingGrounds | 寺庙、市集、行宫、衙门、义仓、城墙、校场数量；非负整数 |
| 州预算 | taxRate、otherIncome、expenses | 州税率0–1；其他收入、九类基础支出，两/旬；查询时叠加动态费用 |
| 现金账本（含当前旬） | turn、income、expenditure、net、closingTreasury、closingDebt | 一旬一行，保留最近 36 旬；旬序严格递减；收支守恒 |

行政开销、官吏薪俸、士兵薪俸、民伕薪俸、爵位俸禄、武装购买、建设费用、维护费用、其他支出，均单独保存和显示。全国建设数、人口、职业人口、军力、面积和存粮按所属州相加；0–100 民生值与生活水平按人口加权平均，不简单平均。

产业开发面积当前统一使用等效经营用地亩数：农业为农田、牧业为牧地、商业为交通与经营用地、工业为矿工用地。四种产量单位不同，禁止直接相加。

## 派生与结算

- 开发率 = developedArea / capacityArea。
- 每旬产量 = 四舍五入(职业人口 × 行业基础系数 × 开发率 × 生产率 / 100)。农业系数 0.075 石；牧业 0.012 头；商业 0.16 两；工业 0.09 件。
- 商业产量在基础公式上叠加营业增长与已生效特殊商业加成；开发面积按 productiveArea(p,key,turn) 排除尚未启用部分。
- 州税收 = 四舍五入((农业产量 × 0.7 + 牧业产量 × 4 + 商业产量 + 工业产量 × 0.8) × 州税率 × 情势系数 × 治安系数)。民乱系数为0.65，其他为1；治安系数为 `1−max(0,40−治安)/100`。
- 全国收入 = 所属州税收 + 所属州其他收入 + 中央其他收入 + 本国户部主官能力修正。没有领土的国家不收中央经常收入、不做常规结算。
- 全国支出 = 所属州动态费用 + 有领土时的中央基础费用 + 动态军需/行政/建筑维护；本国另计官阶爵位俸禄与户部清廉损耗。具体公式见[长期玩法](longterm-development.md)与 countrySummary；当前预算预测不等于实际现金流水。
- 跨旬统一执行常规财政与粮食结算，浏览报表不推进旬序。同一旬重复调用内政结算不会重复记账；命令型动作在确认提交时即时入账。
- 允许欠款的强制付款在国库不足时国库置零，差额累计国债；普通消费不足会拒绝。债务暂不自动偿还、暂不计利息。
- 每旬粮食消耗 = 四舍五入(人口 × 0.005) 石。存粮加农业产量、减消耗；缺粮时存粮置零，安定下降 2、民忠下降 1。安定低于 30 转为动荡。
- 积粮值 = min(100, 四舍五入(存粮 / 12旬口粮 × 100))。实际石数和可供旬数同时显示。
- 地方现金与国库不是同一概念；当前国库统一收付预算，地方居民现金先作为独立经济指标，不重复参与国库结算。

查看和轻量结算已接入任命、政策、征税、统一征兵、建设、交易、人口流动与事件等功能。

## 地图与剧本

天下舆图限定为参考图中的欧亚区域，西至罗马，东至日本；不再显示美洲、澳洲等整个地球范围。水墨山川底图、书法地名、轻量疆界与纸卷式文字详情组成界面。地名与指标是实际可交互内容，不写死在图片中。可拖动、滚轮或按钮缩放、键盘 Enter/Space 选择区域。首次点击本国区域查看国家信息，进入十州后点州查看详情；右侧可收卷恢复完整地图。

初始虚构国号为“大晟”，首都长安，初始只拥有参考图红色的十个城州：河北、河南、淮南、江南、岭南、河东、关内、山南、剑南、陇右。

其余33个具名地区为独立国家，各有国家ID、初始核心州、人口、财政和独立现金账本；全图共43州。确切列表由 `domestic.mjs::REALMS` 定义。原“北庭”已命名为“铁勒”。这些是当前剧本种子数据；疆界为策略示意，不用于精确历史地理。旧schema补国迁移已停止支持，不能把历史迁移步骤当作当前导入功能。

水墨背景来自内置 ImageGen，保存为 `assets/sketch-ink-eurasia.png`，完整提示词见 `docs/ink-map-art.json`。地图拓扑与点击地名由程序叠加；图片内容不充当指令。

大陆轮廓来源：[Natural Earth 1:110m Land](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson)，公共领域，离线存放于 `src/world-land.mjs`，应用运行不联网获取地图。

## 兵部侍郎 · 军事统计

朝堂 `war-deputy` 打开军事统计，按中央和各州展示兵员、训练及九兵种套装总量、占用和可用量。地图与总表可查询本国和外国驻地，查询不产生资源变动。

`centralArmy` 只记录来源州、兵员与训练，中央兵员是来源州军籍的分列部署；全国兵员始终等于人口职业中的士兵合计。`troopKits.depots` 是唯一装备账本，库存按人份计量。训练按真实兵员加权；无兵时为0。详情见[军制规则](troop-kit-rules.md)。

验证：`npm test`、`npm run test:kit-routing`、`npm run test:kit-office`。

## 工部侍郎 · 建物与民生统计

朝堂 `works-deputy` 打开工部统计，沿用水墨界面，包含建物统计表、特殊建物表、民生细查。

- 建物表按寺庙、衙门、校场、市集、义仓、城墙、行宫列出十州实有数及全国合计，直接使用原有 `province.buildings`，与户部全国建设统计一致。点击州名可下钻。
- `province.specialBuildings` 登记特殊建物 `{id,name,description,count}`。同州 ID 不得重复、数量必须为正整数，名称和说明长度受校验；按所在国家和州汇总，空表显示“尚无特殊建物”。初始无记录，不虚构特殊设施。
- 地图民生细查显示人口、地形、土地、民忠，以及安定、治安、体能、营业、积粮、防御六项指标和七类建物。积粮值沿用户部 `grainSecurity` 计算。
- 州详情可切换“民生与建物”“经济与开发”，后者分别列出四产业的职业人数、开发面积、开发率及每旬产量，复用户部计算函数和单位，不相加不同产业产量。
- 统计为只读查询，不新增建设、拆除或经济操作。当前导入只支持schema 8，不执行schema 4到5的历史迁移。
- `src/works.mjs` 负责统计，`src/works-ui.mjs` 负责报告，地图交互由 `src/domestic-ui.mjs` 共用。`npm run test:works` 验证三类报表、地图/键盘选州、经济换页、特殊建物登记重载、回合、邻邦及兵户部回归、小窗口布局。

## 吏部官职表与朝班

`src/personnel.mjs` 统一定义 13 个中央职位，官职表从中央将军至宰相排列；不添加参考图中的任职人员。职位定义与任职人员分开；姓名、年龄、能力、清廉、忠诚和经验从实际在职官员读取，空缺职位显示“—”或署理。各州刺史、将军根据本国国家 provinceIds 和当前州名动态生成，不存重复职位表；初始 10 州共 20 个地方职位。

朝堂仅显示中央职位。按用户座次图，由后至前：左列工部侍郎/尚书、兵部侍郎/尚书、户部侍郎/尚书、宰相；右列刑部尚书、礼部尚书/侍郎、吏部尚书/侍郎、中央将军。独立召见名册与人物区域共用注册表，姓名不贴在身上；朝堂图片维持原始比例。地方刺史、将军不进入朝堂名册。

## 礼部外交与贸易

参考截图标示礼部，故外交/贸易接入 `rites-deputy`；`personnel-deputy` 保持吏部官职表。`src/diplomacy.mjs` 定义国家对关系，`src/diplomacy-ui.mjs` 展示外交总表、贸易总表和全图外交细查。

- `domestic.diplomacy[]` 每两个国家一条记录：`countryIds` 为按 ID 排序的两个不同国家，`relation` 为 none/ally/hostile/nonaggression/defense/protector/protected，`friendship` 为 0–100 整数，`trade` 为 `{years,quota,income}`，分别表示贸易年数、约定额度（两）、累计贸易收入（两）。贸易数值均为非负安全整数。
- 双向查询返回同一记录，避免 A→B 和 B→A 两份状态互相矛盾。34 国完整记录为 561 对，本国总表列 33 个邻邦，人口和土地从现有州数据汇总。
- 新记录关系“无”，友善度 50，贸易三个值均 0；不复制参考图中的示例国家人口或关系数值。当前不支持schema 5迁移到6。原 `Country.relations` 只作为旧存档兼容字段，外交表以新国家对记录为准。
- 报表本身只查询；礼部动作可签约、贸易、和亲、贡赋，外国战略可发动战役。跨旬结算贸易与年度贡银，并按实际支付写入财政流水；不把累计收入再次入账。

## 地图共同显示

户、兵、工、礼部地图首次进入均使用完整 `CAMPAIGN_VIEW` 且不预选国家，兵工礼默认打开地图细查，总表通过页签进入。国家分区使用整体可逆剪切场细化共享边与交点，补充国家也参与同一分区；本国使用持续淡金填色和去除内部州界后的独立国界线，选择邻邦不取消本国标识。底图海岸裁剪保持不变。

### 刑部尚书

刑部提供调查经费、特赦、天牢。兼容范围内缺少刑部记录时补建官员名册，不重置已有国库或地方数据。姓名、忠诚与吏部侍郎表同步。调查经费为0时停止密查，1–10,000两时确认立即扣费并调查，此后每旬同额扣费，国库不足自动停止。忠诚严格低于40%的官员可被查实，支持收押或二次确认处斩。收押撤职并进入天牢，可处斩或释放为民。

地方官忠诚低于40%，每旬按（40－忠诚）%概率酝酿叛乱，下一旬独立；密查发现后留出一整旬裁决，继续忽略仍会独立。独立转移实际州归属、人口、军队及地方经济，新增国家和外交关系，双方敌对；京城为最后据点，其官员谋反失败逃亡。中央官无地方独立能力。

特赦每旬一次，各本国州人口增加0.5%（向下取整、至少1人），新增为未从业人口，治安减5且不低于0；囚臣需单独释放。刑部记录保存最近100条，所有政令保存成功后才更新界面。

### 天牢性格与忠诚

官员新增 `personality` 枚举，规则集中定义于 `PRISON_PERSONALITIES`：`repentant`（悔过）每旬+3，上限80；`fearful`（畏威）每旬+1，上限60；`staunch`（刚烈）每旬−1；`resentful`（怨恨）每旬−3，负向均以0为下限。正向性格只停止增长，不将原本高于上限的忠诚压低。另有 `steadfast`（坚贞）与 `composed`（沉静）每旬不变，`pragmatic`（权变）每旬+1、上限70。默认性格按官员ID稳定分配；历史人物可按性格模板版本同步，读取时不随机重抽。

`prison: PrisonRecord | null` 保存本次入狱的 `admittedTurn`、`lastSettledTurn`、`servedTurns`、`lastDelta`、`totalDelta`、`lastReason`。收押当旬不改变忠诚，结束本旬进入下一旬时开始结算；全局旬序与个人最近结算旬序共同防止重复执行。仅 `imprisoned` 参与，释放、处斩后保留最终记录并停止变化，忠诚恢复不自动出狱或复职。天牢展示性格、服刑旬数、最近/累计变化、原因和下旬预计值，纪事保留逐旬变化。

旧档仅对缺失字段补值：在押人员以 `max(1, justice.lastTurn)` 作为记录起点，历史服刑旬数从0开始，不追溯调整忠诚。显式无效性格或关押记录由存档校验拒绝。

### 全图边界复核（2026-10-16）

逐一复核34国与本国十州。`painted-realms.mjs` 将日本、吕宋、僧伽罗及南洋群岛从大陆自动分区中独立出来，并按原画像素指定高丽与天竺的覆盖范围；后续区域优先覆盖，合并裁切片段后绘制，消除同国内部伪边界。补绘高丽半岛与斯里兰卡的海岸裁剪。所有外国地名定位在本国陆地上，内政与出征地图共享多轮廓路径。

## 平衡规则1（2026-10-17）

本国新局中央其他收入400两/旬。新增繁荣公共服务费，按`round(Σ各州 人口×0.0013×max(0,生活−50)/100)`计入行政支出；预算和实际常规结算共用同一口径。商业营业增益除以600、封顶10%。粮食在灾后期初先扣超安全库存8%的陈粮损耗，再计当旬生产与口粮；详见[粮食救济](food-relief.md)。旧档既有钱粮和其他收入不重置。
