# 战斗卡牌属性规则与推演（2026-10-26）

本次让普通兵、精锐兵、人物牌都受兵力、训练和将领影响。人物固定模板、专属技能与配牌机制保留，开战攻命额外乘属性倍率，最后四舍五入，最低1。旧战斗根据原规则快照继续进行，新战斗使用属性规则v1。

## 规则

- 单张兵力倍率：`(0.6 + 0.4 × min(人数,100)/100) × min(1,人数/25)`。100人为100%，75人为90%，25人为70%；低于25人进一步折减。增兵仍影响部队牌数量与预备兵，卡牌满编后额外兵力不无限叠加单卡攻击。
- 训练以60为基准，每点改变攻击0.4%、生命0.6%。训练30为88%攻击、82%生命；训练90为112%攻击、118%生命。
- 带队攻击能力：近战按武力80%＋智力20%，弓兵、弩兵、弓骑按武力40%＋智力60%。以60为基准，每点改变攻击0.3%。
- 带队统率：以60为基准，每点改变生命0.4%。
- 主将统率：以60为基准，每点改变全军攻击和生命0.4%，35为90%，90为112%。主将原有技能仍由武力、智力、统率中的最高项决定。
- 新公式替代旧的精锐／人物不足75人减生命与训练门槛，避免两套惩罚重复叠加。战斗状态增减仍在锁定攻命基础上计算；受伤不降低攻击，治疗不复活实际阵亡兵员。
- 人物模板原有的能力门槛继续生效；本公式对普通兵牌和历史人物牌也生效。属性小幅变化可能尚未越过整数门槛，详情显示未取整值。

## 推演方法

运行 `node scripts/simulate-card-attributes.mjs --pairs=80`。使用生产战斗AI、真实战损与存档校验，不以简化公式代替对局。11种条件×新旧规则×80组种子×两种先后手，共3520场；每场起终均验证战斗状态。固定人物模板、主将技能、配牌及抽牌种子，单独变化数值能力，避免更换人物模板或技能混淆结果。基准为双方带队三项能力60、主将统率60、训练60、混编1800人（亲卫另计）；不同兵力场景会自然改变牌组。

| 我方条件（敌方基准不变） | 旧规则胜率 | 新规则胜率 | 新规则95%区间 |
|---|---:|---:|---:|
| 同条件对照 | 52.5% | 52.5% | 45.3%–59.7% |
| 训练30 对 60 | 43.1% | 22.5% | 16.2%–28.8% |
| 训练90 对 60 | 62.5% | 77.5% | 70.3%–84.7% |
| 带队能力35 对 60 | 52.5% | 46.9% | 39.4%–54.3% |
| 带队能力90 对 60 | 52.5% | 62.5% | 55.4%–69.6% |
| 主将统率35 对 60 | 52.5% | 50.0% | 42.0%–58.0% |
| 主将统率90 对 60 | 52.5% | 61.3% | 53.5%–69.0% |
| 兵力1200 对 1800 | 37.5% | 24.4% | 17.9%–30.9% |
| 兵力600 对 1800 | 26.2% | 0.0% | 0.0%–0.0% |
| 兵力3600 对 1800 | 70.0% | 70.0% | 62.9%–77.1% |
| 600精兵良将 对 1800普通军 | 41.2% | 44.4% | 36.2%–52.6% |

训练优势最显著，优秀带队将领与主将统率也产生独立增益。1200对1800的劣势比旧版更明显；600普通兵对1800普通兵160场无胜，不能把样本中的0%理解为理论绝无胜算。600训练90、带队能力90、主将统率90对1800基准军仍有44.4%胜率，说明精兵良将可以弥补部分数量差。3600人仍通过原有牌量与预备兵机制获益。

同条件基准胜率52.5%，新旧一致；先手胜率60%，同样新旧一致，本次没有消除既有先手优势。区间按成对得分的均值标准误估算；零胜率时区间退化，不能据此判定真实概率为零。这是固定AI、混编、无额外武器／奥秘／地标的比较，不能推广为所有配牌的保证胜率。完整逐场景汇总见 `card-battle-attributes-simulation.json`。

## 界面

战斗卡牌详情显示基础攻命→本场攻命和兵力、训练、带队武将摘要；展开“倍率与计算过程”可查看兵力倍率、武力／智力权重、带队统率、主将统率、未取整值与最终整数。战前牌组、本场牌组也能逐卡展开。当前状态与技能修正仍单列，开战加成不受沉默移除。旧版战斗明确标记原规则快照。

## 验证

属性单调性、整数门槛、射手智力权重、实际攻命与说明一致、只读预览、存档往返和旧版战斗继续进行均有回归覆盖；另运行卡牌战斗回归、类型契约与Electron详情窗口验收。验证结果：220项卡牌单元／集成测试通过；52份运行时类型快照与负向类型检查通过；Electron卡牌详情16项检查和战前／本场牌组4项检查通过。视觉截图见 `screenshots/card-battle-attributes-inspect.png` 与 `screenshots/card-battle-attributes-calculation.png`。
