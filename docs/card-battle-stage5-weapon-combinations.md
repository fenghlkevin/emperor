# 武器组合、代价与反制

2026-10-23，正式规则4、武器定义1／AI1。下表是功能与规则说明，不报告胜率；最终阶段一针对最终卡表补齐跨阵容、人物、训练、兵力和先后手47%至53%逐组目标。

| 组合或边界 | 实际收益与代价 | 反制与已验证行为 |
|---|---|---|
| 武器解护卫 | 主将可直接消耗自身生命处理护卫；每次有效攻击耗1耐 | 护卫仍先处理，高攻部队即使阵亡仍同时反击，主将可能死亡 |
| 武器＋治疗 | 整军鼓舞2军令恢复5命，最多30 | 原亲卫阵亡不回退，军令不足不能施放；11步教学实际27→30但保留伤亡 |
| 主将护甲＋武器 | 既有护甲先吸收实际反击 | 护甲耗尽后仍伤主将；原武器模型已覆盖4反击／3护甲→损1命 |
| 牵制敌军＋武器 | 冻结阻止敌部队主动攻击，并正常抽牌 | 冻结不取消同时反击、不移除护卫；新增组合检查先冻结后打护卫仍损3命 |
| 扰乱军令＋武器 | 2军令沉默移除可移除护卫，再可攻击主将 | 沉默要真实目标和费用；敌方未被消灭，后续仍可能攻击 |
| 护甲盾对抗武器 | 盾挡一次伤害 | 攻击次数与1耐仍正常消费；原武器模型已覆盖耗尽与跨回合 |
| 奋勇进击等部队强化 | 保留部队原有增益规则 | 装备不属于部队，不能把单位临时强化施加到武器上；非法目标世界与军令均不变 |
| 同回合换装 | 可换攻击更高的新武器 | 剩余耐久旧装仍毁损、花新军令；已攻击标志不刷新，不能无限连击 |
| 历史人物遗计抽牌＋反击 | 使用真实历史卡定义的死亡抽牌顺序 | 空牌库遗计可致疲劳；新增引擎夹具中主将被同时反击致死，敌方遗计疲劳也致死，正式结果为和局，两侧装备弃装 |
| 满10张手牌爆武器 | 正常按当前牌库顺序抽牌并爆牌 | 该牌进入弃牌区，但绑定备用套装没有损坏；战后归还，不凭区位虚构实物损耗 |
| 武器未抽到／未使用 | 未产生战斗收益 | 仍占用开战领出的真实备用装，阻止二次出征借用；战后未坏释放，不强抽补偿 |
| 满7支部队 | 武器占独立主将槽，30张名额仍从计策扣 | 不增加第8支部队，不复制人物、训练、兵员或装备 |

功能证据分别来自既有武器正式引擎／出征UI／守城来源验收，以及新增 `tests/card-battle-weapon-combinations.test.mjs` 和武器教学。遗计双主将死亡使用隔离正式引擎夹具和真实人物卡定义，明确不充当真实朝廷经济／平衡样本；出征与守城库存守恒由其真实世界测试独立验证。

连续操作、快速与减少动态效果通过隐藏原生交互验收；人物、驻地、兵员、训练与备用整套始终按正式快照关联。声音按用户要求暂缓，存档兼容不在当前交付约束内。
