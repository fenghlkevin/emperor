# 历史人物性格与天牢

2481 人均有固定性格、性格词、设计依据及史料链接，不以随机数或清廉分数决定性格。性格与善恶评价、对玩家的忠诚分别处理。

现有资料支持 74 人个案设计、399 人按本人记载设计；2008 人性情资料不足，明确标注保守设计，默认沉静自守，不凭空推定悔过或怨恨。性格词为游戏解释，并非史书原文引语。天牢反应也是玩法推演，不意味着历史人物必然效忠虚构皇帝。

|反应|每旬忠诚变化|界限|
|---|---:|---|
|悔过|+3|最高80|
|畏威|+1|最高60|
|刚烈|-1|最低0|
|怨恨|-3|最低0|
|坚贞|0|保持当前忠诚|
|沉静|0|保持当前忠诚|
|权变|+1|最高70|

高于增长上限的忠诚不强制降低。收押次旬开始，每旬结算一次；释放或处斩后停止。已有历史人物按稳定人物 ID 更新性格，保留忠诚、入狱时间及已服刑记录，不补算往期。

人物详情展示性格与囚禁反应；天牢显示性格词、可展开的设计依据及下旬预计变化。

生成顺序：

```sh
node scripts/design-personnel-personalities.mjs
node scripts/rebuild-historical-profiles.mjs
```

性格设计卡在 `src/historical-personalities.json`，史事证据在 `src/historical-evidence.json`。补充可靠资料时优先修订设计脚本的个案与匹配规则，再重建数据。
