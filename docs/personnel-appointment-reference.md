## 原版证据

- `reverse/emperor/code-analysis/tables/referenced_strings.json:6181` 起依次出现「哪個職務要做調動？」、「由誰來擔任%s,職務呢？」、「由%s,擔任%s,。」以及「請繼續選擇要調動的職務或離開。」
- `reverse/emperor/code-analysis/KING/object1.relocated.asm:58908` 附近，`0x3F998..0x3F9A8` 构造 `0x70414` 专用选人控件；`0x3FB3A..0x3FC26` 保存职位并提示选择人选。
- 同文件 `0x70DE8` 构造15个可视槽；`0x71797..0x717C8` 计算人数除以15并向上取整；`0x7291A` 使用 `page * 15` 定位。这支持“独立名册，每页15人”的结论。
- `0x71833` 起逐人绘制，`0x719BD / 0x71A26 / 0x71A8F / 0x71AF8` 读取人物 `+0xC / +0xE / +0x10 / +0x12` 数值。字段对照见 `reverse/emperor/code-analysis/io/load_officials.mapping.json:28` 与 `reverse/emperor/save-analysis/README.md:37`，支持并列比较智慧、武力、清廉、忠诚。

没有发现原版搜索、属性排序的确证，不能将这些功能归于原版。

## 本次实现

- 先选职位，再打开独立的选任名册；每页15人，并列显示现职与八项实际属性。
- 加入姓名/现职实时搜索、待命/在任筛选和属性降序排列，作为本次易用性改进。
- 不再默认替用户选中首个人选。选人和取消选人均不提交政令；选好后仍需拟令与确认。
- 六页仅正文区域纵向滚动，取消表格、人物卡片、详情栏的高度上限及纵向滚动。选人模态窗口只保留其正文的一层纵向滚动；窄屏表格可以横向滚动。
- `personnel-actions.mjs` 中的政令、费用、忠诚、制举、委任及存档规则未改。
