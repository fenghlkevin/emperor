# 第一阶段卡牌平衡推演

> 历史记录提示：本文件保留当时的设计与检查结论；本次实现以[生产版设计](card-battle-release-design.md)、[平衡复核](card-battle-release-balance.md)与[原型对照](card-battle-ui-comparison.html)为准。

日期：2026年10月22日  
对象：第一阶段v4设计卡表，炉石式完整回合。状态：完整卡表已交付，训练与部分兵力收益得到改善；先后手与时长尚未全部通过，数值不能直接冻结进入开发。

## 1. 结论

100名开放人物、29种部队模板、12种计策、36个随机人物模板已列齐。当前可以审阅每张卡的费用、攻命和技能；不能把“卡表完整”当作“平衡已通过”。本轮没有修改游戏运行时代码。

最终候选进行了78200局统计模拟，另有身份重放、状态守恒、随机人物固定性与边界检查。全部统计来自独立设计模型，不是正式游戏、人类玩家或最优AI胜率。旧v3校准数据与先前同步／交替方案不混入本轮统计。

## 2. 受测范围与方法

| 项目 | 条件与样本 | 统计局数 |
|---|---|---:|
| 主矩阵 | 8军阵×训练20／60／90×3主将；每组300个种子对，换先后手 | 43200 |
| 全部人物镜像 | 100人，每人50个种子对，双方同一人物卡与两名相同通用统领 | 10000 |
| 人物技能消融 | 同费、同身体，比较完整技能与移除关键词／战吼／亡语的同名替身；每人50个种子对 | 10000 |
| 训练与兵力 | 9组90对60训练，6组兵力梯度；每组200个种子对 | 6000 |
| 独立种子与进攻倾向 | 3个关键条件×3种倾向，每组500个种子对 | 9000 |
| 合计 | 不含结构和诊断重放 | 78200 |

同一对种子中，军队A／B各自的牌序归属保持不变，再交换先后手。双方使用相同启发式决策器，只读公开场面及自己的手牌、牌库数量与已知组成，不读取敌方隐藏手牌或未来顺序。进攻、默认与交换倾向仅改变同一决策器的进攻权重，不是三套独立最优搜索。

通用统领采用专有池60～74档的三种0号变体，测试已核对费用、身体、关键词与效果一致。人物专题使用其实际专属定义，100人都在镜像样本中有真实部署记录。每人轮换搭配一种主将风格，不能据此声称覆盖了100人任意组合或全部主将搭配。

主矩阵为齐装标准100人分队、无城防。模型包含30张牌库、3／4起手与调兵令、首回合抽牌、费用、护卫、突袭、反骑、破盾、圣盾、潜行、战吼、亡语、强化、沉默、冻结、护甲、治疗、空牌疲劳、人物额度、预备兵与损失峰值记账。军队多来源合并、真实国家人物生命周期、文化池完整素材、存档迁移和实际UI不在本轮生产级验收范围。

## 4. 先后手仍未全部通过

## 5. 训练收益校准

v3曾把训练收益普遍放到所有低费与主力卡，90对60训练的9组得分为95.75%～99.75%，过于接近必胜。v4收紧为高阶编组少量生命收益，取消全军统一加攻击；前锋和低费小队保持标准预算。同期也调整了低费解场、部分突袭身体和组牌，所以改善是联合校准结果，不能全部归因于单一参数。

| 相同兵力与人物，90训练对60训练 | 高训练方得分 | 95%成对近似区间 |
|---|---:|---|
| 1800混编／武力主将 | 61.25% | 56.32%～66.18% |
| 1800混编／智力主将 | 62.25% | 57.46%～67.04% |
| 1800混编／统率主将 | 67.50% | 62.60%～72.40% |
| 1800骑兵／武力主将 | 67.25% | 62.77%～71.73% |
| 1800骑兵／智力主将 | 64.50% | 60.24%～68.76% |
| 1800骑兵／统率主将 | 69.00% | 64.42%～73.58% |
| 1800纯重骑／武力主将 | 66.75% | 62.13%～71.37% |
| 1800纯重骑／智力主将 | 63.25% | 58.94%～67.56% |
| 1800纯重骑／统率主将 | 70.75% | 66.07%～75.42% |

本轮高训练方得分为61.25%～70.75%，在这些样本中有明确收益且未接近必胜。它只覆盖3军阵与3主将的90对60，不代表所有训练差、兵力和人物组合都已验证。

## 6. 兵力与补兵

v3在手里部队较少时自动用补兵替代普通抽牌，可能挤掉更需要的计策或人物。v4默认先正常抽牌，牌库空且有实际缺额时才用真实预备兵替代空抽，并统一30张初始牌库。

| 同质量兵力对比 | 主将 | 较多兵力方得分 | 95%成对近似区间 |
|---|---|---:|---|
| 1800对600 | 武力 | 96.50% | 94.73%～98.27% |
| 3600对1800 | 武力 | 51.25% | 46.22%～56.28% |
| 1800对600 | 智力 | 98.00% | 96.64%～99.36% |
| 3600对1800 | 智力 | 63.00% | 58.38%～67.62% |
| 1800对600 | 统率 | 99.75% | 99.26%～100.00% |
| 3600对1800 | 统率 | 60.25% | 55.68%～64.82% |

1800对600仍有很大的实体牌数量优势；3600对1800主要体现预备兵，武力主将组的区间仍包含50%，收益不明确。不能把更多兵力一定更强作为已验证结论；K上限、预备兵发挥时机与小军计策比例还需继续验证。不同兵力组的牌库构成也不同，这不是只改一个数值的单变量试验。

## 7. 人物与历史约束

100人都完成卡表覆盖和实际部署样本，另对每人做了同费同身体的技能消融。单人只有100局，且主将搭配随人物轮换；不能用这些结果给100人做强弱总榜，也不能把一人的技能收益排名当成对其他人的胜率。完整逐人数据保留在结果JSON中。

历史与UI的硬约束已独立写入[人物关联与随机池](card-battle-phase1-person-binding.md)：历史定义与取得实例分开，所有内容按ID关联本人；随机人物按真实能力从专有池抽取，再固定为唯一实例。初始人员沿用已有姓名、能力和头像，不能在接入卡片时重抽外观。

当前有26条人物简介仍是原作或未匹配史料，已逐人标注。资源文件存在只证明可关联，不证明历史衣冠与武器已经全部核准。本轮不编造缺失事迹，也不将原作同名人物强行匹配为某一历史人物。

## 8. 尚待校准的项目

- 先后手：智力型、部分低兵力与重骑条件仍明显偏向先手。保持标准补偿，继续优化低费回应、解场与突袭交换预算、抽牌时机及自动配牌。
- 时长：主矩阵各组中位数为12～31个完整回合，部分防守与低兵力对局未达到原先8～12轮目标。需要在现有牌型内补强合理终结能力、减少无效等待，不能靠临时统一掉血结束。
- 兵力：超过初始实体上限后的收益仍可能较弱；小军更多计策的效果必须与军粮成本、持续战损一起评估。
- 人物：消融样本不足以定价全部技能，定向检索、护卫和保护类人物需要更充分的横向对战与组合试验。
- 历史：补核26条原作资料，并按绑定要求逐张检查卡面衣冠、武器及技能表现。
- 产品验收：正式引擎、存档迁移、外国人物实际生成、装备账本与真实UI均未开发，不以独立模型代替这些检查。
