# 太医院与独寝恢复修复 · 2026-10-29

## 实际问题

旧金龙殿把恢复放在图片全部解码成功后的3秒计时器中。此时离殿会清除计时器，没有属性变化，却仍可能消耗一个行动阶段；图片或呼吸动画失败也可能阻断恢复。旧侧栏只在整页重新渲染时刷新，房间或纪事窗口内已成功保存的健康变化不能立即看到。

原太医紧急诊治限健康≤30，入口位于本朝纪事，按钮禁用时没有普通就诊替代入口；诊治成功后直接关窗，反馈不足。没有把紧急诊治数值模型一概认定为失效，已补实际点击确认及保存验证。

## 当前行为

- 金龙殿入殿即进行一次恢复并保存，装饰画卷与动画不再控制属性结算；体力最多+150、健康+10、快乐+5，每时辰一次。
- 侧栏健康、快乐、体力及健康门槛提示随保存成功立即刷新，无须关窗。诊治后的国库银两同时刷新。
- 恢复保存失败时保留错误提示和“重试安寝”，不显示成功；重试从原状态计算。未成功安寝直接离殿不消耗阶段。
- 宫城图御书房下方院落设置“太医院”入口，移除左侧按钮；早朝、夜间、健康低于20、体力耗尽均可就诊。战斗、京城失守待处理或本朝已结束时不可诊治。
- 太医院健康未满即可就诊；本朝纪事保留健康≤30的紧急诊治，并提供前往太医院的按钮。

## 诊治数值

| 项目 | 当前规则 |
|---|---|
| 健康 | 最多+25，按100封顶 |
| 药后不适 | 快乐最多−5，最低0 |
| 药后疲乏 | 体力最多−10；原有正体力至少保留1，原为0则仍为0 |
| 寿元 | 不额外扣减，药后疲乏不触发过劳 |
| 诊金 | 标准1000两，受已有难度诊金系数影响 |
| 次数 | 每旬一次，与原紧急诊治共享 `endings.lastTreatmentTurn` |
| 危重 | 成功诊治清除危重累计 |

诊金和副作用在点击前展示；成功后显示实际健康前后值、实际副作用与诊金。银两不足、已经就诊、健康已满等均显示原因。支付、健康、快乐、体力、危重和限额作为同一候选存档提交；保存失败不发布任何收益或扣费。未新增存档字段，保留旧档已使用的诊治次数。
