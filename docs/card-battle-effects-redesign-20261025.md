# 战斗增益、敌方持续效果及奥秘／武器／地标设计

日期：2026-10-25。状态：设计提案，未实现视觉改动。

> 2026-10-25 设计更新：组合状态的 UI 与持续表现以 [新的完整 UI 设计](design/card-status-ui-20261025/design.md) 为准。下文相关冰壳、护盾整框、叶片等为先前探索记录，不再作为最终方案。新一轮仅交付静态设计，未修改现有预览或游戏实现。


## 1. 战斗速度

标准档播放倍率由 1 提至 1.15，时长约缩短 13%；例如 3300ms 的技能展示变为约 2870ms。快速档保持 2 倍，自动战斗仍叠加现有 1.8 倍。保留起手、命中、数字变化、收势顺序，以及减少动态效果设置。

## 2. 统一表现规则

每个实际生效的效果拥有独立的形状、作用位置和数字提示，不能只换泛光颜色。一张牌既加攻又加生命，必须同时呈现两种效果；人物登场演出保留，但结算效果使用同一套语言。

施放分为来源提示、飞行或连线、目标命中、状态留驻四层。数字在对应效果命中时更新；依照引擎已结算事件播放，不再计算一次战斗规则。攻击强化放在左下攻击区，生命强化放在右下生命区，护盾沿边框，控制放在顶部标识，尽量保留人物脸部。

同一结算的不同属性错开约 90ms 起播，重叠完成，不逐项追加长停顿；同一种属性同一批结算可合并数字，不同属性不得合并。群体效果共用一次施法演出，各目标各自显示命中。无效、被抵挡、被净化、到期分别提示；治疗为零时不显示虚假的加血数值。

## 3. 己方增益设计

| 效果 | 瞬时特效 | 持续表现与结束 |
| --- | --- | --- |
| 恢复当前生命 | 青绿水滴沿右侧上升，汇入生命珠；显示实际恢复值 | 回血本身不留永久光效 |
| 增加生命上限 | 翠玉枝叶从生命珠展开，形成一段玉环；标“生命上限 +N” | 生命珠保留细玉环；移除时收拢；当前生命变化按实际事件提示 |
| 永久加攻 | 朱金刀锋向上掠过攻击珠，短促火星；标“攻击 +N” | 攻击珠保留刀锋刻线；移除时刻线消退 |
| 本回合加攻 | 琥珀疾风带绕攻击珠半圈，标“攻击 +N · 本回合” | 虚线弧与回合小标；到期弧线散开，提示到期 |
| 主将护甲 | 银蓝甲片逐层扣合在主将护甲数字周围 | 护甲纹与数字常驻，消耗时碎开相应甲片 |
| 护甲盾 | 金白六边护罩从卡角闭合 | 边框细盾线；抵挡伤害时先闪盾再碎裂，标“抵挡” |
| 额外关键词 | 护卫为盾纹，突袭为斜向风刃，潜行为墨雾，反骑/慑马为马蹄禁纹，破盾为裂盾 | 独立图标与名称；沿既有关键词规则移除，不虚构持续回合 |
| 抽牌、减费、返还军令 | 抽牌为书页从牌库入手；减费为费用珠收缩刻度；返还为军令玉珠回流 | 数字分别在手牌费用与军令区域变化，无额外人物光环 |

组合示例：同一部队获得攻击 +2、生命上限 +3、护甲盾，先出现左下刀锋，90ms 后右下玉枝，随后边框护罩闭合；三种图形均可辨认。实际回血另播青绿水滴。状态详情分别列出各项属性及期限。

## 4. 对敌方施加的持续／延迟效果

当前引擎存在冻结、沉默和属性削弱。本方案也定义未来延迟触发的表现规范；不会因此新增中毒、灼烧等玩法。是否显示倒计时必须由真实规则提供。

| 效果 | 施加瞬间 | 持续与解除 |
| --- | --- | --- |
| 冻结 | 冰蓝棱片从卡角合拢，顶部落下雪晶 | 边角薄冰＋雪晶；详情沿用真实解除条件；解除时冰片融散 |
| 沉默 | 灰紫封印压住技能区，墨线封住技能图标 | 顶部封口印；原技能区降低饱和度；解除条件按引擎，不显示虚构回合数 |
| 降低攻击 | 暗红断刃落入左下攻击珠，标“攻击 −N” | 攻击区断刃刻线，与加攻玉金风格区分 |
| 降低生命上限 | 枯紫裂环收紧右下生命珠，标“生命上限 −N” | 生命区保留裂纹，不能表现成普通扣血 |
| 设置攻击数值 | 刻度尺扫过攻击珠，显示“攻击设为 N” | 按最终属性保留标记，避免误标为伤害 |
| 延迟触发（未来扩展） | 封签附着目标，显示真实触发条件 | 有真实回合数才显示计数；触发时封签亮起→对应效果命中→数字更新；取消则封签熄灭 |

多状态示例：冻结＋降攻＋沉默，同时保留边角薄冰、左下断刃、顶部封口印；不把三者归成一层紫光。到期、净化只移除对应状态。目标阵亡时清理全部附着表现，不向后续占据同一位置的卡片转移。

## 5. 奥秘牌整体美术重做

用户称“奥术牌”，暂按现有 `secret` 奥秘类别设计：当前全部为「御前警戒」「料敌设伏」。不改卡名、费用或战斗规则。

整体方向：御前密令、青铜机关、封蜡暗纹。卡框采用深墨青底与克制的旧金边饰，中央用有纵深的场景叙事，替换当前扁平眼睛／交叉武器图标。插画占上部约 62%，下部独立浅绢规则区，名称、费用与触发条件在小尺寸下仍清楚；不将规则文字画进插画。

| 卡牌 | 主插画构图与色彩 | 设置、触发与结算特效 |
| --- | --- | --- |
| 御前警戒 | 夜色宫门近景，前景禁军斜持盾戟，远处宫灯照出门缝；墨青、旧金、少量冷白，主体是保护阵形 | 设置时折成密令并封印；触发时宫门光影展开、三枚甲片向主将扣合，护甲 +3 在扣合时出现；随后按真实结果继续敌方攻击 |
| 料敌设伏 | 狭道俯视构图，前景暗处弩机与绷紧引线，远景敌军剪影踏入伏击区；铁灰、暗赭、微量朱红 | 设置时密令潜入暗槽；触发时引线亮起、短促弩矢射向攻击者，命中显示实际伤害；若攻击者阵亡，表现攻击中断与阵亡，否则继续原攻击 |
| 共用隐藏牌背 | 封闭卷轴、完整朱蜡印、低对比云雷纹；取消大问号 | 敌方两种奥秘共用相同牌背、颜色、设置动效、音效和悬停信息，触发揭示前不得泄露具体种类 |

奥秘槽位使用小型封印徽记，己方可查看牌名和条件，敌方只显示未知奥秘。触发时从实际槽位揭牌，揭示展示约 600–800ms，随后转入专属命中效果；多张按引擎触发顺序逐张揭示。未触发的奥秘继续保持密封。触发失败或被取消时使用对应文字，不播放成功伤害／护甲。

音效方向：回血用清水与玉音，加攻用金属掠声，护盾用低沉合甲声；冻结用短冰裂、沉默用收束闷音；警戒用门闩与合甲，设伏用绷弦与短弩。多效果混音限制峰值，避免所有声音同时抢占。

## 6. 后续实现与验收

将当前 `enhance` 泛化状态拆成攻击、生命上限、授予关键词等表现通道；同一 `buff` 事件按实际字段变化展开。单个事件包含多项变化时不能只按 `event.type` 去重。来源与先后顺序优先使用现有事件和历史 cause 信息；仅对缺失字段使用前后快照差值，并避免把多次事件的最终差值重复播放。

验收应覆盖：所有现有卡牌效果类型；回血与加生命上限分开；加攻＋加生命＋盾三效并存；冻结＋降攻＋沉默并存；群体多目标；同回合多次修改同属性；抵挡、零恢复、到期和阵亡清理；两张奥秘的设置、揭示、攻击继续／取消；敌方隐藏信息；标准、快速、自动与减少动态效果模式。1440、1000、800 宽度下检查手牌、场上卡、放大预览及槽位，光效不挡关键数值。

建议先制作一段三增益组合、一段三负面状态组合，以及两张奥秘的卡面与触发演出预览，再覆盖全量卡牌。当前提交仅调整标准速度，其余均等待视觉方案确定后实现。

## 7. 武器牌卡面与特效重做

覆盖当前全部武器：「备用刀盾」「备用长枪」。与奥秘采用同一套材质精度，但武器以锻铁、皮革、木杆和刃口冷光为主，卡框为铁灰与旧铜，避免所有类别都使用金色泛光。主体占插画区约 75%，背景为虚化军械架，缩小后仍能看清武器轮廓。

| 武器 | 卡面构图 | 装备与攻击演出 |
| --- | --- | --- |
| 备用刀盾 | 长刀斜置前景，盾牌立在后侧；刀刃有真实厚度，盾面保留铆钉与皮革包边；冷钢、暗木、赭皮 | 装备时刀盾轮廓从牌面抽出，收进主将武器槽，伴随扣带与短金属声；攻击为宽弧斩痕，盾保持装备轮廓，不暗示新增格挡能力 |
| 备用长枪 | 枪杆由左下贯穿右上，枪头为视觉焦点，背景军械架强调纵深；冷银、深棕、少量暗红缨结 | 装备时枪身沿长轴滑入武器槽；攻击为细长直刺、枪尖冷光与短距离冲击线，明显区别刀盾的横向斩击 |

武器卡左下为攻击，右下为耐久，耐久使用铆钉／分段刻度与工具提示，不能沿用生命珠造成误解。当前两张均为 2 耐久，显示两段；小尺寸同时保留数字。

装备、可攻击、本回合已攻击、磨损、耗尽、替换分别表现：

- 装备：卡面移动至主将武器槽后，槽位亮起一次，显示实际攻击与耐久。
- 可攻击：刃口细高光与明确可用标记；本回合已攻击后高光熄灭，标“本回合已攻击”，武器仍保留。
- 命中：先播放对应刀斩／枪刺，再更新目标伤害与主将反击伤害；护甲盾抵挡时使用盾效果，不伪造生命损失。
- 磨损：仅收到 `weapon-wear` 时熄灭一段耐久，出现“耐久 −1”；攻击被奥秘中断时按实际事件处理，不能自行扣耐久。
- 耗尽：最后一段消失后，刃口失光、轮廓碎成少量铁屑，标“耐久耗尽”；避免长时间爆炸遮住主将。
- 替换：旧武器退入暗处并标“已替换”，新武器随后入槽；不把替换演成战斗击碎。主将战败导致失去武器也采用独立退场提示。

同一次攻击中的奥秘揭示、护甲获得、伤害、反击、磨损、破损，按引擎事件顺序衔接。伤害提示、主将护甲、武器耐久分别占用自己的位置。

## 8. 地标牌卡面与特效重做

覆盖当前全部地标：「整军营地」「号令旌台」。采用有空间纵深的战地建筑场景，卡框用青石、木构与旧铜包角；轮廓以建筑基座区别于人物、武器和奥秘。地标无攻击与生命，不显示对应数值珠，底部独立显示剩余次数、可用／冷却状态。

| 地标 | 卡面构图 | 部署与发动特效 |
| --- | --- | --- |
| 整军营地 | 暖色营帐位于中景，前景药箱、整齐绷带与水盆，侧面灯火透过帐布；橄榄绿、米白、暖琥珀 | 部署时木桩定位、帐布展开并落下短尘；发动时营灯亮起，一束青绿补给流连接受伤友军，在目标生命珠处播放回血水滴，显示实际恢复量 |
| 号令旌台 | 石木高台、主旗与两侧小旗构成高低层次，前景有令鼓；暗木、旧金、克制朱红 | 部署时基座落稳、旗杆竖起、旗面展开；发动时短鼓点配旗面一次有力摆动，金色号令波抵达目标，再播放琥珀临时加攻风带，标“攻击 +2 · 本回合” |

两张地标共用清楚的状态系统：

- 剩余次数：两枚铜筹与“2／1 次”数字；发动成功后消耗一枚。次数与冷却分开，不用同一条进度表达。
- 可用：建筑功能点亮起，营地为营灯、旌台为旗顶铜饰；边框保持稳定，避免整张卡持续闪烁。
- 冷却：功能点熄暗、建筑仍清楚；标“冷却中”，悬停说明“使用后隔过一个己方回合才能再次发动”。剩余等待从真实 `landmarkReadyTurn` 与己方回合数推导，不按敌方回合递减，不用虚构秒数进度条。
- 就绪：收到真实就绪事件时，灯火／旗饰亮起一次并提示“地标就绪”。若当前无合法目标，另外显示“暂无可选目标”，不能误报为冷却；满血友军不能成为营地治疗目标。
- 次数耗尽：最后一次目标特效完整落地后，地标降旗／熄灯并淡出，标“次数耗尽”，随后呈现已释放的场位。
- 主动拆除：收帐／降旗、基座淡出，标“已拆除”；不用伤害爆炸，也不伪造退还费用。

地标连线只连接真实目标，治疗与临时加攻复用第 3 节的目标效果；来源的营灯、旗鼓演出用于辨认是哪张地标发动。地标占用现有场位，卡面与特效不扩展到相邻牌的数值区域。

## 9. 扩展验收与预览范围

后续预览增补四张卡面、一段刀盾攻击、一段长枪攻击，以及两种地标完整生命周期。检查武器装备／替换、主将攻击／反击、被奥秘中断、耐久耗尽；检查地标部署、合法目标、冷却、就绪、最后一次使用、主动拆除及场位释放。双方使用同一视觉规则，所有数字以真实结算事件为准。所有卡面同时检查手牌、场上、编牌、教程与放大预览，避免只改战斗界面。

本次补充仍只做设计：武器、地标的数值、效果、库存扣损和存档结构保持现有规则。
