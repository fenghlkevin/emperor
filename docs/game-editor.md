# 局内编辑器

进入当前进度后，选择左侧「局内编辑」；朝堂中先打开左上角起居菜单。

- 文武人物：编辑仍存活的已登记官员，调整智力、武力、统率、政务、清廉、忠诚、经验与年龄。
- 州郡城池：调整安定、治安、营业、体能、防御、民忠、生活水平、驻军训练与七类建筑数量。
- 国家势力：调整本国或外国的银两、存粮和威望。银粮差额通过现有账务接口入账。

选择对象后修改数值，点击「核对修改」，检查前后差异，再点击「确认并保存」。编辑不消耗行动，也不推进时日。关闭或切换对象时，未保存的修改会要求确认放弃。

窗口内可撤销上次成功编辑；撤销会恢复该次编辑前的完整进度并产生新的保存版本。关闭编辑器后不保留撤销历史。保存失败时保留原进度，可重试。当前战斗、待处理战役、亡国危机和已终评进度禁止编辑。

当前不提供新增人物、候选人编辑、姓名身份修改、城池归属、官职任免、兵力和装备数量编辑。人物编辑保留原来的个人成长潜力，手动调整能力不重算潜力。

验证：`node --test tests/game-editor.test.mjs`；`node_modules/.bin/electron tests/game-editor-desktop.cjs`。桌面验收使用独立临时存档，覆盖实际入口、核对、保存、撤销、人物修改后重载及1440/900/390窗口宽度。

本次验证结果：编辑器4项业务测试和桌面验收全部通过，58组类型契约快照通过。完整业务回归1217项中1215项通过；两项失败为非人物美术引用清理、随机立绘目录旧PNG清理，报错涉及现存素材，本次未修改素材目录。
