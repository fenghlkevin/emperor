# 军阵卡牌战斗：首版玩法与接入

## 军队如何进入卡牌战场

沿用原有的出征编队：一名全军主将、亲卫、最多六个子队，每队有实际将领、兵种和人数。朝堂出征、兵部出征及两处守城部署入口均已切换到卡牌模式。已有六角格存档沿原战场续战。

| 军事数据 | 对战中的作用 | 战后处理 |
|---|---|---|
| 全军主将 | 使用实际选中的官员头像、姓名与属性；30点军心；根据智谋、武勇、统率生成主将技 | 沿原将领经验与战报结算 |
| 主将统率 | 每50点给己方部队牌增加1点兵力 | 不改变兵籍 |
| 主将亲卫 | 保护主将；每累计损失1点军心，折损初始亲卫的1/60，向上取整，上限50% | 军心恢复不复活伤亡；军心溃散时主将撤离，其余亲卫生还 |
| 子队将领 | 本队每张牌展示原将领；每40点武勇增加1攻，每60点智谋增加1兵力 | 同一将领的各张牌属于同一实际子队 |
| 子队人数 | 每队等分为最多6张部队牌，全军最多24张；余数分配给前面的牌；每个士兵只属于一张牌 | 不凭空召唤、复制或归还士兵 |
| 部队规模 | 规模加成为 min(6, floor(log2(该牌人数/100+1)))，同时增加攻击和兵力 | 数量优势递减，维持可读卡面；目前为试验平衡值 |
| 训练度 | 每40点训练增加1攻、1兵力，保留驻地真实训练快照 | 不因为抽牌或换牌改变训练 |
| 装备 | 继承真实兵种；缺装乡勇攻击按原装备系数折减 | 实际阵亡一人核销一人份对应装备 |
| 城防 | 守方部队额外兵力为 round((原防御系数−1)×4) | 延续原占领与城防结算 |
| 军粮和银两 | 原出征整备、额外补给在确认军令时扣除；常规驻军粮饷沿原按旬规则 | 卡牌回合是一次战斗内部动作，不推进旬、不重复收取粮饷 |
| 军令点 | 只表示本回合行动能力，与国库和粮食分开 | 每回合恢复，不兑换实际资源 |

部队牌受到伤害后，按 `ceil(该牌人数 × 累计受伤 / 初始卡牌兵力)` 回写阵亡，上限为该牌人数。未抽到、仍在手牌、被爆牌弃置的部队没有战斗伤亡；不会因为抽不到牌就删除真实军队。所有卡牌伤亡最终合并回原子队，再走原有驻地、装备与人口结算。

## 对局规则

首版固定我方先手，起手3张，敌方4张并额外获得一张0费调兵令。玩家可选择起手替换，替换牌不会成为自己的替换结果，随后洗回牌库。完成换牌后抽首回合牌。

每方30张牌；真实部队牌以外的牌位循环补充军需调度、万箭齐发和整军鼓舞。敌方额外调兵令不计入30张。第一版自动形成军阵，不需要另行组牌。

每回合军令上限增加1、最高10，恢复军令并抽1张牌。手牌最多10张，超出的抽牌进入弃牌区。牌库抽空后，每次抽牌承受递增疲劳伤害。超过80个半回合再追加递增军心消耗，保证对局可以结束。

双方各7个部队位。新登场部队下回合才能攻击，每回合攻击一次；攻击部队双方同时受伤。护卫优先承受攻击；突袭当回合只能攻击部队；远程兵以登场削减敌方1点军心体现特性，普通攻击仍遵守统一反击规则。

| 主将条件 | 主将技 | 费用 |
|---|---|---|
| 智谋高于武勇 | 运筹：抽1张牌 | 2，每回合一次 |
| 否则，统率达到80 | 振军：恢复4点军心 | 2，每回合一次 |
| 其他 | 督战：对敌方主将造成2点伤害 | 2，每回合一次 |

| 计策 | 费用 | 效果 |
|---|---|---|
| 军需调度 | 3 | 抽2张牌 |
| 万箭齐发 | 4 | 所有敌方部队受到2点伤害 |
| 整军鼓舞 | 2 | 主将恢复4点军心 |
| 调兵令 | 0 | 本回合增加1点军令，上限10 |

军心归零、主动撤军都会结束对局。战果面板由玩家点击结算，继续使用原来的 `beginWar → advanceWar → finishWar` 链；守城仍由原守城结算处理。自动战斗使用同一合法动作引擎，不走简化伤亡公式。

界面使用独立古战场背景、九兵种插画、现有官员头像、木质手牌区、红绿主将军心、玉色结束回合按钮与军令灯。整体布局对应确认过的概念图；7个部队位按新的玩法规则调整。

验证命令：`npm run test:card-battle`、`npm run test:card-battle-ui`、`npm test`。实际界面截图位于 `docs/screenshots/card-battle-desktop.png`。

## 当前范围

这是可以从出征走到结算的第一版。它沿用卡牌对战的基础交互，尚未加入自建牌组、武器、复杂触发连锁、更多专属主将技与精细战斗动画。每种兵种、人数和训练加成仍需要后续平衡体验；出兵人数不会逐人线性放大卡面数值。

## 玩家操作说明

### 1. 先开始交战

打开试玩后，中央会显示“部署先锋”。这时点击底部手牌只是在选择要替换的起手牌，还不会出兵。选中的牌会抬起并出现高亮，再点击一次即可取消。点击“开始交战”确认；不想换牌可以直接开始。

优先留下2～3费的部队牌。当前军阵可能没有1费牌，第一回合只有1点军令，无法出牌时直接结束回合即可，并非操作失效。

### 2. 看懂界面

| 位置 | 内容 | 用途 |
|---|---|---|
| 上方中央 | 敌方主将与红色军心 | 将敌方军心打到0获胜 |
| 中央上排 | 敌方已上场部队 | 可以选择攻击；优先处理护卫 |
| 中央下排 | 己方已上场部队 | 点击选择攻击者 |
| 下方中央 | 己方主将与绿色军心 | 我方军心归零战败 |
| 主将右侧 | 主将技按钮 | 2费，每回合最多一次；悬停查看效果 |
| 最底部 | 手牌 | 点击使用，当前版本不用拖动 |
| 右下角 | 军令，例如3/5 | 剩余3点，本回合上限5点 |
| 右侧 | 结束回合、撤军 | 交给敌军行动，或确认撤军 |
| 左侧 | 回合、自动战斗 | 查看行动方或交给电脑 |
| 左下方 | 军情·兵粮与将领 | 展开查看实际兵员、训练及军粮口径 |
| 右上角 | 保存离场 | 离开战斗界面，保留当前战局 |

手牌左上角蓝色数字是费用；部队左下角数字为攻击，右下角红色数字为剩余生命。卡面生命是战斗数值。实际人数从卡面移到军情与悬停说明中，不再与生命并排显示。悬停部队牌可查看将领、实际生还/初始人数、训练和能力。

### 3. 打出一张牌

先确认左侧显示“我军行动”，且没有开启自动战斗。看右下角剩余军令，再点击底部想出的牌。

- 部队牌：消耗军令，自动放入己方下排的空位，不需要再点击地面；最多7支部队。
- 计策牌：消耗军令并立即生效，当前计策不需要选择目标。
- 正式交战后，单击手牌就是确认使用，不是预选。当前版本没有撤销出牌。

例如剩余5点军令，可以先出一张2费刀盾兵，再出一张3费弓兵，军令变为0。攻击本身不消耗军令，即使军令为0，已经准备好的场上部队仍能攻击。

### 4. 指挥部队攻击

点击中央下排一张己方部队牌，再点击高亮的敌方部队或敌方主将头像，即完成攻击。点击另一张己方部队可切换攻击者。

普通部队登场当回合不能攻击；下一个己方回合才可行动。每支部队每个己方回合最多攻击一次。卡牌会显示“刚上场”“已攻击”“可攻击”或“突袭就绪”。旧战局缺少细分记录时显示“待命”。可攻击部队带绿色光效，选中的部队抬起，合法目标带暖色高亮。点击不能行动的部队会说明原因；没有可执行动作时会提示结束回合。

攻击敌方部队时，双方同时造成伤害，被击败的一方仍会造成本次反击伤害。攻击敌方主将只扣主将军心，主将不会在当前版本自动反击。

示例：己方3攻/4兵力攻击敌方2攻/3兵力，敌方离场，己方剩3攻/2兵力。受伤会保留到后续回合。

### 5. 护卫、突袭与远程兵

- 护卫：敌方场上有护卫时，部队普通攻击必须先攻击护卫，不能绕过去打主将或其他部队。计策和主将技仍按自身效果结算。
- 突袭：登场当回合即可攻击敌方部队，但当回合不能攻击敌方主将。下一个己方回合恢复普通攻击规则。
- 弓兵、弩兵、弓骑兵：登场时使敌方军心减少1；普通攻击仍会受到敌方部队反击，没有额外射程操作。

### 6. 主将技和计策

点击己方主将右边的圆形主将技按钮使用。每次消耗2点军令，每个己方回合一次。具体技能由现有将领属性决定，按钮名字可能不同；悬停查看说明。

- 运筹：抽1张牌。
- 振军：己方主将恢复4点军心，最多恢复到30。
- 督战：敌方主将受到2点军心伤害。

计策中，“军需调度”3费抽2张；“万箭齐发”4费对所有敌方部队造成2点伤害；“整军鼓舞”2费恢复己方主将4点军心。敌方后手另有0费“调兵令”，本回合增加1点军令。

恢复军心不能复活已经阵亡的士兵，也不会给场上受伤部队恢复兵力。

### 7. 结束回合和常见操作障碍

出牌、攻击和主将技可以自由安排顺序；做完后点击“结束回合”。不必用完军令，剩余军令也不会积攒到下回合。下个己方回合上限增加1、军令补满、抽1张牌，部队重新获得攻击机会；军令上限10。

| 现象 | 先检查 |
|---|---|
| 点击手牌只是选中 | 是否还在“部署先锋”阶段；先点“开始交战” |
| 第1回合一张牌也出不了 | 只有1点军令，手牌可能最低2费；直接结束回合 |
| 点击手牌没出兵 | 是否军令不足、轮到敌方、自动模式开启，或已有7支部队 |
| 点击己方部队后无法攻击 | 是否刚登场、已攻击，或没有合法目标；看中下方提示 |
| 无法攻击敌方主将 | 是否有护卫，或本队是本回合刚登场的突袭部队 |
| 主将技是灰色 | 是否不足2点军令、已用过，或不是己方回合 |
| 手牌突然减少却没上场 | 是否打出的是立即生效的计策；看中下方军报 |
| 关闭自动后不能立刻操作 | 如果仍是敌方回合，等待敌军结束 |

### 8. 胜负、撤军与续战

目标是敌方主将军心归零，不需要消灭所有敌军。胜负确定后点击“结算战果”，查看参战、阵亡、生还和军备损失。

想提前结束时，点击“撤军”，再点击“确认撤军”；“继续作战”可取消撤军确认。撤军按战败处理，不会清除已经产生的伤亡。

“自动战斗”让电脑接管己方；可点击“停止自动”恢复手动。起手阶段仍需先确认“开始交战”。

独立试玩中，“保存离场”后会出现“继续军阵试玩”，同一窗口、同一进程内可继续。独立试玩战局保存在内存中，彻底关闭试玩窗口后不会保留；正式游戏入口沿用正式存档流程。

### 9. 与真实军队的关系

主将和子队将领都来自当前游戏军队。部队牌由实际出征部队拆分生成，人数不会复制。训练、人数、装备、将领属性和城防会影响卡面数值。卡牌受伤会按比例计入对应部队阵亡，战后按原驻地归还生还士兵与装备，并核销实际损失。

军令是回合行动点，不是军粮或银两。军粮沿用出征补给和按旬驻防支出；点击出牌或结束卡牌回合不会另扣一旬粮饷。“军需调度”只抽牌，不增加真实粮仓库存。

### 10. 第一次试玩的建议顺序

1. 起手保留较低费用的部队，点击“开始交战”。
2. 第1回合没有1费牌就结束回合。
3. 有足够军令后，点击底部部队牌让它上场。
4. 等到下个己方回合，点击己方场上部队，再点敌军攻击。
5. 优先击败护卫；没有护卫时，可直接攻击敌方主将。
6. 结合主将技与计策，做完操作再结束回合。
7. 胜负确定后点击“结算战果”。

## 五兵种试玩与生命调整

试玩实际配置刀盾、长枪、弓兵、轻骑、重骑五个子队。主将骑兵亲卫单独占用100人，轻骑子队160人、重骑80人均从真实库存预留；亲卫不生成手牌。军情展示每种部队牌的总数和牌库剩余数。

新战局采用规则2：每张部队牌在原生命计算上增加4点，攻击不变，以降低同档部队一次攻击就退场的频率。旧存档没有规则字段时仍按规则1验证和续战，不改变已上场部队的生命。新兵没有无敌保护，结束回合后仍可能被敌军攻击，弓兵应放在护卫后。

卡面左下标“攻”、右下标“命”，下方仅展示将领；实际兵员放在军情与悬停说明。此调整不改变真实伤亡账本。

# 下一阶段完整卡牌设计稿：部队、武将、主将与训练度

状态：设计讨论稿，尚未实现。本节作为下一阶段目标，前面的内容记录当前试玩实现。用户已明确：只使用现有训练度，不新增士气系统。

## 一、先统一玩家看到的规则

1. 卡牌只显示费用、攻击、生命。攻击5打生命10，目标剩5；部队交战同时反击，生命归零离场。受伤不降低攻击。
2. 主将也是生命值，不再将主将生命称为“士气”或与训练度混用。主将生命归零即本方战败，含义为亲卫防线失守、主将撤离，不自动判定人物死亡。
3. 训练度沿用现有0～100，开战时换算为卡牌加成。对局中不随伤亡降低，不再套一层士气、状态条或百分比衰减。
4. 人数、训练、将领、装备、城防只在开战时生成最终数值，玩家不用在每次攻击时重新计算。实际人数和伤亡放到军情与战报。
5. 普通部队上场后下个己方回合才能攻击；此期间可以被敌人攻击。护卫保护后排，突袭提供立即交换机会，不增加新兵无敌规则。

## 二、三种身份

| 身份 | 在哪里 | 攻击与生命 | 与现有军队关系 |
|---|---|---|---|
| 全军主将 | 场外固定主将区 | 显示主将生命，不主动普通攻击；使用主将技 | 出征选择的真实主将，亲卫保护其防线 |
| 普通部队卡 | 手牌→七个战场位置 | 有攻击、生命和兵种能力 | 来自对应真实子队的一部分兵员 |
| 武将卡 | 手牌→同样的七个位置 | 更高费用与数值，带一项将领特技 | 该子队将领亲自带领的一部分兵员，替换一张普通部队卡 |

同一人物不能既当全军主将，又作为武将卡上场。同一子队将领只有一张武将卡，其余牌是他的普通部队。不额外生成一个不占兵籍的“单人英雄”，不把整队兵力算进武将牌后再给其他牌重复使用。

## 三、九兵种与乡勇：基础卡面

以下是标准编制、训练加成前、将领加成前的基础值。均为首轮平衡起点，需要模拟和试玩验证，不视为已定稿。

| 部队 | 费用 | 攻击 | 生命 | 能力与定位 |
|---|---:|---:|---:|---|
| 乡勇 | 1 | 1 | 5 | 缺装应急部队，无特技；只由实际缺装守军生成 |
| 刀盾兵 | 2 | 2 | 8 | 护卫，承担伤害，保护弓弩 |
| 长枪兵 | 3 | 3 | 9 | 护卫；主动攻击骑兵时本次攻击+2 |
| 轻骑兵 | 3 | 4 | 7 | 突袭，登场可攻击部队，适合抢回场面 |
| 重骑兵 | 5 | 6 | 11 | 突袭，高费突击主力 |
| 弓兵 | 3 | 4 | 6 | 登场：对一个敌方部队造成2点伤害 |
| 弩兵 | 4 | 5 | 7 | 主动攻击护卫部队时本次攻击+2 |
| 弓骑兵 | 4 | 4 | 8 | 突袭；主动攻击部队时，本次受到的反击伤害减少1 |
| 骆驼骑兵 | 4 | 4 | 9 | 突袭；主动攻击骑兵时本次攻击+2 |
| 象兵 | 7 | 7 | 14 | 护卫；主动攻击部队时，本次受到的反击伤害减少2 |

“骑兵”包含轻骑、重骑、弓骑、骆驼骑兵，不包含象兵。兵种加伤只在主动攻击时生效，不在反击时生效；攻击预览需明确展示本次攻击值与双方预计剩余生命。护卫仅限制普通攻击选目标，登场伤害和计策不受其限制。

弓兵仍遵守部队交战双方反击规则，不默认免反击、不重新增加射程。强弱通过卡面生命、登场伤害及费用区分。

乡勇用独立低数值，不能再在其低攻击上重复乘0.5装备惩罚；完整配装兵也不重复加一层“装备品质”数值。外国特色兵种仍按现有产地、装备与实际参战资格生成，不能为补齐牌库凭空给玩家。

## 四、训练度：只在生成卡牌时生效

| 真实训练度 | 显示档位 | 攻击加成 | 最大生命加成 |
|---|---|---:|---:|
| 0～39 | 新募 | +0 | +0 |
| 40～69 | 训练有素 | +1 | +1 |
| 70～89 | 精练 | +1 | +2 |
| 90～100 | 百战精锐 | +2 | +3 |

普通部队卡和武将卡使用同一张表；主将技不乘训练系数。中央、地方、盟军使用各自原驻地的训练快照，不统一强行用中央训练。

例：训练60的标准刀盾兵，由基础2攻/8命生成3攻/9命。受到5点伤害后变成3攻/4命，训练仍为60，攻击仍为3，不会因为剩余士兵减少而再扣攻击。

## 五、兵力与带队将领加成

### 子队规模

规模档位按开战前整支真实子队人数确定，不按分成几张牌后的单张人数重复计算。目的是避免“多拆一张牌就降低所有卡面”。

| 子队真实人数 | 档位 | 普通部队和武将卡的加成 |
|---|---|---|
| 1～99 | 残部 | 攻击−1，生命−2，最低均为1 |
| 100～999 | 标准 | 无额外加成 |
| 1000～2999 | 大队 | 攻击+1，生命+2 |
| 3000～5999 | 强军 | 攻击+2，生命+3 |
| 6000～10000 | 大军 | 攻击+3，生命+4 |

人数还决定实际可投入与损失多少兵员。数量优势采取递减档位，不让十倍人数变成十倍卡面攻击。档位仍属待验证方案，不以训练名称标注人数档位。

### 子队将领

武勇作用于本队卡牌攻击，智谋作用于本队卡牌生命：低于60无加成，60～79增加1，80～100增加2。一次生成后锁定，普通牌与武将牌各加一次，不在武将牌上重复结算。

全军主将不再给全部部队叠加攻击和生命光环，改为主要影响自身生命与主将技，减少全军主将、子队将领、训练、规模四层同时放大的问题。

最终部队卡：基础值＋训练加成＋子队规模加成＋子队将领加成；守城再按既定城防档位给守方生命加成，最多+2。最终攻击和生命最低1，不再在战斗过程中叠乘隐藏系数。

## 六、武将卡

### 生成与身份

每支子队最多分成4张卡，其中1张是该将领的武将卡，另外最多3张为普通部队。人数少于4时按实际人数减少卡数，每张至少1人。兵员按整数等分、余数逐张分配；武将牌只持有自己那一份兵员。

武将卡沿用真实人物姓名和头像，卡面形如“沈怀安 · 轻骑统领”。普通部队用兵种插画，姓名只在详情中显示，避免同一将领看起来上场了四次。

### 九种武将卡模板

| 武将带队兵种 | 费用 | 基础攻击 | 基础生命 | 继承能力 |
|---|---:|---:|---:|---|
| 刀盾统领 | 3 | 3 | 10 | 护卫 |
| 长枪统领 | 4 | 4 | 11 | 护卫、主动攻击骑兵+2 |
| 轻骑统领 | 4 | 5 | 9 | 突袭 |
| 重骑统领 | 6 | 7 | 13 | 突袭 |
| 弓兵统领 | 4 | 5 | 8 | 登场对一个敌方部队造成2伤害 |
| 弩兵统领 | 5 | 6 | 9 | 主动攻击护卫+2 |
| 弓骑统领 | 5 | 5 | 10 | 突袭、主动进攻受到反击−1 |
| 骆驼统领 | 5 | 5 | 11 | 突袭、主动攻击骑兵+2 |
| 象军统领 | 8 | 8 | 16 | 护卫、主动进攻受到反击−2 |

统一为对应普通牌费用+1、基础攻击+1、基础生命+2。然后应用同一套训练、规模和带队属性加成。乡勇的署理将领可使用2费2攻7命的乡勇统领模板，没有额外人物特技，不凭空视为正式名将。

### 一人一项人物特技

按真实将领武勇、智谋、统率的最高项决定，最高项低于60则暂不附加人物特技；并列优先统率、武勇、智谋。

| 类型 | 判定 | 武将卡附加特技 |
|---|---|---|
| 猛将 | 武勇最高 | 登场：对一个敌方部队造成2伤害 |
| 智将 | 智谋最高 | 登场：抽1张牌 |
| 统将 | 统率最高 | 登场：己方主将恢复3生命，不能超过上限 |

同类登场伤害合并为一个事件：弓兵统领的2点伤害与猛将2点合并为4点，一次选目标，不要求连点两次。第一版不增加专属武器、技能树或多段连锁。历史人物的专属技能留待单独设计，不用孙刘曹预设身份替换现有将领。

武将牌离场只代表该将领的带队分队退场，不让同队其他牌消失，不扣一层不存在的士气。人物负伤、俘虏或死亡由独立战后规则处理，不因一张牌生命归零就自动处决人物。已发生的带队属性加成不因武将牌离场突然回收。

## 七、全军主将

主将从实际出征或守城部署中选择，在场外固定展示，不占七个部队位，不放进牌库。

| 主将统率 | 初始及最大生命 |
|---|---:|
| 0～59 | 30 |
| 60～79 | 32 |
| 80～100 | 34 |

主将没有普通攻击值，UI显示“主将技”而不显示误导性的0攻。军令技能每回合一次、费用2；以三项最高属性决定类型，并列优先统率、武勇、智谋。60以下仍有基础主将技，避免新人无事可做。

| 主将类型 | 技能 | 基础效果 | 对应属性≥80时 |
|---|---|---|---|
| 武勇型 | 督战 | 对敌方主将造成2伤害 | 造成3伤害 |
| 智谋型 | 运筹 | 抽1张牌 | 仍抽1张，暂不叠加复杂效果 |
| 统率型 | 振军 | 己方主将恢复3生命 | 恢复4生命 |

统率既影响主将生命，也可能决定技能类型；子队将领只影响自己的队伍。不将官员忠诚、清廉自动映射成卡牌攻击。

主将亲卫仍按真实兵种、人数、装备参战，保护主将，独立结算损失。默认不产生亲卫手牌，部署页必须明确说明；想在手牌中使用骑兵，应编入骑兵子队。

## 八、军阵与计策

保留炉石式军令、手牌、轮流行动和七部队位，不强行为少量真实部队补出大量计策凑30张。

军阵由每队最多4张实体部队卡，加6张固定计策生成：2张军需调度、2张万箭齐发、2张整军鼓舞。六个满额子队为30张，五队为26张，一队正常为10张。残部不足4人时按人数少出卡，不复制兵员。牌库数量在出征确认页展示。

| 计策 | 费用 | 效果 |
|---|---:|---|
| 军需调度 | 3 | 抽2张牌，不增加真实粮仓库存 |
| 万箭齐发 | 4 | 对所有敌方部队造成2伤害 |
| 整军鼓舞 | 2 | 己方主将恢复4生命 |
| 调兵令 | 0 | 后手额外获得1张；本回合军令+1，上限10 |

先后手各自起手3/4张，后手额外调兵令；目标是在正式玩法中随机先后手，试玩可固定玩家先手。初始手牌至少含一张实际存在的≤3费普通部队；若军阵没有此类牌，则不凭空生成。允许换牌，替换期间不把刚换出的同一张牌作为替换结果。

手牌上限10，超过上限的抽牌弃置；部队牌因爆牌弃置不产生真实阵亡。牌库空后按1、2、3……递增疲劳伤害扣主将生命。卡牌回合不推进旬，继续沿用原军粮与银两账本。

## 九、目标选择与卡面布局

普通牌：左上军令费、顶部兵种名、兵种插画、下方一条能力、左下“攻”、右下“命”。普通牌不突出将领姓名或实际人数。

武将牌：金色边框、真实姓名、真实人物头像、兵种标签、兵种能力和一条人物特技；费用、攻击、生命的位置与普通牌一致。

主将：固定头像、真实姓名、主将生命、技能按钮。不再把主将生命写成军心后又引入另一层同名概念。

训练度、规模、将领加成和真实生还人数放在悬停详情或军情展开区。示例：“基础2/8，训练+1/+1，带队武勇+1，最终4攻/9命；该牌初始100人，当前生还78人”。加成明细只解释已生成数值，不参与玩家即时心算。

有指定目标的登场牌，先点击手牌进入预选，再点高亮目标才扣费并落牌；点击取消或Esc可返回。没有合法目标时仍允许作为部队上场，明确提示该项登场伤害不会触发，避免卡死。无指定目标的牌保留单击使用。

普通攻击先选己方部队，再选目标；目标旁预览双方交战后生命。例如“我方4/9 → 4/6，敌方3/7 → 3/3”。不显示两个可混淆的“兵力”数字。

## 十、真实伤亡与结算约束

生命表示分队战斗承受能力；实际人数只用于初始规模与战后账本。所有实际人数必须能追溯到原驻地、原子队及预留装备。

普通牌与武将牌按各自初始人数和受伤比例回写实际伤亡；未抽到、留在手牌或被爆牌弃置的卡不因离开牌库产生伤亡。第一版不提供恢复部队生命的技能，主将治疗仍不复活亲卫伤亡，避免治疗后回算兵籍的矛盾。

武将牌与普通牌共用原子队的伤亡上限，同一士兵不能在两张卡中阵亡两次。主将亲卫单独占用、单独归还，卡牌攻击不重复消耗真实军粮。

## 十一、完整算例

一支800人的刀盾子队，训练60，带队将领武勇72、智谋65、统率58。全军主将统率75。

- 子队拆成4张，每张200人：3张普通刀盾兵、1张带队将领的刀盾统领。
- 训练60：攻击+1、生命+1；800人是标准规模，无额外规模加成。
- 带队武勇72给攻击+1，智谋65给生命+1。
- 普通刀盾：2费，基础2/8，最终4攻/10命，护卫。
- 刀盾统领：3费，基础3/10，最终5攻/12命，护卫；最高属性为武勇72，附带登场造成2伤害。
- 全军主将统率75：32生命，不额外给这些部队再加一层攻命光环。
- 普通刀盾受5伤后为4攻/5命，对应本牌100人阵亡；同队其他三张牌不因此改变卡面。

## 十二、设计验收目标

1. 正常同档前排通常能承受至少一次普通攻击；弓兵偏脆，但可由护卫保护，不承诺所有新兵都不会被集火击败。
2. 刀盾承担伤害、长枪应对骑兵、轻重骑抢场、弓弩提供针对性输出，五类常见兵种均可实际入手牌。
3. 提高训练能看见固定、有限的攻命增益；不会因训练高、名将高、人数多再连乘至失控。
4. 武将卡比同兵种普通卡强但费用更高；同一人物不重复占据多个角色，不复制兵员。
5. 正常完整对局目标8～12个双方回合；不能依赖无限治疗或反复召唤卡死。
6. 最终实现前需要测：九兵种同费用对局、低高训练交叉对局、不同人数档位、武将密度、先后手胜率、薄牌库疲劳及实际兵员/装备守恒。

待用户确认的主要设计取舍：固定三十张改为随真实编队生成的10～30张军阵；主将生命命名；部队基础数值、训练档位与武将技能范围。尚未据此修改运行中的战斗规则。
