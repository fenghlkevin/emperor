# 军阵卡牌第一阶段生产设计（v5）

日期：2026-10-22。当前实现与数值以本文件、[生产卡表](card-battle-release-catalog.json)和开战快照为准；旧草案与独立 Python 模拟保留为历史记录。工作树为 `codex/card-battle`，未合并 develop。

后续阶段与执行顺序见[军阵卡牌开发计划](card-battle-development-plan.md)。

## 基础交锋

双方轮流完成整个回合；开战随机决定先后手。先手3张，后手4张加0费调兵令；双方自己的首回合均正常抽牌，军令从1增长到10，每个己方回合刷新。手牌上限10、部队位7；普通部队下个己方回合才能攻击，突袭登场只能攻击部队。攻击不消耗军令，每单位通常每回合一次，攻击与反击同时结算。5攻打10命后剩5命，受伤不降低攻击。

护卫阻挡普通攻击，潜行单位不作为敌方定向目标，护甲盾抵挡一次伤害；沉默、冻结、临时强化、范围伤害、遗计、爆牌和递增疲劳均由同一正式引擎处理。一次结算完整处理死亡与遗计后判断胜负，双方主将同时归零为和局。城防只提供显示可见的0～4护甲；等条件审计不加入城防。

这是炉石式基础回合与卡牌交锋；自动军阵组牌、人物取得和真实兵员账本是本游戏的军队适配，不声称覆盖炉石全部职业、构筑格式或当前扩展内容。

## 军队、训练、主将与兵粮

- 卡片仅由本次实际部署的九类兵种、装备、部队与已任命人物生成。主将亲卫与实体卡兵员分开；同一人不能同时当主将与可部署人物，单人本场最多一张。
- 初始实体数先取 `base=min(18,max(1,floor(N/25)))`，再取 `K=min(20,base+floor(max(0,N-1800)/900))`；无军队时K为0。N为不含亲卫的实际兵员。按实际来源比例分配，不造兵；每张最多100人，剩余为该来源预备兵。
- 其中一张真实前锋以1费1攻2命计入起手，保证首回合有合法出牌。低费小队最多5张；实际不同部队将领最多形成3张人物卡，其余为主力与精锐。兵种来自实编，骑兵不会被替换成枪兵。
- 武力军阵采用2费3/2突袭的轻骑小队；智力、统率军阵采用2费2/3突袭的轻骑巡哨。两张是公开的固定卡定义，消耗同样的真实轻骑兵源。费用、攻命不会因为先后手或国家标签临时变化。
- 初始牌库共30张，计策从主将风格包补足。通常同计策最多2张；不足以形成6张实体卡的极小军阵为补齐30张场景牌库允许重复计策，不生成无来源士兵。牌库空、有实际预备兵和已损失编制时，每个己方回合最多补1张100人的同源普通部队替代空抽；无预备兵则照常疲劳。
- 训练0～39：人物卡生命−1；40～69无训练修正；70～89精锐生命+1；90～100精锐及人物生命+1。高档修正不叠加，不加攻击，也不增加独立士气。
- 实体少于75人时仅精锐与人物额外−1生命；少于25人再按人数/25缩放攻命，至少1。修正只在开战锁定，战中普通受伤不改变攻击。
- 主将使用所选现有人物本人身份、肖像与当前能力，基础30命、0攻；最高武力、智力或统率决定主将技，并列优先统率。技能均2费、每回合一次：督战对一个敌方角色造成1伤害；运筹抽1牌并使己方主将受2伤害；整军恢复一个友方角色2生命。
- 卡片按受伤比例的历史最高损失计实际阵亡；治疗与加生命不复活士兵。未上场的烧牌不制造阵亡。主将生命损伤对应亲卫损失，最多亲卫一半；护甲吸收不扣亲卫。生还者与装备按原部队、中央／地方／盟军来源归还，战果只结算一次。
- 军粮与出征银两沿用实际出征补给，卡牌回合不额外推进旬或重复扣粮。战斗期间不能推进国政旬或更动人员安排，避免改变参战快照。

## 人物关联与生成

100名当前开放人物均按历史定义ID关联本人、费用、攻命、技能与美术；招募实例 `recruit-ID` 关联回同一历史定义，身份与实例分别记录。原作26名身份仍待考证，继续展示待考状态，不编造史实。历史定位决定文武风格与技能主题，费用攻命为游戏平衡值。

随机人物使用独立36模板池（武力／智力／统率 × 四能力档 × 三固定变体）。根据本人实际能力筛选、加权抽取一次，再保存姓名、肖像、文化、能力、潜力、池、模板、种子和完整定义。同能力同种子采用同规则，不因国家或玩家身份增益；没有姓名的外国领队继承原来源实际能力，缺失项统一35，不额外获得60～84能力加成。

查看、任命、读档和再出征都不重抽。实际战外成长跨档时沿原方向、原变体升级，保留人物ID、姓名、肖像与生成种子；战斗开局保存完整规则、普通卡表与实际人物卡快照，旧对局沿原规则续战，v1/v2旧档走原引擎。

## UI与验收

场上战斗卡为5:7竖向长方形满幅立绘、窄名称条与角落攻命，没有手牌的费用和技能纸面；手牌保留费用珠，普通无技能部队用满幅立绘与底角攻命，有技能的部队和人物保留说明纸面，攻命置于插画与说明的交界；计策无攻命。手牌采用连续浅扇形排列，命中区域固定、内部牌面抬起，插画保持原始比例裁切，所有卡片保持5:7矩形，场上卡框正置。落定时扩散尘光，上场后立绘呼吸、衣甲流光与少量粒子持续循环，卡框、数值与点击位置稳定。主将技与计策具有蓄势、亮牌、目标飞行和对应命中效果；正常速度下完整技能牌静止展示约两秒，技能名和完整说明持续可读。部署时两种卡面交叠渐变，攻击、抽牌、受伤、治疗、护盾、遗计退场、计策箭矢和换回合都有动效；支持快速与减少动态效果。状态先提交再播放，关闭续战不重复扣血。

最初原型的场景、雕木桌面、铜饰主将框和青玉按钮经参考原图恢复为物理底板，实际姓名、数值、卡片与动作保持实时渲染。与原图的功能差异为七个部队位、本人主将与百人牌册。详见[原型对照](card-battle-ui-comparison.html)、[UI规范](card-battle-ui-spec.md)、[美术记录](card-battle-assets.md)及[生产平衡报告](card-battle-release-balance.md)。
