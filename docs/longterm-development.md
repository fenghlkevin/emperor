# P1 与指定长期玩法实施说明

实施日期：2026-10-16。本轮范围是全部剩余P1，以及用户选定的特殊建筑、官员与家庭生命周期、人口与生活水平发展、称号封禅与特殊结局。所有新增门槛、价格、概率之外的确定性规则均为本项目试行设计，未将攻略分歧裁定成原版算法。

## 入口与操作

- 早朝召见**宰相 → 国政长策**，提供国政总览、特殊工程、宗室承续、民政军籍、条约军援、封禅功业、官员任期七页。
- **工部尚书 → 特殊工程**，进入同一个工程目录、预估与队列。
- **紫宸殿 → 内侍 → 宗室教养与储位**，办理统一玉牒、教养、赐名、和亲与储君事务。
- **本朝终评 → 储君继位**，有合格成年储君时可延续国家经营。

查看与取消不扣资源。政令先预览，再确认保存；保存失败不发布任何钱粮、人口、军备、人物或序号变化。国政每次成功消耗一次行动；结束本局和继位不额外消耗已归零寿元的行动。

## 一、特殊建筑

每种建筑在全地图最多一处，全国同时只施工一项特殊工程，与普通工程和产业队列独立。采用本州现有民伕作为施工资格和征用来源，不复制人口、不改变职业人数；民伕不足、受灾或失地时保留进度停工。停止工程不退款，但释放全国工程名额。大运河南、中、北三段与长城东、中、西三段均按段连续施工，每段180旬（5年），总计540旬（15年）。每段完成记入工程纪事，整项竣工后下一旬启用全部收益。旧档在建工程保留已施工旬数，按新分段工期继续，旧档已竣工工程保留。建设费一次支付；正常施工每旬推进一旬，开工当旬不推进；竣工后下一旬启用。

旧档仅有自定义登记、没有新规则版本的特殊建筑保留原记录，不凭名称自动补发全国收益。

## 二、战争、军籍与民乱

### 城防与地形

战场开战时冻结目标州地形与城防，随战场保存。守军防御系数为 `min(1.5,1 + 州防御/500 + 长城0.2)`；该系数进入伤害计算，兼容旧式即时战力结算。丘陵使双方骑兵伤害×0.9，高山使骑兵每格消耗2点移动预算；步兵、枪兵仍按既有规则。战场页头显示地形和守方城防增益，旧战场缺少新字段时维持原规则。

### 双向调度

原有大将军中央向地方调派保留；国政民政页新增地方兵员和六种军备调回中央。士兵按来源州迁入中央军来源州，人口、士兵总量和实物军备守恒；来源州就是中央来源州时，只改变中央部署子集，不能重复增加该州兵籍。中央训练按新旧兵员人数加权。

### 民变与恢复

连续缺粮且安定低于25会累计风险，连续达到3旬后发生民变状态，每旬治安−2并损失部分地方现金，留下国政事件。已有官员叛乱建国与战争收复保留。

民政页的“赈后安民”要求最近一次供粮已经足额，每州每旬限一次，支银500两、安定与治安各+10、减少2旬民变累计。缺粮应先通过现有购粮、调粮与生产调整解决；持续足粮、恢复安定后可平息民乱。此首版民变为地方秩序与经济事件，不额外复制一支凭空产生的军队。

## 三、财政、人口与中央官员

当前数据结构和兼容范围以[数据字典](data-dictionary.md)、[存档兼容](save-compatibility.md)为准。本文“旧档补值”均以当前外层版本与内政schema有效为前提。

### 动态预算

兼容范围内初始化国家发展记录时冻结现有兵员、民伕、普通建筑作为基线，保留原常规预算；以后按增量调整，避免把整套历史支出再收一次：

- 士兵每增加1人：每旬兵饷增加0.04两。
- 民伕每增加1人：每旬薪俸增加0.015两。
- 普通建筑每增加1座：每旬维护增加2两。
- 当前军需按实际士兵每人0.025两、民伕每人0.01两计算并按国家取整；没有散件装备维护基线。
- 行政服务另加各州 `人口×0.0002×(0.5+生活水平/100)`，全国求和后取整。普通建筑另加每座3两的当前维护，各州取整；带当前规则版本的特殊建物每项加20两维护。
- 平衡规则1另按`round(Σ各州 人口×0.0013×max(0,生活水平−50)/100)`收取繁荣公共服务费，计入行政开销；新局本国中央其他收入400两/旬，旧档原值保留。
- 在职官员每级官阶增加2两/旬、每级爵位增加5两/旬；致仕或死亡不继续收取增量俸禄。
- 支出不会因削减兵员或设施变成负数。常规财政和报表使用同一动态费用函数。

中央户部主官能力相对50的差值，按税收×差值/500调节常规收入；清廉低于50部分产生税收×差值/1000的损耗，计入常规支出。工部影响特殊工程实际费；礼部能力与国家真实兵力相对差异进入谈判评议；刑部能力影响调查可发现的低忠诚范围。缺职采用署理能力50、清廉50，不在查看报表时扣款。

这是把现有预算升级成“原有基线+可解释变化”，没有同时废除原有国库、债务与税基公式。基础开局仍较宽裕，长期平衡数据单独归档。

### 人口与生活水平

每年正月上旬、正常旬供粮之后结算：足粮且安定至少50，人口增长0.4%；否则减少0.2%。变化落在未分配人口，不能删掉已登记四业人员、士兵、民伕；最低保留全部职业人数加1。

无灾、足粮、安定与治安均值至少60、农业开发率至少40%、税率不高于20%时，生活水平每年+2；缺粮或税率超过30%时−2，范围0—100。生活改善增加少量地方现金；生活等级按20/40/60/80分为尚可、小康、富裕、极富，低于20为贫穷。

足粮、无灾、无在建产业项目且地方现金至少500两时，地方每年用自有现金按5两/亩开发最多100亩农业，不扣国库，也不凭空增加地方现金；新增面积从下一旬产出启用。

迁民只移动本国两州的未分配人口，每笔1—10000人、每人0.1两，两州每旬各限参与一次；迁入州须无灾且安定至少40。总人口守恒，不将已就业人员或军户悄悄改职。

## 四、外交与条约义务

既有谈判增加礼部任职能力、双方真实兵力差异，兵力修正限制在±10分。原友善、威望和经济承担条件仍保留。

- 防御同盟和保护关系：被攻击国的合格第三国盟友按真实国库援银，每国最多500两；有实际军需援助时守方训练增加5点，总加成最多20，不创造士兵或装备。同一开战命令只履约一次。
- 玩家作为援助方收到待办时，可支付500两或拒绝；拒绝解除相关条约、友善−20、威望−5。待办与结果均可重载。当前没有新增外国主动经营/主动宣战AI；该请求机制支持第三国冲突调用，不能据此宣称外国战略AI已完成。
- 赠礼修好：100—10000两，真实双边划款，每500两向上取整增加1点友善、最多20点，每国每旬一次。赠礼不自动缔约。
- 议和：敌对且友善达到50，对方接受解除敌对，贸易另议。
- 保护国归附：我国为保护方、友善至少90、我国威望至少90，对方每次同意移交一州，国库支付10000两安置费用；使用既有占领、任官与驻军治理机制。此路线覆盖岛国，无需虚构本轮已完成海战。

## 五、统一皇室、成长与继位

外交玉牒与后宫出生记录共享稳定身份。出生皇嗣同步进入外交名册；两条和亲入口统一年满16岁，任一入口出嫁后另一入口不能重复出嫁。储君不能外嫁，在位君主不能被再次册为储君或重新赐名。

外来公主保留其外交身份，同时生成独立后宫身份，可册封、冷宫、召回、相伴及生育，不占用某位本国人物的原身份。立绘复用现有素材和配方，没有新增批量人物素材。

- 3—17岁在宫皇嗣可亲授，每旬每人一次，200两、学养+5、育亲+3；学养与育亲封顶100。
- 可为在宫宗室赐名，并同步出生记录；16岁以上未婚在宫皇嗣可立储。
- 官员每年增龄，在职经验+1；70岁致仕，85岁寿终。退休后继续增龄，原职留空待任命，事件永久进入有界历史记录；培养属性有成长标识，历史资料刷新不覆盖已发生的成长。
- 太后每年增龄，90岁薨逝后慈宁宫变为祭奠叙事；后宫成员90岁寿终移出活动名册，腾出名分，保留姓名年龄和死亡旬；成年子女与初始宗室90岁寿终。既有少年皇子夭折与孕期事件保留，已故人物不再增龄或重复出嫁。
- 在位满50年、有成年储君且皇陵已启用，可以主动禅让，归档本朝。
- 寿终或禅让等终局后，有16—79岁的在宫未婚储君，可从“本朝终评”点击继位。国家、领土、钱粮、兵籍、条约、工程保持不变；新帝按储君年龄与学养初始化个人属性，寿元按80岁目标重新计算。先朝嫔御退居、宗室留于玉牒，新帝按玉牒中生母记录设置慈宁宫，旧档生母缺失时明确显示未载，不把先帝年轻嫔妃硬认作新帝生母。新帝可重新经营后宫；不把先帝嫔妃直接当新帝后宫。最多保留最近20朝终评和5000条先朝嫔御身份摘要。

继位后在位年数从新的起始旬计算，世界日历连续；下一次禅让须新帝自己的在位年数达标。

## 六、称号、封禅与特殊终局

称号按当前皇帝500量纲判定；官员能力仍为0–100，两者不能混用。以下为本项目规则，不冒充原版复刻。

|称号/事件|项目试行条件|
|---|---|
|智慧、武术、魅力、才艺皇帝|对应属性达到500|
|铁人皇帝|体力上限达到500，竞技场提供一条可达路线|
|长寿皇帝|年龄达到100|
|天王皇帝|全部州郡实际归属本国|
|天可汗皇帝|保护至少3个仍有领土的国家|
|孝道之君、慈父慈母|孝道/育亲达到80|
|封禅冠冕|威望至少80，每年一次、支银3000两|
|禅让|本帝在位满50年、合格储君、皇陵启用|
|霹雳升仙|实际统一全部领土、至少十州且全部生活水平80、全国平均安定治安80、四艺500、长城与皇陵启用、孝道育亲各80、至少三次封禅|

称号取得后本朝保留，不因属性暂时降低反复发奖。封禅、禅让和升仙均显示前置条件，结束本局需再次确认；不满足条件不改动任何状态。终评记录结束原因、冠冕、称号、孝亲育亲与储君；可按现有导出流程留存或由储君继续新朝。

## 验证与实现边界

`npm test`覆盖原有玩法与新增专项：工程费用一次入账、停复工与停建、归属变更、全国效果、能力成长重载、统一婚盟、外来公主、教育赐名立储、家庭寿终、官员退休后自然死亡、人口迁移与军备回调守恒、动态费用、民变恢复、城防地形、双边军援与赠礼、议和归附、称号封禅、禅让升仙和可玩继位、坏档拒绝与保存失败回滚。

`npm run test:longterm`验收宰相/工部入口、工程预估和确认/取消、写盘失败重试、宗室教育与储位、七页布局、1440/900/390窗口、重载完工、封禅与终局条件，以及储君继位后返回可玩皇城。

`npm run test:longterm-balance`在固定随机序列和灾害种子1/7/41下运行普通经营、书院加全国委任、严重低产三类各108旬，在36/72/108旬重载与对账；结果为[长期经营验收数据](longterm-balance-results.json)。随机祥瑞保留，因此缺粮情景的全国人口不必单调减少。基础经营仍有较大财政余量；维护成本已随军队与建筑变化，低产压力则仍会造成生活水平和安定恶化。没有用“账目正确”替代“全部参数已平衡”的结论。

巡游狩猎、药材炼丹和水路战斗仍未纳入本轮用户选定的P2条目。外国战略AI、玩家守城与真实盟军、长期经济调平已在后续P1实现，详见[外国战略与防御实施说明](war-rules.md)。家庭与特殊结局规则为明确的首版项目设计；不能据此宣称完整复现所有有争议的原版结局矩阵。

本轮最终验收：280项测试通过（其中30项长期扩展专项），包含实际1800旬的五十年在位、禅让与可玩继位；长策、战争、财政及P0/P1桌面回归通过；九组108旬经营结果已保存。
