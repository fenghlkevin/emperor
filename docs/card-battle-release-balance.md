# 第一阶段生产版平衡复核（v5）

日期：2026-10-22。使用实际游戏的 `cardAI` 与 `actCardsMutable`，不是独立的 Python 近似模型。完整数据见[统计结果](card-battle-release-results.json)。

## 结论与范围

本轮完成了开局可出牌、整回合、先后手随机、实际兵种入牌、国家与人物无隐藏加成、训练收益、兵力收益与真实战损的实现和复核。不能将有限样本的平均五五开解释为所有牌序、人类水平、阵容与操作都严格50%。
主矩阵共144000局，72个同质量镜像条件。先手平均得分50.32%，逐组范围44.40%～55.85%。68/72组点估计在45%～55%；旧设计的每组47%～53%理想目标只有55/72组命中，不能标成该理想目标全部通过。

开战由随机数决定先后手，玩家不固定先行；在同质量、同策略的条件下，交换玩家／国家标签的120对重放、12891步动作与状态逐步严格镜像。这样排除了国家标签或主客身份的隐藏优势；先后手本身仍有具体阵容差异。

## 样本与方法

| 项目 | 条件 | 实际局数 |
|---|---|---:|
| 主矩阵 | 8军阵×训练20/60/90×3主将；每组1000个独立种子对 | 144000 |
| 策略敏感性 | 5军阵×3主将×进攻/交换两种倾向；每组500种子对 | 30000 |
| 100人物 | 每人100种子对镜像，加100种子对技能消融 | 40000 |
| 训练与兵力 | 9组训练差、6组兵力差；每组500种子对 | 15000 |
| 合计 | 不含调参诊断、结构测试与身份重放 | 229000 |

每对牌序A/B固定后交换先后手；人物卡在每对中按同能力同模板生成，跨对变化固定模板变体。双方用同一启发式，仅读取公开场面、自己手牌和已知牌库组成，不看对方暗牌或未来牌序。95%区间按独立种子对得分的正态近似计算；平局半分。工作线程实际接收的种子域逐行校验，调参样本不混入本报告。

## 人物与来源公平性
全部100名历史定义都有真实部署记录。人物镜像整体主方得分50.26%、先手49.40%。单人只有200局，不能按小样本给100人排强弱榜。消融组保留同费、同身体，去除一方专属关键词/登场/遗计；它是研究对照，不是游戏里的可取得卡牌。

随机人物按实际能力抽取专有模板后持久化；同种子同能力同预算，文臣低武力受攻击上限与突袭门槛约束。外国没有凭接入卡牌就得到更高能力。存档保留人物实例、历史定义、肖像、模板、潜力和成长记录。74名有既有可追溯身份，26名原作人物仍保留史实待考标记。

真实军粮、士兵、亲卫与各来源装备通过整场保存/续战/结算测试；死亡峰值不因治疗返还士兵，烧掉未上场的牌不产生阵亡。旧v1/v2存档沿原引擎续战。
