# 吏部尚书

朝堂召见吏部尚书，办理官职调动、官员外调、封爵、地方委任、制举。官职表采用十四职横列，可翻页、查询；调职同步刑部名册，以稳定官员ID记录身份，原任转为待命。外调需二次确认，永久删除官员并记入不再征召名单。加官与封爵各有独立等级，每次忠诚+10（最高100），逐级赏银100–900/600两；调职忠诚+5。

制举500两，下一旬基础呈上5–15人（新制吏部尚书最多额外2名，并提高名士及高能力新秀选拔概率），按皇帝魅力与智慧影响的概率，从当前开放历史名单及本朝随机新秀中生成候选；保证文职、武将都有代表。现役和退职姓名排除；历史名单不足时由新秀补足，不按完整史料库人数决定本届人数。逐人录用为待命官员后可调职；候选与筹备状态支持存档，详情见[制举说明](examinations.md)。

地方委任在常规内政结算后，按缺粮、灾情、民生、农业余量、设施和军务依次处理，共享全国预算及国库保留线（默认各2000两，可设置）。练兵基础100两，增量按刺史效率计算、最高训练100；训练低于80时优先练兵。其余条件允许且兵员不足人口1%时，从未分配人口中最多征100人，每人4两，不附送装备；治理损耗另计。灾时优先购粮并暂停新工程与军务，失地撤销委任，关闭委任不取消已有工程。详见[地方治理](p01-governance-and-progression.md)、[数据字典](data-dictionary.md)与[结算顺序](turn-settlement.md)。

## 翰林院研习与个人潜力（2026-10-19）

吏部尚书新增翰林院入口。只录入有效在朝但没有官职、没有地方辖区的待命人员；最多1–3人（按尚书文职岗位能力每40点多1人）。可选择智力、武力、统率、政务中的一科（清廉、忠诚不可学习），同时积累经验。尚书空缺暂停；换任导致名额减少时按入院顺序保留当前名额，超额人员暂停而不扣费。应天书院原有清廉增长取消，当前不提供清廉培养，不另行替换为其他加成。吏部侍郎以政务、智力、经验均值提供0–25%研习进度加成，不能改变个人上限。

每个实际研习旬支银20两，遵守国库保留线。基础进度100/旬；每600进度增加1经验；所选能力低于70时每1800进度增加1点，70及以上每3600进度增加1点。院内能力培养上限80、经验上限100，并同时受到个人单项潜力限制。入院当旬不推进，科目切换、出院再入院保留该人各科进度，不额外结算同旬；任职、收押、致仕或离开名册后停止。经验与本科目均封顶不收费，可改修另一科。

随机候选在`createExamCandidates`生成时即保存`potential.version/base/caps`，初始能力与五项潜力一并持久化，录用只迁移身份而保留潜力。新生成随机人物采用第三版分层潜力（普通90%、优秀9%、奇才0.9%、百年一遇奇才0.1%，详见下文），依据初始能力与稳定人物编号固定各科禀赋；不得低于已有初值。已有第一版潜力保持原规则：增加5–20点，低段最高50、中段80、高段95。它不是训练后重算的“当前值＋若干点”，也不在读档或换职时重抽。普通本朝初始官员同样固定五维潜力；旧档缺失字段只初始化一次。现有高于潜力/院内上限的旧值不削减，但不能继续增长。

历史人物单独审定五维上限，不使用随机人物的成长公式。下表依据已有逐人史料、能力审定与补充史传设定；数值是游戏设计，不声称史书测得数值。诸葛亮与吕布补核《三国志》卷35、卷07：

## 礼部侍郎隐藏缔约辅助（2026-10-19）

在新制官员效果已启用时，有效在职礼部侍郎按政务、智力、经验均值，每10能力提供1点评议，最多10点，仅用于`kind=treaty`的缔约判定。它接入现有确定性评议，不新增掷骰、不改变外交授权或使臣抵京流程；贸易、贡银、和亲、解约及邀请使臣不受此项影响。空缺、待命、收押时加成为零，不凭空产生收益。

此项是隐藏被动能力：官职说明、任命效果对比、国政页面只显示“协助礼部办理通邦事务”，不展示具体加成数值或公式。谈判仍显示最终总评议与门槛，避免出现低于门槛却宣称成功的矛盾。预览与实际执行共用同一判定，不会因重复预览、取消或读档重新抽取结果。

任职加成统一通过`office-ability.mjs`计算，依据当前官职，不依据人物名册的“文职/武将”标签。每项属性先限制在0–100，三项均值四舍五入，最终能力0–100。
