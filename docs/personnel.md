# 吏部尚书

朝堂召见吏部尚书，办理官职调动、官员外调、封爵、地方委任、制举。官职表采用十四职横列，可翻页、查询；调职同步刑部名册，以稳定官员ID记录身份，原任转为待命。外调需二次确认，永久删除官员并记入不再征召名单。加官与封爵各有独立等级，每次忠诚+10（最高100），逐级赏银100–900/600两；调职忠诚+5。

制举500两，下一旬呈上5–15人，按皇帝魅力与智慧影响的概率，从当前开放历史名单及本朝随机新秀中生成候选；保证文职、武将都有代表。现役和退职姓名排除；历史名单不足时由新秀补足，不按完整史料库人数决定本届人数。逐人录用为待命官员后可调职；候选与筹备状态支持存档，详情见[制举说明](examinations.md)。

地方委任在常规内政结算后，按缺粮、灾情、民生、农业余量、设施和军务依次处理，共享全国预算及国库保留线（默认各2000两，可设置）。练兵基础100两，增量按刺史效率计算、最高训练100；训练低于80时优先练兵。其余条件允许且兵员不足人口1%时，从未分配人口中最多征100人，每人4两，不附送装备；治理损耗另计。灾时优先购粮并暂停新工程与军务，失地撤销委任，关闭委任不取消已有工程。详见[地方治理](p01-governance-and-progression.md)、[数据字典](data-dictionary.md)与[结算顺序](turn-settlement.md)。
