# 兵种套装军制

当前开放刀盾兵、长枪兵、轻骑兵、重骑兵、弓兵、弩兵、骆驼骑兵、象兵和弓骑兵。统一招募士兵，按驻地采购并分配完整套装。

## 操作

- 兵部「招募士兵」统一招募，每人4两；新兵按来源体能确定训练，按人数加权，招募不附赠装备。
- 「购买装备」购买完整兵种套装，包含武器、防具和相应坐骑。库存按可装备人数计量，不再逐件维护刀、枪、甲、盾、头盔或战马。
- 「出征编队」选择接壤目标、全军主将、亲卫兵种与人数、最多六个子队及不同将领。自动配装；也可按中央库存自动编队。人数允许残部，不限百人整数倍。
- 「调拨军队」可在中央与本国各州之间单独调兵、调装或一并调拨；人口与军籍只迁移一次。
- 守城从本州、中央增援及实际应约盟军分源编队，不能跨驻地借装备。缺装步兵作为伤害系数0.5的乡勇，不凭空生成装备。无在职将领时可由署理领队。
- 大将军保留训练、长期训练、治安检视；调拨入口导向兵部。户部采购导向兵部，宰相调回中央使用相同套装账本，军事总览展示库存、占用和可用。

将领加成、侧背击、城防和地形继续实际生效。重骑需要本次行动连续同向直行至少2格，并沿该方向攻击相邻敌军才获得冲锋；先手动移动再攻击也适用。转弯按末段重新累计，等待、防御、结束行动和回合更替清除冲锋，反击不享受冲锋。

各兵种共用兵员、军饷和粮耗规则，以套装采购价区分成本。

## 资源与结算

出战同时占用士兵及对应套装，不能重复用于调拨、解散或其他军队。士兵人数和训练直接读取原人口兵籍及中央军字段，不另存一份重复人数。

战后生还或撤退士兵携装返回原驻地；阵亡一人损失一人份对应兵种装备。缺装乡勇阵亡只损失兵员。结算编号不可重用，关闭动画后续战不重算伤亡。解散士兵还乡，装备保留；中央无兵时停止长期训练。

撤守按守方4%、攻方2%核算实际损失，生还者携装归营；仍承担原有失地或京城危机后果。迁都带走中央套装，降国时中央套装归入原京城降军库存。

敌国按完整套装报价补装，自动战役按真实来源及套装覆盖计算，不再补充零散刀甲盾。军事祥瑞分别给予刀盾兵或轻骑兵完整装备，通知文字与实际入库一致。

统一军饷和粮耗；不增加套装耐久、零件回收、修理、箭矢库存或动物饲养账目，也不按新库存额外收取旧零件维护费。

验证入口：`npm test`、`npm run test:kit-office`、`npm run test:kit-routing`、`npm run test:kit-heavy-combat`。完整开发与验收记录见 `troop-kit-development-progress.md`。

弓兵与弩兵现使用同一招募兵员、套装采购与出征账本。弓兵170两/人份，射程4格；弩兵240两/人份，射程3格、基础移动2格，可穿透部分重骑护甲。移动后射击分别保留70%、60%伤害；任一敌军贴身即禁射，只能以40%、35%的近战系数应战。非相邻攻击不触发反击，射击没有侧背击加成。没有箭矢消耗或独立补给库存。

骆驼骑兵、象兵、弓骑兵已开放。骆驼仅大食/柏柏尔产地采购，沙地伤害+20%、对普通骑兵+35%；象兵仅天竺/真腊/骠国产地采购，移动2、冲击伤害+25%、目标本次反击减半，象鼻绑刃随姿态运动；弓骑仅东/西突厥、回纥/铁勒产地采购，移动4射程3、移动骑射不减伤，远程基础伤害为专职弓75%。产地身份固定随州，不因归属改变；占领后必须稳定才能购买。失地停止该地产购，已调运装备保留。装备调拨本身不限产地。

盟军编队名额不足时只派出可容纳的实际齐装队，其余带装备留在原驻地，不自动降成乡勇；战报注明实际出战与留营人数。九种装备齐全的驻地可编入九种兵种，不虚构装备不足。

敌军成长遵守同价采购：先付费买完整装备，再按可覆盖的空闲装备与国库招募；缺装时先补现有驻军，不再每轮无装征百人。新兵训练与玩家一致按来源体能加权。自动编队兼顾已有特色、远程与近战，名额外兵装留营。主将AI在子队仍作战时优先留后防御，遇威胁后撤，避免会被本次反击及紧邻威胁击溃的攻击；主将退场判负规则不变。


军备体系只有当前九兵种套装一条实现。中央及地方仅登记兵员、训练和套装库存；不存在零散军械库、装备值、切换军制开关或旧战场升级。亲卫选择实际兵种，费用、兵籍、占用和阵亡与普通部队同账结算。旧进度不转换；缺失或不完整的套装数据不能加载，但不妨碍开启新朝。地方委任与中央统一按4两/人招募。
