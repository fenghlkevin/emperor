# 城市属性关联检查与农牧工商资源口径

## 已实现的资源规则

农业、牧业提供粮食；商业、工业提供银两。资源新制在相同有效用地、用工、生产率、地形加成下，农业基础产粮0.18石/亩，牧业肉乳等折粮0.06石/亩，农业是牧业的3倍。实际总产量仍取决于投入，不保证无农人州农业总产量高于牧业。两业均按本业用地、对应职业人口和生产率计算，官员生产加成只应用一次。

农牧粮食先满足当地民间口粮，粮赋统一进全国粮库；国库供给军籍、民夫和实际赈济缺口。工商产银经过税率、动荡、治安与官员征收效率进入全国国库。产出不等于税收，粮食不重复折银征税。新资源快照保留农牧各自基础和最终产量，校验分项总和与官员取整。旧的农业单来源历史快照继续可读，不补造牧业历史、不重新结算已过旬。

工业原货物产量先按0.8折银，后续税基直接使用折银结果，不再二次折算。旧资源分支未来生产也采用农牧供粮、工商供银，但不强行重置旧用工记录或历史库存。

## 检查发现与处理

1. 牧业此前只进入银税、不进入粮食；已按新方案修正，并覆盖粮食自给、粮赋、全国分配、预测与报表。
2. 旧资源分支曾把农业折银征税，和当前钱粮解释不一致；已删除农牧银税，农业开发不再凭空增加银税。
3. 四业景气是产能利用程度的派生值，不是第二次生产加成。扩城后分母增大，分数可能下降而实际产量不降；说明已明确。它不适合单独代表绝对国力或可支配收入。
4. 灾害目前降低钱粮库存和安定、阻碍工程和部分民生恢复，但没有直接削减当旬产业产量。这是生产模型的规则缺口，尚未新增未议定的减产比例。
5. 民间余粮与官粮分开。全国供粮共享的是粮赋和官库存粮，不是自动没收所有民间产出；跨州民间余粮不会无条件充当另一州赈济。这是现行制度，若要实现民间跨州流通需明确交易、损耗和征收口径。
6. 农牧改供粮后，工商成为银税来源；开局常规结余可能由盈余变赤字。这是新分工的平衡影响，不能靠重复征收农牧银税掩盖。应从工商发展、税率、兵员与支出治理解决，或另行议定平衡参数。

## 验证

专项覆盖：相同投入农业/牧业3倍关系；农牧停产不改变银税；工商停产不改变粮产；只有牧业仍能供粮；全国预测和实际守恒；同旬不重复结算；官员加成分项取整；伪造来源拒绝载入；农业单来源历史记录兼容。另跑全量回归与州情桌面验收。
