# 普通建筑民生收益

实施日期：2026-10-16。按[P0方案](research/emperor/P0内政与财政开发方案.md)接入普通建筑，以下均为本项目试行数值，不作为已验证原版规则。粮食救济、人口自然增长、战棋城防与巡游当前已由对应模块接入；本文件只描述普通建筑收益。完整结算顺序见[旬结算顺序](turn-settlement.md)，兼容范围见[存档版本兼容](save-compatibility.md)。

## 七类建筑

|建筑|每旬收益或作用|条件与下游|
|---|---|---|
|寺庙|每座安定+0.25，每旬最多+2|本旬足额供粮；影响下一旬民乱风险|
|衙门|每座治安+0.25，每旬最多+2|不因灾害统一停用；影响下一旬盗匪风险|
|市集|每座营业+0.25，每旬最多+2|商业增益为高于迁移基准营业的数值÷600，最多+10%；不影响其他三业|
|校场|每座体能+0.25，每旬最多+2|新兵训练=floor(当前体能×0.2)，中央征募按来源州人数加权，地方委任征兵采用同一规则；不自动提升老兵训练|
|粮仓|灾害粮损乘1/(1+粮仓数×0.1)，向下取整|只保护粮食损失，现金和民生损失不豁免；不生成粮食、不改变口粮和积粮分母|
|城墙|防御=基准防御+新增城墙数×5，上限100|下一旬生效；实际进入战场防御系数；与地形和长城效果合并封顶1.5|
|行宫|每座民忠+0.1，每旬最多+1|本旬足粮且无活跃灾害；被动恢复是项目简化；已建行宫同时决定巡游目的地资格|

商业先用既有公式计算并取整基础产量，再乘营业修正取整；税基只计入修正后的商业一次。完工当旬的面积和营业收益不会追溯改变已发生的产出。市场增益低于基准时按0处理，不额外减产。

## 时点与小数

旬结算先处理灾害、产出及口粮，再判断缺粮，扣既有缺粮惩罚，随后结算建筑恢复，最后推进营建工程。新竣工建筑在下一旬才参与恢复、粮损保护和防御计算。灾害风险实际抽取发生在恢复之前；恢复自下一旬影响风险和商业生产。

寺庙在缺粮时停止恢复，行宫在缺粮或活跃灾害中停止恢复，衙门、市集、校场仍可恢复。效果记录分别保留本旬供粮条件、灾情、有效建筑数、各项恢复和防御结果。重复结算同旬或重复读档不再次收益。

小数使用整数百分之一点余数保存，例如4旬×0.25累计为1点、10旬×0.1累计为1点。主民生字段保持整数，报表、风险、商业产出和新兵训练读取同一有效值；界面指标显示四舍五入整数，收益明细显示小数。负面事件和政令通过共用变更函数处理，指标到0或100时清理余数，不残留越界小数。

## 展示与委任

工部尚书“普通营建”和工部侍郎的省份民生详情增加收益表，展示实有/当旬有效建筑数、收益与条件、最近实际恢复、延迟启用旬及继续建设的边际收益。选择已封顶建物时明确提示“当前收益已封顶”，玩家仍可自行选择营建。

地方委任保留原有费用、预算保护线和训练/征兵策略，仅筛掉恢复速度已封顶或指标已满的无效新建候选，避免继续为无额外收益的建筑支出。自动治理当前已接入购粮救济、全国预算和国库保留线，见[地方治理](p01-governance-and-progression.md)。粮仓的保护仍有边际收益，不能与固定恢复上限的建筑一概判定为封顶。

## 存档兼容

每州新增独立版本 `buildingEffects.version=1`，保存营业、防御及城墙基准、百分之一点余数、最近结算和待启用建物。新局及兼容范围内缺少建筑效果记录的档案以当时实际营业和防御为基准，不使收入或防御在加载瞬间跳变。既有建筑自下一次完整旬结算起生效，不补发历史收益；在建普通工程、产业队列、人口、银粮和费用保持原样。

读取不重算叠加防御；新增城墙的增益相对固定基准派生。未来若引入其他防御事件，应修改基准或增加独立修正，不应直接覆盖派生防御后重复叠加。无效版本、余数越界、非法基准、未来结算或错误竣工标记会被拒绝。

灾害历史新增未保护前粮损和粮仓保全数量，新记录满足“原粮损=实际粮损+保全”。旧灾损历史缺少这些字段仍可读取，不伪造历史保护效果。

## 验证

建筑专项覆盖B01—B08，以及同旬防重、恢复与风险顺序、委任跳过无效建设、迁移及坏档校验、保存失败回滚。产业开发专项隔离市场收益，继续独立验证原来的开发增产时点；原征兵断言同步为体能加权的新兵训练规则。

桌面专项：`npm run test:building-effects`。包含工部和民生报表、小数恢复、粮仓保护说明、延期启用、旧档、保存失败回滚及900×680窗口。另回归 `npm run test:industry`，检查既有开发与职业调配流程。现有内联样式CSP提示未在本次调整，其他控制台错误仍使桌面测试失败。

本轮最终结果：211项单元测试全部通过；建筑收益桌面专项和产业桌面回归均通过。截图已检查，收益表和小窗口滚动正常。

粮仓同时保护周转存粮：安全库存为18旬口粮，每座下旬有效粮仓增加2旬，最高36旬；仅期初超出部分每旬损耗8%，向上取整。详见[粮食救济](food-relief.md)。
