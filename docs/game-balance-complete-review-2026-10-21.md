# 游戏整体平衡复查 · 2026-10-21

## 结论

第二版解决了默认开局迅速负债、官粮严重膨胀、免费训练和官职映射等问题，但**目前仍不能认定整体平衡已经完成**。本轮发现8项需要处理的事项：2项优先处理的战斗资源/AI经营问题、4项策略与评价设计问题、2项收益归因/说明问题。每项均给出方案和验收条件，区分确定的计算问题、可重复的策略结果和需要确认的设计取舍。

本轮只检查，不调整游戏数值或运行规则。完整结果、源码指纹与覆盖范围以文末最终记录为准。

## 方法

- 使用 `createPlayableGame`，与应用真实新局共用资源、地方自治、官效和发展版本2；不是旧 `newGame` 兼容夹具。
- 从当前工作区冻结源码，再在同一快照上运行最终检查。并行的巡游/画像改动不混入快照内的运行结果；快照时间、逐文件SHA256和压缩包另外保存。
- 完整基础对照：原23组、17640旬，默认/人工经营/委任/产业开发/高税/特赦/祭祀/书院/运河，固定灾害种子1、7、41，逐年JSON存读档。
- 新增策略对照：20%、27%、29%税率搭配定期特赦，以及先50%一年、再20%十九年的恢复路线；每条3种子，共12组8640旬。普通政令走业务API并扣实际办公成本，不注资、不补人口或装备。
- 新增完整世界：开启外国AI经营和战争，3种子各360旬，共1080旬；需要时走业务自动防御，不用额外资源救局。
- AI因果对照：明确关闭灾害与战争，分别不扩军/调用真实扩军函数，2组共720旬。该组是隔离夹具，不代表完整世界。
- 静态反事实和压力夹具独立标注：出战兵种、未出战装备库存、设施为零、财政分类、战损、土地硬上限等，不冒称普通游玩路线。
- 全量业务/类型测试与新增页面专项另行执行。测试通过与“策略是否平衡”是不同结论；上一轮旧桌面脚本的覆盖缺口不会计入本轮通过证据。

## R01 · P1 · 出征粮耗读取库存比例，未按实际出战兵种计算

**证据**：同一真实新局、相同将领、200人编队，两个合法报价：

| 实际出战 | 报价中的骑乘占比 | 实收军粮 | 按当前设计公式应收 |
| --- | ---: | ---: | ---: |
| 200刀盾兵 | 25% | 18石 | 16石 |
| 200轻骑兵 | 25% | 18石 | 24石 |

`military-costs.mjs` 从中央军营**全部兵装库存**计算比例，`kit-war.mjs` 虽已有实际编队，却只传总人数。给同一纯骑兵编队的军营额外放入10000份未出战长枪装备，报价从18石降到17石；这是标注的库存反事实，不是免费获得装备的普通路线。

**影响**：轻重骑兵及特殊坐骑的后勤选择未按承诺兑现；留营库存影响出战成本。

**方案**：补给接口接收已校验的实际编队，按实际骑乘人数/总出战人数计粮；银费、官效和牧业折扣也从同一次报价生成快照。保留旧快照规则，不用现有库存倒推旧账。

**验收**：200纯步兵16石、200纯骑兵24石；同一编队增加/减少未出战装备不改报价；开战实扣、保存、重载、结算都使用相同快照，分别覆盖混编与特殊骑乘兵种。

## R02 · P1 · 外国AI只有现金门槛，未来军费与灾后恢复约束不足

**证据**：开启完整AI的10年三种子检查中，41个外国分别有15、15、13国负债，15–16国期末常规预算为负；国债合计约10.7万–17.2万两。不能把这些债务全部归因于扩军，灾害和外国间战事也在运行。

进一步隔离到好望角：关闭灾害和战争，仅比较真实扩军函数：

| 10年对照 | 初始兵员→期末 | 初始预算结余→期末 | 期末现金/债务 |
| --- | ---: | ---: | ---: |
| 不自动扩军 | 1400→1400 | +76→+35两/旬 | 22262 / 0 |
| 允许自动扩军 | 1400→1858 | +76→+4两/旬 | 2902 / 0 |

该对照本身没有破产，但证明扩军会吃掉大部分安全边际。`growForeignKitArmy` 的目标统一为人口2%，而新档位初始军率为1%–1.6%；管理逻辑主要检查现金高于3000，缺少新增军饷、军需、粮耗和灾备的持续预算预测。完整AI还继续付费训练和兴农。

**方案**：按显式势力定位和威胁确定目标军率；征兵前计算至少未来12旬的军费、粮需与灾备。经营性赤字时暂停非紧急扩军和练兵，优先恢复生产与偿债；紧急防御另设有上限的例外，不凭空补钱粮。

**验收**：重跑全部外国开局与3种子10/20年AI；隔离灾害、战争、扩军、训练分别归因。没有战损/灾害的稳态国家不能因日常扩军进入结构性赤字；重灾国家有可验证的恢复策略和明确困难势力定位。

## R03 · P2 · 定期特赦的代价偏弱，高税的政治成本可被低成本对冲

**证据**：特赦每12旬可办理一次，全国民忠+3、治安−1，直接银费为0；办公成本已按规则扣除。治安损失通常能由现有衙门服务恢复。每12旬一次，20年60次：

| 路线 | 期末国库 | 国债 | 生活 | 民忠 | 治安 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 默认20%，无定期特赦 | 1.97万–5.89万 | 0 | 65–66 | 51 | 71–72 |
| 20%+定期特赦 | 2.50万–6.95万 | 0 | 65–67 | 78–80 | 72–74 |
| 27%+定期特赦 | 31.86万–35.29万 | 0 | 60 | 50 | 78 |
| 29%+定期特赦 | 34.05万–40.20万 | 0 | 56 | 41 | 76–78 |

27%/29%并非无代价：生活和民忠明显低于低税路线；因此不把它们误称为对所有指标都占优。但全国忠诚收益与固定−1治安不随规模/反复次数变化，使特赦很容易成为定期必按的低成本对冲。相同福利/岗位下的静态税压平衡点也在约27%，不能只检查25%与50%两个端点。

**方案**：给连续特赦加入年度次数收益递减、司法积案/再犯风险或按实际案件规模计算的支出；保留紧急安抚用途。不要仅加一个会被建筑恢复自动抵消的短期治安扣点。若明确把它设计成税收政治经营路线，需让长期民生与司法代价进入终评。

**验收**：18%–30%税率扫描；无特赦/偶发/每12旬重复三组同种子对照。保留至少三条有不同优缺点的可行路线，不让一个低成本周期按钮取代大部分地方民心经营。

## R04 · P2 · 财政评价遗漏经常性“单次”支出，窗口实际只有一年

**证据**：`fiscalHealth` 只汇总 `categories.regular`；治理、训练等实际可能反复发生的交易记在 `oneOff`。有效账本最多保留36旬，即一年，并非多年。

隔离会计夹具每旬收入1000、常规支出900、另有经常性支出100，36旬实际总盈余0；该函数仍返回经营净额+100/旬、经营分70、综合财政分83。这里是会计分类反事实，不是普通开局的自然评分。

**方案**：区分经常性经营支出、资本建设、一次性灾损、债务本金和赠与。对治理、维持训练等经常项目计入经营口径，另保留总现金流；建立有限长度的年度汇总或滚动趋势，不能把资本投资全额简单当作经营亏损，也不能把所有 `oneOff` 忽略。

**验收**：同一经济活动换交易类别不能无故改善经营分；经营净额与实际日常收支对账；长期赤字不能仅靠最近一年好转迅速被判为高度健康；新旧存档不补造历史收入。

## R05 · P2 · 高税失误后的自动恢复路线很长，降税并不等于出债

**证据**：仅第一年50%税，然后正常改回20%，保留默认委任和正常宫廷维护，再运行19年。三个种子降税时已有约9760–12024两债务；期末仍欠50768–73084两。

种子1在第37/109/361/721旬的债务为12024/124172/111867/73084两；民心与生产恢复有滞后，后期在逐步还债，不能据此说“债务机制完全不能恢复”。这是严重高税失误的恢复检查，不是默认开局失败。

**方案**：增加可理解的债务应对模式：委任主动降低可选开销、保留必要供粮和治安，明确展示持续利息、预计现金缺口和本金恢复期；对正常经营盈余先留出偿本额度，再批准可选投资。不要靠免费清债掩盖后果。

**验收**：小额经营债务、短期高税、重灾三类初始危机分别测试；给出可执行的政策组合、最低生活/粮食约束及预期恢复年限。若故意把一年50%税设计为长期重创，必须在调税预览和危机反馈中明确提示。

## R06 · P2 · AI的中立宣战资格仍由ID哈希决定

**证据**：非敌对关系主动宣战路径包含 `hash(country.id)%3===0`。41个外国仅13个满足；本国六个接壤对象中只有奚、林邑满足这条资格。28国仍可在敌对关系等其他条件下参战，不能说它们永远不会打仗。

完整世界3种子各10年均没有玩家防御战，但全图有1–3国被吞并，不能说全图没有战争。该结果本身不足以证明玩家绝对安全；结合代码，可以确认威胁资格来自技术ID，而非显式的势力战略定位。

**方案**：将战争倾向、邻境威胁、经济承受力、扩张目标显式配置，使用可复现随机源决定行动；保留预算与停战约束。重命名技术ID不应无意改变势力人格。

**验收**：固定地理与战略档位，改变非语义ID不改变侵略倾向；多种子验证边境压力、战争频次及军需消耗，分别统计全球战争和玩家遭袭。

## R07 · P3 · 零设施基础恢复与建筑收益的归因需要澄清

**证据**：将五类恢复设施数量设为0、福利设为20的反事实中，安定、治安、营业、体能、民忠每旬仍各+0.05；基础服务目标为45，民忠为50。这不等于整个国家无成本恢复，政府仍有行政支出。

**方案**：若这是基础治理能力，单列“基础治理恢复”，与具体建筑边际收益分开展示；若恢复必须依赖对应设施，则数量为0时设施收益应为0。不要把基础目标和设施投资收益混记。

**验收**：0/1/多座设施、人口扩大、缺粮及灾害的归因一致；预览、结算和报告分别对账基础治理、设施、特殊工程和政策效果。

## R08 · P3 · 长期训练报价仍承诺旧训练保底

**证据**：第二版实际已取消训练保底，补入新兵后只能逐旬恢复；但 `quoteGeneral` 返回的说明仍为“维持不低于当前……”。初始报价为60，若开启时训练100则会承诺100，而实际合法补员后的训练为66、下一旬68。

**方案**：按规则版本生成说明：第二版展示每旬真实增量、费用、保留银线及暂停条件，并明确新兵/调兵会稀释训练；兼容档才说明旧保底。

**验收**：训练100→开启长期训练→补员→存读档→跨旬，界面与报价不得承诺立即恢复100；费用与实际提升一致。

## 城市、产业、特殊工程和军备恢复的其他判断

- 建筑按人口覆盖提供服务目标、工程共享民夫、分期计划按开工付费、灾害停工等约束仍有效；不能为追求增长把它们移除。
- 农牧工商的边际结果按州、土地、实际新增从业和各自单位分别记录。农业与牧业不能直接和银两产业相加排名；粮食过剩时农牧的边际用途主要在灾备/军需，工业的兵装采购收益取决于真实补装需求。
- 城州扩建将人口与土地捆绑：土地达到地形上限后，人口专项扩容也被拒。这是明确存在的设计边界，不直接认定为计算错误。若希望成熟城市还能提高人口密度，建议增加独立的人口基础设施升级，保持地理土地硬上限。
- 按真实军籍损失后报价：中央损失400人，补员补装约7709两；中央1600人全部损失约30833两；全国25%损失10325人约198882两。后两项明显超过18000两初始现金。它们是比例战损/报价夹具，不是已实测的战术胜率或完整复建路线；不能把“中央400人可恢复”推广成“全国任意中等战损可迅速恢复”。
- 应天书院已有实际武力培养，分段工程有真实收益；初始报价记录受益人数与门槛。高才艺/高劳力工程的开工条件仍需靠正常发展满足，不通过审计注资解锁。
- 贸易额度、真实邻国供粮、付息还本、征兵占岗、人口与装备守恒仍是应保留的有效机制；本轮没有发现它们恢复为旧的免费训练或凭空补粮问题。

## 处理顺序

1. 修正实际编队的补给快照，恢复兵种后勤选择的真实性。
2. 对外国AI的新增军费、灾备、经营性赤字建立持续预算约束。
3. 联调特赦、高税和终评口径，明确债务恢复策略，做完整税率扫描。
4. 把战略倾向从ID哈希改为显式配置，再评估战争压力与军需节奏。
5. 清理基础治理/设施收益归因及长期训练旧说明；同时修复旧桌面脚本的覆盖缺口。

不能只提高初始银粮、统一涨价或减少全部灾害来让结果变绿。
