# 人物属性与简介

全员设计版完全移除姓名、编号取模生成能力的算法。2481人均在 `src/historical-designs.json` 保存独立的五项设计卡；重建时缺任何一人、任何维度的分数或依据都会报错，不再回退通用分档。五项0—100的能力是史实表现的游戏化设计，不能当作历史测量值。

| 属性 | 评价内容 |
| --- | --- |
| 智力 | 谋略、判断、学术或技术理解 |
| 武力 | 个人武勇、骑射、近战；不把兵法、官阶当武艺 |
| 统率 | 军队组织、战役指挥、兵种协同与军事后勤 |
| 政务 | 行政、财政、制度与地方治理 |
| 清廉 | 廉洁和公私操守，独立于能力，也不等于对当前君主的忠诚 |

重要人物由 `src/historical-ratings.mjs` 逐人写明五项分值、人物特点与史事摘要。例如朱熹智力94、武力12；孙膑智力98、武力8、统率96；陈庆之武力28、统率97；秦桧智力89、政务87、清廉8；和珅政务92、清廉1。名臣、名将、清官、谋臣、权臣、奸臣、忠烈等标签与分值分别处理，不用单一善恶评价替代能力。

其余人物同样保存独立设计卡：使用本人传记正文、明确任官记录、著述记录，分别处理学识、技术、外交、临阵武勇、领军、防务、治军、后勤、胜绩、败绩、制度、财政、赈济、司法、教育与操守行为。五项分别保留原文证据及取舍，不把职业头衔直接当作高阶能力，也不借用父兄或同名人物的成就。统一的是评估尺度，而不是给所有普通人物套同一组分数。

设计方式如实分为“逐人史事审定”和“逐项史料设计”。后者依据本人事实逐项制定，不冒充全部经人工史论；每一条证据与每一个分值都在设计卡中明确保存、可逐人调整。个人记录不足的维度注明保守设计，不编造具体战绩或廉贪行为，不强求每个人的每个数值都不同。

新增专项审定覆盖刘宰、胡铨、韩侂胄、史弥远、杜衍、王应麟，以及司马错、陈泰、王基、高顺等。张苞按早夭、缺乏独立战绩的史实处理；陈武、马忠、王昶等明确采用名册时代对应的身份；刘爚的简介排除误配的清代同音人物。对于反对贪腐、弹劾权臣、遭诬陷的记录，不把对应罪行算到当事人身上。

入朝年龄30和忠诚65为游戏起点；经验依据本人任职、专业与实践记录设计，不再统一按普通人55等旧档位。已录用人员的当前年龄、忠诚、经验及官职爵位保留。随机数仅用于制举人数与抽取人选，不用于五项基础能力。

## 简介和来源

每人提供简介、简介资料类型、参考来源、评分方式与评分依据。简介分为手工史事摘要、百科导言节录、CBDB身份资料及事迹待考。查到的现代同名人物和明显生年冲突记录不作为古代人物简介。CBDB的基础身份资料不能自动证明具体战功、操守。

百科导言来自各人物维基百科页面，逐人保留页面ID链接与CC BY-SA 4.0说明。只保留截短导言，转换简体；文本节录及其改编依[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)提供，原作者及版本历史可从对应页面访问。手写摘要不是百科原文。CBDB身份信息来自[公开衍生数据](https://github.com/SousekiL/historical-figures-network/blob/main/data/network.json)，保留原CBDB编号和查询入口。

## 游戏与存档

吏部尚书增加“人物名册”，可按姓名、朝代、特点查找，按文武筛选。点击名册、候选表或任职表中的历史人物姓名，可查看简介、五项能力、来源和评分依据。录用、调动、封爵继续使用稳定人物ID。

存档加载时升级历史人物的五项基础能力及简介元数据；候选的初始年龄、忠诚、经验同步新版。已录用人员的当前年龄、忠诚、经验、职务、品级、爵位、刑部案件与存活状态保留。升级依据版本字段，已升级者不会在每次加载时重新设置属性。

先运行 `node scripts/design-personnel-scorecards.mjs`，依据已保存的本人事实与专项审定生成独立设计卡；再运行 `node scripts/rebuild-historical-profiles.mjs` 验证全员覆盖并重建运行时表。两步均不联网、不使用随机数。存档属性版本升级为4，已录用人员的成长和任职状态不重置。
