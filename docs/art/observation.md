# 观景台与御街朝拜

入口与轮廓均移至南侧中央城门楼。场景参考武道场的绘画风格与深绿金色界面。

国势采用本国人口加权指标：民忠25%、民生20%、安定与治安均值20%、粮食保障15%、财政10%、军备10%。财政以国库能覆盖六旬支出的比例计算，军备使用地方训练与装备的人口加权均值。各项限制为0—100，最终四舍五入。

朝拜人数 = 20 + 5980 × (国势 / 100)²，四舍五入，最多6000且不超过本国人口；无人口则为0。画面最多720个人物，按比例绘制，保留中轴御道。首次登台保存本旬国势及人数，读档与再次登台保持一致；每旬仅首次快乐+5、体力-1，仍沿用宫廷阶段限制与离场推进。

美术使用内置 image_gen，项目资源：assets/sketch-observation-v1.png、assets/sketch-observation-commoner-v1.png。

场景提示：以 sketch-martial-court-v3.png 为画风参考，南门城台向外俯瞰御街，成年金袍皇帝背对镜头、内侍与白玉栏杆在前景，空旷御街供运行时叠加人群，远景古城、红墙金瓦、暖色日光，无文字界面。

人物提示：透明底单个古代百姓，蓝灰布衣束发，朝镜头方向跪拜，俯视35度，手扶地、低首，柔和接触阴影，细腻手绘，缩小后仍清晰。
