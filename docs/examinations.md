# 制举人物规则

原作来源：`reverse/emperor/code-analysis/tables/person_templates_1.json` 的100名特殊人物。41名普通模板不作为历史名士池。繁简体及别名对齐现有史料人物；未匹配者保留原作模板并注明来源，不编造史料。已有2481人全库仍保留，名册与制举仅使用原作100名名单。

每届花费500两，下旬基础呈报5–15人。新制在职吏部尚书的选才能力为智力、政务、经验均值，每40点额外增加1名、最多2名（最高7–17人）。最后一名固定为随机新秀；其他名额的名士概率为 `0.05 + 0.35 × (魅力 + 智力) / 200`，两项皇帝属性限制在0–100；新制在职吏部尚书另按选才能力×0.0015增加名士概率，最终不超过80%。可用历史池为空时全部生成新秀。已任职或外调同名人物不再抽取。

新秀采用百家姓单姓、复姓与一至二字名字组合，避开完整历史库、当前官员及同榜重名。普通随机新秀的智力、武力、统率、政务采用两次随机取均值的分布，范围10–65，主要集中25–50；清廉独立按原范围生成，忠诚、经验和年龄独立生成。每榜文武兼有。优秀新秀选拔概率为基础0.5%加吏部尚书岗位能力×0.025个百分点，最高3%；文职智力或武将武力专长70–85，另一相关项（政务或统率）至少50–70，其余保持普通分布。吏部尚书空缺时仍保留基础0.5%，无尚书额外加成。个人潜力在生成时固定，成长仍受个人上限约束；历史人物、已有人员、名士概率加成和额外名额不受本次调整影响。

旧档非原作历史候选及官员移入 `personnel.hiddenPeople` 保留数据，退出活动名单；不改写原始人才库。随机新秀支持录用、任职、后续旬结算与存档校验。

随机新秀在生成候选时就写入个人五维`potential`（初值及固定封顶），不是入院或录用时再抽。录用、换职、研习和读档保留同一潜力；人物简介可查各项封顶，生成能力上限与成长潜力不是同一个字段。翰林院与书院训练均遵守个人潜力，详见[吏部与个人潜力](personnel.md)。

随机新秀潜力采用独立固定分层：普通90%、优秀9%、奇才0.9%、百年一遇奇才0.1%。普通各项在初值上增加5–15、最高70；优秀最擅长一项最高85、其余最高75，增加10–25；奇才最擅长一项上限90–95，其余增加15–30、最高85。任何上限不低于初值，清廉固定为初值且不可学习。分层与初始优秀选拔独立，不保证初始高能力者拥有顶级潜力；尚书、侍郎不能提高潜力档次。新生成的随机人物使用第三版潜力，已有第一、二版固定潜力继续保留，旧档缺失潜力者首次补入新规则，录用、培养和重载不重抽。

百年一遇奇才的高潜力科目从初始能力最强的科目依次选取，只含智力、武力、统率、政务；两项必定为95–100，20%概率再增加第三项。清廉、忠诚不可学习，初始能力、培养速度及翰林院研习上限保持不变。第一、二版已固定潜力保持原样。
