# Emperor 1.0.2

本次版本包含 1.0.1 之后的游戏代码、界面、美术和文档更新。

- 朝堂奏报与召见流程调整，新增军情与批量人事操作。
- 中央军募兵、采购、调度、解甲和出征流程更新，统一数量选择及容量检查。
- 工部工程、民夫储备、产业周期与工期规则调整。
- 皇帝属性、太医院、御花园与宫廷交互更新。
- 军阵卡牌结算、部署、人物资料和美术更新。

## 独立运行包

- macOS 12 及以上：Apple 芯片 arm64、Intel x64，各提供 DMG 与 ZIP。
- Windows x64：安装版 setup.exe、免安装版 portable.exe。
- 包含运行环境、完整游戏代码和运行素材，无需 Node.js、Python 或开发工具。
- Mac 使用临时签名，尚未经过 Apple 公证；Windows 尚未使用商业证书签名。
- 发布页附 SHA256SUMS.txt 和各平台的实际运行验证报告。

图片仅在发行构建目录转换为无损 WebP，并逐像素核验；原始图片及存档引用路径保留。
