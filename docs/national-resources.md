# 全国钱粮与中央补助

2026-10-19 起，各国分别维护一份国库银两 `fiscal.treasury`、一份粮食 `fiscal.grain`。本国所有州共享这两份资源。州保留生产、税收、需粮、实际供给、缺口、民生、工程和军籍，不保留府库或独立存粮。钱粮调拨和依赖地方府库的特别征收取消，军队及装备调动继续保留。

2026-10-21 发展平衡第二版以[修复方案](development-balance-fixes-2026-10-21.md)为准：农牧先满足民间口粮，再按剩余产量的10%乘名义税率征粮；公共安全储备按军民夫口粮加2%人口救灾准备估算。灾害直接影响对应产业生产。生活每三旬逐步趋近服务、就业、生产率和税压共同决定的目标；下文原条件每次±2仅描述未启用第二版的兼容规则。

## 原版中央补助的证据与本项目取舍

网络资料：

- [狼窝论坛：DOS版皇帝，政策路线讨论，2009-04-30](https://acgwolf.com/discuz/viewthread.php?tid=35388)：玩家机制研究区分国税与百姓现金；补助按金额除当地人口增加现金，生活等级受现金积累影响。
- [PTT Old-Games：皇帝的一點小問題，2013-02-08](https://www.ptt.cc/bbs/Old-Games/M.1360254749.A.AEF.html)：玩家说明补助可以提高富裕度，生产开发才提供持续收入，并转述说明书的生活等级升降条件；回复同样提及补助除当地人口。

上述是玩家研究与对说明书的转述，不是已核验的原版代码或官方公式。它们支持“中央给百姓生活补助”的用途，不能证明原版存在可支用的地方政府府库。本项目不把旧实现的 `status.cash` 继续当作另一份政府资金。

本项目使用显式简化规则，而非宣称复刻原公式：国库一次性支出，立即提高指定州 `livingStandard`。每人补助 0.01 两提高 1 点，生活保留两位小数、最高100；费用只计达到上限所需部分，太小且无法形成可见改善的金额不扣款。可同时安排多州。生活水平自然升降改为每三旬检查（第3、6、9旬等），仍按原条件每次+2、−2或不变，范围0—100。人口、官员年龄、发展收入与年度兴农仍按年结算。补助不加粮、不直接改变安定或民忠；提高生活后的公共服务费按既有预算公式自然变化。草稿预览列出实际支出、生活前后值和后续预算，关闭取消不收费，失败保存可重试且不重复执行。

## 统一供粮

1. 灾害按受灾州人口占本国人口的比例，将现有灾损率应用于全国库存的对应份额；义仓减损仍按受灾州建筑计算，实际损失记全国账。
2. 原有资源规则保持：新资源制先保民间自给，再征粮赋，官粮负担军民夫口粮与民间不足的赈济；旧规则存档继续使用其原有产粮口径。
3. 全国安全仓容为各州义仓安全容量之和，仅对超出仓容的期初陈粮扣8%损耗；新粮当旬不损耗。
4. 汇总各州粮赋入全国粮库，再按各州需粮供给。全国充足时所有州都足粮；不足时按需求比例分配，用最大余数法分配整数石，小数相同按州 ID 排序。分配量、缺口逐州留痕，合计严格等于全国实际出粮和缺口。
5. 缺粮州安定−2、民忠−1，并按既有规则暂停相应建筑恢复，不凭旧的州库存判定饥荒。不新增缺粮人口死亡。
6. 委任救急按全国缺口购粮，受授权、治理预算、国库保留线约束；手动购粮可使用保留线内资金。均从全国国库支银、全国粮库入粮。

## 购粮与扣账

全国购粮每石2两，每旬最多购买全国三旬人口口粮；首次成功购买锁定全国额度，切换州不能增加额度。银两和粮食在候选副本上同时记账，成功保存后发布；序号和账本键防重复。没有目标库存、来源库存或钱粮运输路线。

出征补给、巡游、祥瑞、灾损、民变、年度发展收入和兴农开支均使用全国资源；敌国各用自己的国库粮库。失地不搬走全国库存，新叛国不会复制原国库粮库或其流水。

## 兼容与验收

`nationalResourcesVersion: 1` 表示已合并。只迁移现有支持的 schema8 存档，先校验旧粮账和金额，再按所属国家汇总地方存粮、合并地方现金。负余额不足部分入债；已有完整财政账则记录当旬合并流水，无历史账则确立期初。删除地方库存与地方粮账，保留旧政令和救济历史，旧购粮额度废止。重复读档不再次合并，混合新旧库存、损坏金额、未知版本和粮账不平拒绝。

专项覆盖：资源守恒、跨州足粮、全国短缺比例分配、最大余数、仓损、购粮额度、补助效果与上限、出征扣粮、灾损、历史读档、失败保存、重复提交、预测只读、连续跨旬和桌面操作。完整回归使用 `npm test`；桌面入口为 `tests/national-resources-desktop.cjs`。

桌面验收已覆盖实际朝堂入口、1440/1280/980窗口、财政900/390窗口、连续税率/补助/普查、高税率提示、失败保存回滚、取消、防重复以及真实旧档载入后再次保存和重载。

本次最终验收：`npm test` 通过，666项测试全部通过，29份运行时快照及负向类型检查通过；全国钱粮桌面验收、财政舆图桌面回归均通过。`git diff --check` 无空白错误。

## 农牧供粮、工商供银

当前资源新制：农业基础产粮0.18石/有效亩，牧业肉乳折粮0.06石/有效亩，同等投入农业是牧业3倍；实际还受对应用工、生产率、地形和州牧影响。农牧合并先保民间口粮再征粮赋，全国统一入库供给。工业与商业以银两计产并征银税，农牧不重复折银。新增资源快照记录农牧分项，历史单一农业快照保留原值。关联检查见 [城市属性检查](city-attribute-audit.md)。

此次验证：705项全量测试通过，州情四种尺寸桌面验收通过，全国钱粮含真实旧档载入、保存与再次重载验收通过。
