# P0 / P1：地方治理与一局游戏的收束

2026-10-16，按“整理皇帝游戏玩法与攻略”最后一轮的六项优先级实现。以下均为本项目试行规则，不宣称复原原版参数。

## P0 地方委任

早朝召见吏部尚书 → 地方委任。可设置全国每旬治理预算和国库保留线，默认均为2,000两，0—1,000,000两整数；修改从下一次自动治理生效，已发生的开支不会被改写。确认操作沿用统一存档提交，写盘失败不会改变原状态。

每次旬结算完成财政、供粮和工程推进后，自动治理准备下一旬。只处理当前本国已委任州，按预计缺粮量降序、安定升序、州标识排序；共享一个全国预算，不给每州重复分配预算。

1. 缺粮：使用现有每石2两、每州每旬三旬口粮购粮接口；额度和预算不足时分量购买并记录原因。灾时也可购粮。
2. 灾情未退：保粮，暂停新工程与军务支出。
3. 民生不足：治安低于60优先衙门，其次安定低于60优先寺庙，民忠低于60优先行宫；有在建项目时等待恢复。建筑恢复仍沿用现有上限和生效时间。
4. 农业产出低于预计口粮的120%且无在建开发时，按容量、能力和预算开发农业；沿用2两/亩、最多500亩、正常施工一旬、完工后下一旬生效。
5. 补齐有边际收益的民用设施，粮仓自动建设目标最多8座；不无限追加粮仓。
6. 有兵且训练低于80时练兵；否则兵员低于人口1%时，从未分配人口中征兵，最多100人、4两/人，另计治理损耗。低粮、灾情、未满足的民生项目优先于军务。

执行费与治理损耗一起受预算和保留线约束，不为委任举债。财政、购粮、开发与工程复用已有接口；同旬重复调用不重复扣费。吏部地方详情显示任职者、能力、清廉、战后状态和最近五条执行/暂缓原因。

## P1 官员治理

只采用该州在职刺史，待命、已收押、叛臣和失地官员不发挥治理作用；刺史空缺时采用署理官。

- 能力 = 政治（缺省取智力）、智力和经验的均值，缺失智力50、经验0；署理能力30。
- 效率 = 0.7 + 能力/100，影响自动练兵、每笔农业开发面积上限以及战后安定恢复。
- 清廉损耗率 = (100 − 清廉)/500，最多20%；署理清廉50。每笔治理费用按损耗率向上取整，单列财政流水，零损耗不记额外交易。
- 任命和调任即时改变后续治理采用的人物，不追溯改写过去账目。

手动内政不额外加收治理损耗，既有经济产出公式保持原状。

## P1 战后占领

胜利后取得目标国当前一州，记录前归属与占领旬。败退不改变领土；叛乱独立州可通过同一战争接口收复。新领土立即进入内政、军籍和吏部任官范围，原在职地方官转待命；叛臣不自动复职。

占领造成安定−15、民忠−10。该州士兵就是驻军，要求不少于人口的0.3%向上取整，可用现有地方调兵接口补足。只有在职刺史和足额驻军同时具备时，才每旬恢复至少1点安定、1点民忠；缺少任一条件则安定每旬−1。安定达到60且民忠达到50后完成战后治理。该机制表示占领后的持续不安，不凭空生成新的叛军。

最后一州失守的国家保留身份记录，方便外交/婚姻/历史引用，但停止常规财政结算，所有相关条约、通商与贡银停止，不能再进行新谈判或作为出征目标。其余国库只按原有战利银规则转移，不额外复制；敌军现有兵籍与剩余地方军备留在占领州，中央出征生还者仍归营。战报列出取得的州郡与治理要求。

## P1 外交接受与履约

礼明殿现有使臣接见中提交议案，对方进行确定性评议。基础分为友善度加威望差的四分之一取整。

|议案|接受门槛/调整|
|---|---|
|互不侵犯|40|
|防御同盟|60|
|保护对方|65|
|请求保护|35|
|上述条约处于敌对|再扣30分|
|贸易|门槛30，扣除对方承担净支出占其国库比例×100向上取整|
|索贡|非零贡额门槛55，额外加威望差一半取整，扣贡额/对方国库×100向上取整|
|和亲|40|

拒绝会显示依据、实际分和门槛，保留原协议。解约、主动纳贡属于单方事务；非法金额仍拒绝。已缔结互不侵犯、同盟或保护关系的双方禁止直接开战，必须先解约。此版条约义务落在双方禁攻约束，尚无第三国自动参战/援军系统。

通商每旬、贡银每年正月上旬结算，最多支付现银，不因协议不足额制造国债。最近履约记录保存应付/实付并在状况表展示：贸易不足额降低友善5，贡银不足额降低友善10；同旬重入不重复结算。未付金额是本次未履约事实，不自动滚入下期追债。

## P1 最小终局

正常耗尽寿元或体力晕倒额外耗尽寿元时，生成一次本朝终评；旧档寿元已为0时在载入补建。

民生（人口加权安定、民忠、治安均值）、财政（相对初始国库的净资产）、疆域（相对初始十州）、威望四项各0—100，等权平均为综合分，对应“盛世明君/守成之君/功过参半/国事维艰”。侧栏“本朝终评”查看帝号、结束旬、年龄、人口、州数、银两、债务与本朝累计战绩；当前生成终评为version 2，采用永久战绩减本朝基线，含历史类比与终局依据。旧版终评原样保留，缺失战报不补造；详见[P3终评说明](p3-endings-and-capital.md)和[存档版本兼容](save-compatibility.md)。评价随存档归档，可由合格储君继位，最近20朝终评保存在dynasty.pastReigns。

## 连续经营验收与平衡结论

运行 `npm run test:balance`，使用固定随机序列，对亲理、全国委任和低产救济压力三类情景分别使用种子1/7/41，每个运行108旬，在36/72/108旬校验并重载存档。逐旬检查预算上限，记录现金、债务、粮食、民生、治理累计费用与供粮缺口；另对农业与商业500亩开发做108旬配对对照。机器可读结果见 [p01-balance-results.json](p01-balance-results.json)。测试中官员忠诚固定100，以单独观察经济与灾害；它不覆盖任由低忠官员叛乱的风险，叛乱州收复另有专项测试。

结论：常规开局的收入明显宽裕；全国委任会增加开销并改善民忠，但不使国库失控。低产压力局中保留线可守住，购粮预算与收入无法弥补全国口粮缺口，安定和民忠会持续下降。此时玩家仍需调税、调整职业和恢复生产，不能把委任当作免费救灾。500亩开发在108旬内未仅靠新增税收回本，农业还增加实物粮食；目前2两/亩仍是长期投资试行价，未据此贸然改动全局产出公式。
