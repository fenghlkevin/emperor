# 九兵种动画

当前角色由imagegen生成的透明图集、运行时裁切和程序动作组合呈现。亲卫使用所选兵种图集。运行时目录为 `src/battle-sprite-data.mjs`，播放器为 `src/battle-sprites.mjs`。

路径均位于assets。裁切逐帧随viewBox及clip rect同步更新，数量按实际素材登记。

待机以脚下为锚点呼吸及调整重心；不改变格位、朝向、数字或游戏随机状态。行走与攻击期间暂停该单位待机。攻击有蓄力、命中、收势；受击短促后仰，致命伤倾倒下沉并消退。待机、受击与阵亡使用图集结合程序动作，不宣称全部为独立位图逐帧。

弓弩有射击动作与飞行投射物；弓骑采用骑乘射击；骆驼和象有独立轮廓，象鼻外侧钢刃以皮带固定。支持速度、自动加速、减少动态效果与关闭清理。合法战斗动作先保存再播放，关闭后恢复不重复伤亡。

## 生成要求

所有角色保持既有侧面手绘兵人风格、蓝灰服饰与护具、固定脚底、向右、透明背景。各格动作姿态必须不同，武器和肢体不得跨格；无文字、网格、光晕、烘焙特效。

- 刀盾：行走与持盾挥刀；长枪：行走、蓄力直刺与收势；轻骑：骑乘步态及骑枪攻击。
- 重骑：重甲骑手、马铠和独立冲锋挥击，4×4共16姿势，前8行走后8攻击。
- 弓：短反曲弓，抬弓、搭箭、拉弦至面颊、松弦；弩：横向弩臂、弩托与扳机、瞄准射击及复装；各前8行走后8射击，不在图集内画飞行箭。
- 骆驼：真实驼峰、长颈与驼足，4步态及4攻击；象：独立战象、骑手、鞍毯，鼻刃和固定皮带在抬鼻姿势仍清晰可辨，4步态及4攻击；弓骑：骑手拉弓、松弦及坐骑动作，4步态及4骑射。
