# 战争与兵种套装

入口：朝堂 → 兵部。军务采用左侧分类、中间内容、右侧军令确认的三栏布局。

## 出征

选择接壤目标 → 编制军队 → 军令确认。全军主将与最多六个子队的将领不可重复；亲卫选择实际兵种和人数，使用相同士兵及套装账本。每队1至10000人，允许残部。缺员或缺装拒绝出征，不自动采购。前两步仅拟令，最终确认才预留资源并保存战场。

唯一执行链为 `beginWar → advanceWar → finishWar`。生还携装归原驻地，阵亡一人核销一人份对应套装；军令编号保证只结算一次。

## 战术

13×9六角格；九兵种规则、价格、射程、地形、侧背击与特色效果见[军制规则](troop-kit-rules.md)。未移动时可选择攻击落点；移动后不可再次移动。相邻近战最多反击一次，远程不触发隔空反击。等待每回合一次，防御提高20%。任一方主将亲卫被击溃或全军撤退即判负。

杀伤预览与实际结算共用模拟。先保存合法动作，再播放动画；中途关闭只取消表现，恢复战斗不重复伤亡。支持手动与自动、三档速度、自动加速和减少动态效果。

## 守城与外军

来袭时从本州、中央及实际应约盟军按来源配装。库存不跨驻地借用，不重复占用。缺装刀盾乡勇仅作弱战力应急守军，不能凭空获得套装。撤守、失地与京城危机按实际战争结果处理。

外国先按同价采购完整装备，再按真实国库和装备覆盖招募。盟军使用自己的兵籍、装备和来源，生还返回原驻地。战报展示真实参战、阵亡、生还、套装折损、战利银和占领结果。

验证入口：`npm test`、`npm run test:kit-office`、`npm run test:kit-routing`、`npm run test:war-layout`，完整自动战争为 `electron tests/kit-auto-war-desktop.cjs`。
