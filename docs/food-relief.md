# 全国粮食救济

当前钱粮全国共用，规则与原版补助调研见[全国钱粮](national-resources.md)。

户部和御案山河图提供全国购粮：基准每石2两，新制户部侍郎提供最多8%采购优惠，清廉低于50产生最高5%采购损耗；优惠向下取整、损耗向上取整，报价、委任预算和实际支付共用公式。历史采购保存当时官员及费率，调任不改写实付。直接从国库付银、进入全国粮库；不再选择调出州、调入州，也不再需要州际调粮。购粮改按互市银两成交额累计，取消全国三旬口粮的硬性购买上限；旧口粮字段仅兼容历史存档。

各州仍显示田赋贡献、需粮、预计或实际分配和缺口。先汇总全国田赋和安全仓容，扣陈粮仓损后统一供粮；全国不足时按需求比例分配，最大余数法处理整数余粮。只有分配不足的州受到安定−2、民忠−1等现有缺粮影响。

中央补助是直接改善生活的惠民支出，不增加粮食。购粮不能消除灾害或追溯撤销损失；足粮后建筑依既有规则逐旬恢复。新建与开发仍受灾情、民夫、授权等限制。

查看、预览、取消均不收费。执行与保存使用候选副本，失败不扣钱粮或行动成本；政令序号、国库和全国粮账共同防重复。旧调粮历史保留，但不再可执行新调粮政令。

全国旬报显示一份粮食流水，包含田赋、供粮、陈粮仓损、购粮、灾损、祥瑞和巡游；州供粮明细不再充当独立库存账。预测标注尚未发生的事项，并与实际结算使用同一供粮算法。

## 2026-10-19 州情与盟国购粮

疆域图的钱粮页仅展示所选州按现行产业、税率估算的每旬粮食总产出、粮赋、工商银税、地方开支，并列农业产粮和牧业折粮。总产出包含民间留粮；粮赋及银税入全国库。全国库存、全国缺口和仓损不再混入州情。

“粮食购买”为户部独立事项，也可由疆域图按钮进入。只能向当前陆地接壤、仍有领土、双方已由礼部订立互市额度的国家购买。盟约或友善度不替代互市；敌对暂停。互市额度沿用协议出口与进口额度之和，单位为两/旬，双方真实成交共同累计。官效结算后的原价超过剩余额度的部分加价50%，加价向上取整；实际货款计入成交额，拆单、换州、重签协议均不清零；下旬重新计算。

成交在私有副本上完成：买方扣实际货款、加所购粮；卖方加相同货款、扣相同粮食。采购官效保留，全部实际货款转入卖方国库。双方各记银、粮流水；成交回执保存卖方国家与银粮前后快照。持久化成功后才发布，重复提交拒绝。旧购粮回执无卖方字段仍可读取，不追溯补写对方账目。自动委任购粮也受接壤、互市及卖方库存限制。邻国缺粮时会向我国购粮，仅出售我国保留两旬需粮后的余粮，按实际支付能力购买，不赊账；双方实收实付，重复结算不重复成交。互市协议本身不再每旬凭空转移银两。
