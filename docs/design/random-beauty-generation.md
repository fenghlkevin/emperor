# 实时随机佳人

后宫宣召的普通佳人按存档种子与宣召序号实时生成，不再从29名固定人物中抽取，不设生成总人数。每人具有独立ID，姓名可能同名；姓名、18～25岁年龄、籍贯、性格、专长、立绘和属性生成后固定，读档不会重抽。既有存档人物和知名美人的设定保留。立绘从 `src/random-beauties-data.mjs` 当前随机素材池中分配，人物数量不限不代表立绘数量不限。

外表与先天能力独立抽档，档内整数等概率；皇帝属性不改变这两项的概率。

|档次|概率|外表|先天能力|
|---|---:|---:|---:|
|一般般|45%|30～49|20～39|
|一般|35%|50～64|40～69|
|较好|15%|65～79|70～109|
|美人|4.5%|80～94|110～159|
|绝世美人|0.5%|95～100|160～200|

表中的档名用于外表评价；能力按同样权重独立抽取，绝世美人不保证高能力。
新人物初始经验为0，能力显示先天能力。相伴恢复=先天能力+经验+名分加成（未入册时无经验与名分加成），相伴后经验增长，先天能力不被外表公式覆盖。旧人物继续沿用原恢复规则。

知名人物仍按既有才艺概率出现，全部相见后继续生成普通人物。实时人物遣出后不保留在寻访ID数组里，避免无限增长；存档种子与递增序号保障后续身份不重复。巡游普通佳人使用同一实时生成与五档概率；旧存档已生成的巡游人物、夏雨荷等特殊彩蛋保留原设定。


## 随机立绘新增与重制规则（2026-10-22）

- 公开人物先上网寻找并核对成年照片，实际照片作为生成输入；记录来源、像素尺寸与输入路径。身体可见部分参考本人身形，未展示部分按自然成人结构补全，不把二维生成称为精确三维扫描。
- **无论站、坐、卧、瑜伽或舞蹈静态姿势，均光脚，不穿鞋袜。** 检查双脚方向、脚踝连接、脚趾数量和接触关系，避免裙摆完全遮住双脚。
- 以轻薄夏装为主，搭配不同服装结构、手持道具、发簪、耳饰、项链、手镯和腰饰。保持自然头身比例、合理重心和协调的关节姿态。
- 古装立绘只使用古风服装、饰品与道具；不得混入现代体育器械、台球杆、台球、电子设备或现代标识。
- 最终素材必须是真实 alpha 透明 PNG，人物、手脚和道具不得裁切。逐张检查原图，并在浅色和深色底上验收边缘。
- 同一人物允许多个独立造型同时进入随机池；新增造型使用独立 ID 和文件名，已有造型及旧存档路径映射保留。

本次新增 14 款分为 `mainland-photo-six-20261022-*` 和 `mainland-photo-eight-20261022-*` 两组；照片来源、最终提示词与验收记录见 `docs/art/mainland-photo-six-2026-10-22.json` 和 `docs/art/mainland-photo-eight-2026-10-22.json`。

本批 14 款标记 `poolScope: "mainland"`，与各内地州府既有候选合并，去重后等概率抽取，避免专属地方素材使共享款式无法出现。未标记素材继续沿用地方筛选规则；已保存的素材路径不重抽。
