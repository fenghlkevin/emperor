# 实时随机佳人

后宫宣召的普通佳人按存档种子与宣召序号实时生成，不再从29名固定人物中抽取，不设生成总人数。每人具有独立ID，姓名可能同名；姓名、18～25岁年龄、籍贯、性格、专长、立绘和属性生成后固定，读档不会重抽。既有存档人物和知名美人的设定保留。立绘仍从现有20幅素材中分配，人物数量不限不代表立绘数量不限。

外表与先天能力独立抽档，档内整数等概率；皇帝属性不改变这两项的概率。

|档次|概率|外表|先天能力|
|---|---:|---:|---:|
|一般般|45%|30～49|20～39|
|一般|35%|50～64|40～69|
|较好|15%|65～79|70～109|
|美人|4.5%|80～94|110～159|
|绝世美人|0.5%|95～100|160～200|

表中的档名用于外表评价；能力按同样权重独立抽取，绝世美人不保证高能力。
新人物初始经验为0，能力显示先天能力。相伴恢复=先天能力+经验+名分加成（未入册时无经验与名分加成），相伴后经验增长，先天能力不被外表公式覆盖。旧人物继续沿用原恢复规则。

知名人物仍按既有才艺概率出现，全部相见后继续生成普通人物。实时人物遣出后不保留在寻访ID数组里，避免无限增长；存档种子与递增序号保障后续身份不重复。巡游普通佳人使用同一实时生成与五档概率；旧存档已生成的巡游人物、夏雨荷等特殊彩蛋保留原设定。
