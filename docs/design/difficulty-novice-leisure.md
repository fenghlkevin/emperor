# 新帝登基休闲难度修订

2026年10月26日。新帝登基定位为休闲经营：允许慢慢建设、培养人物和体验剧情，犯错后有恢复空间。标准与高难维持既有设计。本修订已替代此前初级档参数并接入正式游戏；推演数据与验收见[交付报告](difficulty-delivery.md)。

## 人才与人物成长

科举基础候选为10至18人，另计现有官员加成；费用200两。名臣出现概率乘1.6，高能力新秀选拔概率乘1.5，最终概率不超过100%。连续三届没有名臣，下一届在仍有未入仕且合格的名臣时保证至少一位；没有可用名臣时改为保证一位高能力新秀。保证结果需要消耗候选名额，不重复生成人物，也不改变同一名臣的基础能力。

训练成长乘1.5，取整且不超过原属性上限；行动体力消耗乘0.75，正数消耗至少为1，诊治费用减半。普通衰老、生活与剧情继续存在，初级档不附加额外寿元惩罚；休息恢复沿用原规则，避免靠免费循环无穷成长。较快成长帮助玩家达到现有功业要求。

## 灾害与经营容错

本国天灾、人祸触发风险乘0.5，灾害导致的产出损失与负面变化幅度乘0.5，持续时间仍沿用原规则，以免改变既有救灾记录校验。概率和损失分别调整，救灾仍能缩短灾期、减轻损失。因战争、主动刑罚或玩家决策造成的后果不归入灾害减损。

建议每朝提供两次自愿启用的休养援助：每次10000两及按领取时公共需求计算的12旬官粮，两次至少间隔36旬。玩家国库低于10000两或官粮低于12旬时，主动领取入口才可用；不打断游戏、不自动弹窗。使用次数与领取旬数持久化，存档重读不重置，不能通过重复打开面板或变更配置重复领取。

## AI与战争节奏

外国经营每12旬一次，对玩家主动进攻的保护期为前180旬，之后对玩家两次主动进攻至少间隔72旬，侵略倾向为现行35%。保护期不阻止外国之间战争，玩家主动攻击某国后，该国可正常进行防御和反击，不能利用保护期连续无代价侵略。保护期按参与国记录，不让无关国家一并提前解锁进攻。

战术AI有25%概率在可用的其他合法行动中选择，减少总是找到最佳交换的压力；规则应排除无意义的无限回合和非法行动。敌方仍支付兵员、装备和补给费用；公开威胁与战斗结算规则一致，不通过伤害作弊制造难度。

## 验证状态与验收目标

已用真实引擎在开局副本中验证城市民生、人口职业、军备和存档结构，并重算初始财政和供粮。开局报价仍沿用正式军费、俸饷和生产公式；建设、科举、灾害、体力与AI等规则均已接入，并补齐报价、扣款、进度和存档校验。

已完成三个种子共18组108旬经营、单种子6组360旬经营及三次实际战败恢复；制举与灾害分域，其他剧情尚未全部分域。本轮样本验证的休闲验收目标为：不扩张、正常休息且不过度抽调劳力时，默认经营108旬不因军饷和官粮被迫破产；一次中等规模战败后仍有守军和重建能力；遇灾能负担一次正常救济；低频建设和选官不要求每旬重复微操。训练、人物与功业还需靠实际游玩达成，不能开局直接授予最高史评。

上一版初级45000两、中央1600人的108旬经济数据及20%失误率战术结果是历史基线，不能用于宣称本修订已经平衡。新增城市开局数据见[逐城资源与兵力设计](difficulty-city-opening.md)；机器配置为 difficulty-v1.json 与 difficulty-city-opening.json。
