# 办理成功自动返回（2026-10-19试玩反馈）

规则：一次性批复、颁旨、办理在保存成功后直接关闭，调用原返回逻辑刷新上一层；执行结果继续留在原有业务账本。保存抛错或明确返回false时不关闭、不发布候选状态，保留草稿、错误与重试入口。核阅、取消和返回草稿仍属执行前流程，不跳过。

## 排查与调整范围

| 范围 | 处理 |
| --- | --- |
| 地方工程/军务奏请 | 批准、驳回保存后收折（此前已改） |
| 户部 | 舆图财政/救济、理财精册、购粮调粮办理后返回 |
| 吏部 | 任命、恩赏、地方授权、全国预算、精册政令办理后返回 |
| 刑部 | 案件、密查拨款、天牢复核与精册命令办理后返回 |
| 工部 | 普通营建、开垦/产业/职业调配、施工安排、停建、特殊工程办理后返回 |
| 军务 | 军营普通军令、扩军/调装奏请、大将军训练/巡防、兵装精册非战争命令办理后返回 |
| 礼部 | 邀请使臣、祭祀与普通外交办理后返回 |
| 宗室、功业、国政与本朝纪事 | 普通事务成功后返回；真正终局沿用终评与继位衔接 |
| 正式使臣接见 | 一次会面可办理多份国书：成功后直接返回议事草稿，更新实际国约；不经成功回执页，不擅自结束接见 |

顺带检查：科举录用已在用印成功后自动关闭；现有叙事、安寝动画、巡游事件后续选择和战斗结果不是一次性办理回执，保留必要流程。本轮没有实际出征或处理战斗。

## 验证

- 新增统一保存返回值检查，覆盖缺少提交入口、false拒绝、抛错及返回正式已保存状态；不会把失败当成功收起。
- 独立实际UI页 `tests/fixtures/operation-results.html`，只操作内存模型、不读写玩家localStorage；可切正常保存、返回失败和抛出错误。
- 实机分别办理地方授权、任命、礼部祭祀、大将军训练、普通营建、户口普查、特殊工程及刑部拨款，8次均自动关闭返回。另有2次人为关闭用于切换失败验收模式，因此界面计数保存8次、返回10次。
- 返回false时河北授权草稿预算550与已勾选文政保留，出现“办理结果未保存，请重试”；抛错时训练值仍60、错误可见、颁令按钮恢复可点击。
- 全UI模块语法检查、数据契约26个运行时样本及反向类型检查通过；相关业务模型46项通过；最终全库635/635项通过（40.45秒）。本轮未运行旧版Electron逐页脚本，不把它们当作本轮验证证据。
