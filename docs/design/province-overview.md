# 州情一屏总览

内政舆图点击州名后默认显示州情总览，保留原来的古风字体、棕色进度条与右侧数值。顶部汇总人口、土地、生活与民忠；三栏分别显示民生、职业人口与军备、全国供粮保障、本州四业税收贡献与本州建筑。全国报表与产业、财政细查仍可从顶部选择。

民生指标显示主要用途，点击指标、生活水平、人口土地、钱粮保障或训练可打开说明，解释实际规则、关联门槛与提升方法；说明不推进时间、不修改资源或存档。提升方法区分直接效果和间接关系，中央补助只直接提高生活水平。

底部改善生活、地方建设、调配人口入口进入现有财政或工部政令，沿用办公时段、存档确认和资源结算规则。上/下一州不改变全国报表选择以外的游戏状态。

验收：`npm run test:province-overview`。真实 Electron 在 1440×1000、1280×800、980×720、900×680 检查无内容滚动或越界，验证十一类指标说明、查看不写档、切州返回以及三个真实政令入口。截图：`docs/screenshots/province-overview-1280.png`。

原营业展示项已改为四业景气，0–100 分；各业实际产出除以其当前允许用地上限、满员、生产率100时的产能，归一化后各占25%取平均。综合值实时派生，不写入存档、不作为税率或额外收益加成。原市集对商业活跃的加成保留原结算，建设收益中明确称商业活跃。人口与产业表同屏显示农牧商工职业人数及各自产出（石、头、两、件）；右栏按实际结算预测显示农业粮赋与牧工商银税，不把不同单位相加，不把税收称为百姓全部收益。产出使用下旬生效用地与用工口径，与供粮预测保持同旬。
