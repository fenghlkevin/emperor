# 各州与番邦进献佳人

每年正月上旬（回合1、37、73……）结算时，玩家当前实际辖下每州选送一名成年女子。正常推进游戏时首次跨年在第37旬触发；新建游戏和读取旧档不补发往年进献。州是否归属以结算时实际归属为准，日本州即使已被玩家占领，仍使用日本姓名、服饰和立绘。

番邦随机进献：玩家国家威望至少200，对方友好度至少80且非敌对，有实际领土。每旬有5%概率从满足条件的外邦州中等概率选一州，最多进献一人。没有符合条件的州不触发。与年度进献可以同旬发生；同一旬结算与读档不会重复领取。

两种进献均直接以未册封身份录入后宫，通过内廷通知和后宫历史告知，玩家可以在名册中查看、册封。属性沿用五档：45%、35%、15%、4.5%、0.5%，外表与先天能力独立抽取，初始经验0。相伴不会覆盖先天能力。

依据来源州在BEAUTY_CITIES的原生地区决定人物文化；不是按州当前占领国。完整立绘只选同regionId，尚无该地区完整立绘则用现有当地立绘部件组合，不借用中原或别国完整立绘。后续定时新增素材沿用RANDOM_BEAUTY_ART和regionId即可供该地区新生成人物使用。既有人物的立绘路径或部件配方固定保存，不随素材池增加换脸。

中原完整素材优先选有同州标记的条目，否则在中原池内选取；中原十州仍有各州服饰与立绘配方差异。人物来源保存在tributeOrigin，结算防重标记为beautyTributeLastTurn。
