# 三档难度接入与推演验收

2026年10月26日。三档难度已接入正式游戏，新建王朝默认「新帝登基」。城市资源、兵力、建设、人才、军需、灾害、成长及AI节奏按难度生效；休闲档提供自愿领取的困难援助。

新帝登基建筑费用七折，普通与特殊工程工期按75%向上取整；分段工程按每段取整后合计，长城和运河各204旬。建筑仍需现有民夫，不能凭空开工或自动获功业。修习成长提高50%、体力消耗减少25%，诊治、灾害风险与灾损、授权整军的恢复费用减半。所有金额均通过实际报价、扣款和存档校验，地方委任、营建奏请、扩军奏请及分期开发共用价格规则。

科举连续三届没有名臣时，第四届在尚有合格未入仕名臣的前提下保证一位；否则保证高能力新秀。援助每朝两次，每次10000两及领取时12旬公共官粮，间隔至少36旬；钱粮不足时由玩家主动领取。保存失败不扣次数、不增加资源。继位保留难度并重置本朝援助次数，不重发开局资源。

旧档归入励精图治，保留原有钱粮、军队和工程。原有两参数创建接口保留兼容开局，游戏新建界面明确传入选择的难度。旧版在建工程沿用其原工期，新工程保存开工时采用的工期或难度快照。

## 连续经营推演

三个固定种子1、7、41，分别测试默认委任和低频建设选官两种策略，三档各跑108旬，共18组；另用种子1延长至360旬，共6组。外国经营、灾害、供粮、财政、衰老和战争均启用；每日正常安寝，实际执行建设、开发与制举，不注入测试资金，不关闭外国AI，不伪造胜利。发生对玩家进攻时用真实守城AI及实际兵籍结算。

低频策略每18旬安排一次合格的商业开发和普通营建，每36旬选官；受资源和工程条件限制的指令记录为受阻。制举与灾害使用各自随机域，剩余环境随机数按每组种子固定；尚未把所有剧情事件拆成独立随机域，不能把同种子视为整个世界逐事件完全相同。

休闲档108旬后国库范围为102106至113028两，六组均无债务、无供粮短缺、无被迫终局。

## 实际战败与恢复

三组休闲档各进行一次实际3000人远征，由真实战斗AI结算，均战败且损失3000人，中央军由8000降至5000。随后按报价授权补员、补装与训练，不使用援助、不添加测试收入。

## 战术对照与实际界面

16个种子、交换先手，每档32场，共96场。双方同兵力和装备，玩家统一采用原有均衡AI，敌方使用正式难度AI。休闲档25%概率选择其他合法行动；高难在公开盘面上对攻击次序作有限两步评估，沿用原有部署策略，移除对手隐藏手牌、牌序和奥秘，不读取真实未来随机结果。

|难度|玩家胜场|敌方胜场|平局|
|---|---:|---:|---:|
|新帝登基|24|8|0|
|励精图治|15|17|0|
|力挽狂澜|16|16|0|

休闲档对照中玩家胜24场，占75%；这是自动策略对照，不是人类胜率。高难与标准的战术胜率接近，不能据此宣称战术强度显著提升；高难的确定差异来自开局缓冲、军需、人才供给及更早、更频繁的外国行动。

实际Electron界面已通过三档新建、难度持久化、读档不重发资源、援助保存失败回滚、成功领取、冷却与余额刷新，并检查1440、900和390宽度。使用独立测试存档，没有替换玩家进度。

## 测试与复现

专项测试覆盖人口守恒、中央兵籍不重复计数、开局军备、难度篡改与版本校验、旧档兼容、开发及采购扣款、地方奏请、普通与特殊建筑工期、科举保底、灾害、训练、出征快照、实际战败恢复、随机域、战术合法性和隐藏信息不变性。存档类型检查增加三档开局及休闲特殊工程快照。

最终类型检查覆盖58份运行时快照，含负向类型检查。全量回归共1208项，1205项通过，另有3项既有素材检查失败，已在改动前的工作区独立复现：未使用的美术资源、随机人物素材数量断言及旧PNG清理检查。难度、经营、战斗、存档专项与实际界面验收通过。

复现命令：

- `node scripts/simulate-difficulty-runtime.mjs`，三种子108旬。
- `node scripts/simulate-difficulty-runtime.mjs --long --seed=1`，单种子360旬。
- `node scripts/simulate-difficulty-recovery.mjs`，实际战败和付费恢复。
- `node scripts/simulate-difficulty-runtime-tactics.mjs`，96场同兵力战术对照。
- `node --test tests/difficulty.test.mjs`，难度专项。
- `node_modules/.bin/electron tests/difficulty-desktop.cjs`，独立存档的实际界面。
- `npm test`，类型及全量回归。

数据文件为本目录下 difficulty-runtime 开头的JSON。此前 difficulty-v1-results 与 difficulty-v1-tactics-results 是接线前的历史实验，不能替代本次验收数据。当前样本支持交付这版休闲开局，未证明所有策略、整个王朝寿命或统一升仙的长期可达性。
