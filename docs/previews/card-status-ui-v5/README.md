# 组合状态交互设计稿

基于 docs/design/card-status-ui-20261025/design.md 制作的独立评审稿，不接入游戏引擎，不修改生产战斗。

- 单卡：四种组合预设、12 种逐项开关、徽记详情、来源、期限及攻命计算。
- 战场：双方七张牌，各卡独立状态，可选中任意单位编辑。
- 满阵压力：双方 14 张牌各以 8 项状态起始，再逐张增减。
- 重放施加：临时演出归入独立徽记，所有既有状态保留。
- 结束示例回合：仅移除临时加攻及按本示例结束的冻结。

示例卡有基础攻击 3、生命上限 7 与 4 点既有伤势。人物插画为仓库现有资源，用于 UI 评审；来源名称为示例文案。沉默按先施加、之后重新获得增益及关键词的展示顺序解释。武器、主将、奥秘、地标的战场栏为布局背景，不提供战斗操作。

状态图标在内联环境使用宿主 Lucide；独立打开时若无宿主图标库，自动显示中文识别字。交互状态保存在当前预览本地，未发送任何战斗请求。

validation.json 记录 20 项本轮交互与布局验收。
