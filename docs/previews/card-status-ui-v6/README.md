# 组合状态紧凑交互稿 V6

独立 UI 评审稿，不接入正式战斗。V5 预览保留供对照。

- 默认双方满阵，各 7 张牌，每张以 8 项状态起始。
- 卡底连续四列小徽记：4 项一行、8 项两行、12 项三行。正负使用不同底色与图形，不另占分组标题或空行。
- 详情与组合编辑放在按需打开的浮层内，不在战场下方长期展开。点击徽记/卡片查看明细，点击“编辑当前部队”增删状态。关闭按钮、Escape、点击外部均可关闭。
- 组合预设只修改当前选中部队。临时加攻与冻结在“结束示例回合”时解除，其余效果保留。
- 保留每项状态、具体来源、期限、正负属性构成和效果重放。
- 窄窗口自动改列，徽记不隐藏；触控时增大徽记点击高度。

1024px 宽窗口、双方 14 张牌且每张 8 项状态：V5 总高约 1654px，V6 约 848px，减少约 49%。当前部队增加到 12 项后，状态区含 5px 顶部间距共约 77px，整体高约 873px。浮层打开时不增加战场总高。

验收记录见 validation.json；包含状态完整性、3 行 12 项、单项移除、到期、浮层高度与 320–1440px 布局。
