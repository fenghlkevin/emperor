# 户部尚书规则与证据

原始证据见 reverse/emperor/code-analysis/EMPEROR/object1.relocated.asm 和 reverse/emperor/code-analysis/tables/referenced_strings.json。

- 普查：0x431dc 的 0x1388 与 0x433f3–0x43404 确认费用 5000 两。原版通过事件登记流民；新增人口具体公式尚未确认。本版即时增加各州人口 1%（向下取整），加入四类生产职业，不修改原军籍。
- 军备采购进入统一九兵种套装军务，按驻地和人份入库；价格、地域权限见[军制规则](troop-kit-rules.md)。
- 补助：c71e8–c71f4 的文案及诏书确认中央拨银。按用户要求一次列出全部十州，逐州输入，等额扣国库并加地方现金。
- 税率：c71f8 原版为全国税率；按用户要求改为逐州 0–50%，后续每旬按该州生产计税。
- 强征：c7208/c720c 确认额外征收和百姓不满，0x4461a–0x4469a 为事件入口，具体收益公式未确认。本版暂取正地方现金的10%（向下取整），受征州民忠减5、安定减3，界面先展示收益和代价。

所有操作先预览，确认后原子执行并保存，随后出圣旨。国库不足、非法数值、外邦目标、重复政令均拒绝，失败不改变原状态。一次性收支单列财政政令记录，不再次计入每旬支出。
