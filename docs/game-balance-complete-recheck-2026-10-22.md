## B01 · P1：负债叠加中央军全损，整军顺序让中央预备队长期空缺

**合法复现：** 从新局把税率设为0%一年，形成真实债务；恢复20%后，中央军在第37旬实际出征全损，再明确授权偿债期间最低战备。整个流程不额外补钱、造兵或强制造灾。

空缺期不是一直缺钱或缺粮：已有步兵装备和超过保留线的现银时，计划仍因其他兵种尚未全部补齐而不招任何新兵。原因是 `src/army-recovery.mjs` 只在所有兵装目标都完成后才进入招募，再在兵员全部补齐后训练。

手动对照直接用已购步兵装备付费招募300人，恢复首批中央兵力的时间提前约65–69旬。自动组补装补员训练实付29,509–29,517两；应急组加上手动招募费后为29,513–29,518两，费用基本相同。提前有人也会更早产生军饷，期末债务略高，仍有真实财政取舍。

这是**中央预备队**长时间空缺，本国地方驻军仍存在，不能夸大成国家完全无军或必然亡国。零税一年加全军覆没本身是严重错误，完整恢复耗时应保留；但没有必要在可以实付形成基本队伍时一直等待所有兵种库存补齐。

**方案：** 恢复计划先形成一支有装备、基本训练的300–500人队伍，再恢复完整战前兵员、各类装备和训练。已有可用兵装时允许下一批先补相应人数，采购、招募和训练仍分别实付；不凭空赠送装备，不扩大原核准额度，不降低本金/利息，不跳过口粮、应急金、债务不恶化及350两/25%结余限制。需要时通过现有续批入口明确追加授权。

**验收：** 三种子同一严重组合下，只要已有可用兵装、劳力、口粮和安全结余，下一个可办理批次就能付费形成兵员；不以其他兵种仍有缺额为由维持零中央军。完整目标、累计实付、训练限次、常规军饷和存读档均能对账。财政确实不安全时继续暂停。

## B02 · P2：地方自动补装把工业优惠记成了实际支出

**合法复现：** 真实新局，只委任河北军务，设置每旬1,400两上限；实际招募100名河北士兵，随后正常推进，委任为现有驻军补装。

三个种子第2旬都出现同样差额：

| 项目 | 金额 |
| --- | ---: |
| 100份刀盾兵装原价 | 1,200两 |
| 工业采购优惠 | 67两 |
| 财政账本实际装备支出 | 1,133两 |
| 本旬实际治理损耗 | 101两 |
| **国库实际总出账** | **1,234两** |
| **委任预算占用及“实支”记录** | **1,301两** |

国库实际扣款正确，偏差发生在委任预算占用和“实支”展示。1,400两预算被记成只剩99两，后续100两训练加损耗被暂停；实际还有166两额度。

原因在 `src/governance.mjs`：采购办理走 `executeKitCommand` 的优惠后报价，预算 `apply` 却传入 `amount * kit.price` 原价。因此预算和记录比真实出账多算67两。

**方案：** 委任采购统一采用正式报价，实际采购价与明确的损耗金额共同计入预算、地方记录和财政回执。若保留保守的预占金额，应标作预占并在交易后释放差额，不能显示为已经实付。损耗采用原价或净价作基数要有统一规则；不要通过额外扣67两或取消工业优惠来让账面凑平。

**验收：** 三种子同流程下，地方记录、全国本旬已用预算和对应财政流水之和一致；工业优惠0%、部分和上限、后续训练、低现金、存读档与重复结算均覆盖。真实未付差额不应阻止预算内下一项军务。
