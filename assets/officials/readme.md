# 官员人物立绘

由内置 image_gen 生成，供选官名册、人物档案、召见和朝堂人物显示使用。共 120 人或模板、360 张 PNG，按人物类型及人物 ID 分目录。

共同提示词：古代中国皇帝策略游戏人物素材；彩色写实手绘风格，自然人体比例与统一暖色侧上方光线，真实织物、面部及发须细节；透明背景，不含场景、地面、烟雾、光晕、文字、界面或水印。同一人物的头像、个人全身像和朝堂立绘保持五官、肤色、年龄感、发须及体型一致。

| 目录 | 内容 | 组织方式 |
| --- | --- | --- |
| [historical](historical/readme.md) | 100 位历史人物，300 张图片 | historical/人物ID/ |
| [random](random/readme.md) | 10 套文臣、10 套武将模板，60 张图片 | random/模板ID/ |

| 文件 | 用途与绘制提示词 |
| --- | --- |
| avatar.png | 头像：正方形头肩近景，面部清晰；完整保留头饰，露出上胸；沿用全身像的个人服装与身份特征。用于选官名册、人员列表和传召入口。 |
| full.png | 个人全身像：从头饰到鞋底完整入画，正面站立，自然约七点半头身；使用人物专属服装及代表性道具，保留少量透明边距。用于召见、人物档案和完整立绘预览。 |
| court.png | 朝堂立绘：保持个人全身像的面部身份与体型，改穿统一深青色朝服、黑色乌纱帽、深色腰带与黑靴；双手在胸前持笏，衣袖收束，正面恭立；文臣用鹤纹、武将用兽纹补子；不穿战甲，不携战斗武器。用于朝堂独立人物层。 |

每个人物目录的 `readme.md` 提供具体身份、服饰与道具提示词，以及实际图片尺寸。图片登记表为 `src/official-art-data.mjs`；同步命令为 `node scripts/sync-official-art.mjs`；历史人物完整性检查为 `node scripts/audit-historical-art.mjs`。
