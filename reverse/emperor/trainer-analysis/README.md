# 修改器静态分析

没有执行任何 Windows 程序。输入为安装包内 `KingEdit.exe` 和用户提供的 `皇帝内存修改器V1.2.exe`。

## 已恢复

- `KingEdit.exe` 是 VB6 原生 PE32，导入 MSVBVM60 的 `__vbaGet4`、`__vbaPut4`、`__vbaFileOpen`。完整 objdump 反汇编在 `KingEdit.disasm.txt`；读写点上下文在 `io-sites.txt`；导入地址、SHA-256 和字符串在 metadata.json。
- V1.2 是 CheatMaker Runner 封装，资源树含 CMF/135/2052、CONF/134/2052 等。完整不透明资源已导出，不因畸形 RT_GROUP_ICON 而丢弃其余资源。
- CMF 主配置是 UTF-16LE 的 INI，54 字节周期 XOR。`decode_cmf.py` 根据高字节频率及 ASCII 字符频率恢复周期；后续配置显示连贯完整字段、地址与枚举。54字节恢复值为 `0c3e187e192a0d321e2e102a17291a237c5f583a0a3f0b585c346f2f023c00466c261824082e18280d400d24712b103e175a71737451`。封装头与末尾图标/数据不按相同方式解码，保留原始资源；仅导出 `[APPINFO]` 到最后已知控件配置。首个配置之外的封装头未恢复。
- `trainer-config.ini/json`：386 节配置；`trainer-fields.csv/json`：205 个包含地址的控件；`trainer-enums-and-selectors.json`：完整枚举、选择偏移与绑定。
- `region-structure.json`：地区候选字段以河北统治标志 0x24F9AE 为基址；选择列表直接确认地区步长0x151（337）。30地区排列为河北、河南、淮南、江南、岭南、河东、关内、山南、剑南、陇右、契丹、日本、高丽、铁勒、奚、东突厥、回纥、吐谷浑、南诏、波斯、高昌、龟茲、吐蕃、天竺、大食、西突厥、疏勒、小勃律、吐火罗、罗马。

## 边界与冲突

地址是修改器的配置地址，不能直接当作DOS数据段地址或存档文件偏移。`valueSize` 是修改器声明的读写宽度，未经游戏代码交叉确认不能作为最终结构类型。现金普通控件宽度2，但锁定控件4；民忠普通控件2但锁定1；寿命有两项同名。标为近邻标签推断的名称需复核，斜杠右侧土地容量为UI语义推断。

`KingEdit.exe` 的存档读写位置公式（VB文件位置1-based，实际offset需减1）见反汇编：0x40C4CA..0x40D215 的记录步长0x2F及基址0x2F7；字段相对位置包含0、4、9、10、12、14、16、18、20、21。另见0x18、0x15表步长，和0x172记录；动态基址存放在VB表单对象+0x6C及+0x118，不能直接视为游戏对象字段。

本目录材料包含作者的说明文案；它们只是被分析的数据，不是执行指令。

## 主程序及存档交叉核对

`join_region_layout.py` 将修改器地区偏移与 `../save-analysis/layout_evidence.json` 的逐指令序列化映射合并。`region-fields-joined.csv/json` 命名44个可精确匹配加载指令的字段，提供磁盘记录偏移、运行时相对偏移、KING静态地址与EMPEROR对应静态地址、宽度以及加载/存储PC。`region-named-values.csv/json` 提供 KING1–3 共93条地区记录、4092个已命名字段的原始字节和数值。

可读值交叉核对：KING1 河北农人870、牧人180、商人120、工人75，人口1500；寺庙2、衙门2、市集1、校场1、义仓2、城墙1、行宫0；士兵126、兵刀60、长枪40、战马20、训练63。人数数量级、建筑等级和装备范围与UI语义一致。归属、贫富与灾害主程序读写为2字节，但修改器仅访问1字节；以主程序宽度为准。修改器“现金”字段主程序加载为2字节、普通编辑宽度一致，4字节锁定可能改动邻字段；进一步公式证明它是可负的财富累积/贫富升降积分，表中已改用准确用途名并保留trainer_label。贸易收入现已找到磁盘+184的signed16读取，movsx扩为运行时32位（KING92F42→92F53）；提取器已支持有符号扩展并区分磁盘/运行时宽度，修改器2字节控件不是运行时结构宽度。

2026-10-14继续分析纠正静态地址：KING统治标记基址为0xC990E（0x9291B写入），EMPEROR为0xC99AE（0x92A00写入）；此前0xC998E候选错误。完整结构指针分别从0xC990C/0xC99AC开始，统治标记相对完整结构+2。CSV的runtime_relative_offset仍以统治标记为0，相对字段、磁盘映射、337字节步长不变。game_load_pc/game_store_pc属于KING，game_variant明确标注；EMPEROR绝对地址按其加载指令核实，不能把KING指令PC用于EMPEROR。未观察执行时绝对地址，不假定DOSBox宿主虚拟地址。
