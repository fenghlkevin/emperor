# 255/256 正常累计可达条件：菜单门槛、重复开战和行动消耗

本项为原 EMPEROR.EXE 指令及原始表的静态复核；未操作 DOS 桥，未将 257 场自然游玩称为实测。运行 `python3 extract.py` 可重生成本目录九段原汇编与 `evidence.json`。三版本的计数布局与直接引用复核沿用第五轮 association-reach 报告。

## 同一个外国可以重复出征

第五轮尚待确认的“撤退/停战后能否再次攻击同国”，已有明确原代码闭环：主动创建 `4AC7E` 写目标国关系5，完整结算 `6684D..66898` 若目标关系仍5就写0，并同步清全局国别状态。原因1/3/4不吞并这个目标。因而正常退却或金钱条件停战后，目标仍是外国且其战争状态已清，重新成为主动出征候选；无需每次外交解约。条件停战的称臣选项可能先写关系3/4，不能将其和金钱选项混为同一关系状态。

出征菜单 `4B6E8` 的 `CC645` 禁用条件是：没有状态不为4的散官（职位77）、没有非属地且关系不为5的目标国、中央兵等于皇帝预留兵E+AA、刀/枪/马三种武器全0。它没有读累计关联计数、皇帝年龄、剩余寿命或威望下限。此处仅设禁用值1，并不在函数首清CC645；调用者初始化/重建的默认清零仍需完整菜单动态核实，不能将以上称为所有前置条件。

`4AC28..4AC68` 扣威望10；目标原关系非0再扣20。真实辅助 `39979` 将威望不足钳到0，不扣寿命。即使威望降至0，该菜单启用路径也未见威望门槛。低威望会影响其他概率/自动联合事件，不能说毫无游戏影响。

原结算 `667AF..6680A` 恢复将领状态，但保留其旧关联byte；计数不减少。原链清理释放已结束战斗，因此累计256次不需要同时保留256战斗或256官员。将领byte历史重复、默认FF与255的问题仍按第五轮实际失配结果处理。

## 消耗与生命周期约束

创建末尾 `4ADBE` 调 `38C10(E,7,0,FF,0)`。重定位对象2基址是 **B0000**，从原表 `C8A64[7*7+0]` 得体力30，从 `C86B0[49]` 得计时2；这些不是字符串误读。正常完整退出 `658AD..658BE` 再扣体力50，故无其他动作的创建+退出成本为80。不能仅看到战后50就说每场只耗50。

计时槽 `CC614[49]` 的2由阶段更新 `13648` 调 `14F0A(A,7,0)` 后清0；`14F0A` 的row7没有专门业务效果，走默认返回。这是可释放的阶段计时，不是永久出征总次数上限。官员出征已调用 `2DEC8` 标其状态2；之后主将状态4和恢复流程需全菜单观察，不可忽略兵部官员的当前行动状态。

休息正常状态0有原函数增加体力150、健康5，并按最大体力封顶；只有阶段行动进度等2的该分支另外扣寿命2。过劳状态1/疾病状态2的休息扣寿命30，后者又加健康80。故达到边界的正常试验应主动休息，避免每次耗空触发成本更高的过劳恢复。

寿命减函数 EMPEROR `3984F` 的直接调用列表没有主动出征创建或战后退出函数。它不证明事件扫描没有寿命副作用，但足以排除“每分配一个序号固定消耗一年/固定寿命”这一说法。年龄按年度更新、剩余寿命按行动/事件单独变化；菜单不存在年龄255等限制。现有随包存档含9999寿命修改值，不能作为原始寿命可达性的自然样本。

场景11/7基础耗时都是1，战场23基础耗时0；回合须经过主调度 `11F7D` 的3行动推进一阶段，而不是每单位战斗动作一年。具体一个完整出征循环主调度被消费几次仍要端到端记录，不能用这张表直接宣称257场耗时几年或已给出全局最短回合数。

## 可复测路径与边界

初始计数c0，确认主动出征A次、生成属地受袭D次：`counter=(c0+A+2D) mod65536`。从0开始，255次创建后counter255；第256场关联255，下一场关联256。从原SAV3计数2开始，分别第254/255次额外主动创建达到这两关联。SAV3随包值不等于自然开局值。

用于验证累计性质的最短**主动分配次数**路径是重复同国：从正常官员/军事菜单选出征→合法一队兵/装→散官主将确认→进入战场→在交战前选金钱条件停战→关闭结局提示并完整退出→需要时休息并推进计时→再次同国出征。金钱分支无战斗损耗时正常Q100归还生还兵装，不吞并国家；这比每次主动退却Q80更适合长循环。实际交涉金额、事件、工资与库状态必须记录，不应强行令其0或替换成功概率。

退却同样允许重复，但玩家退却时兵装仅归80%，小兵数经整除可能归0，反复原样编队会耗尽库存，不能把“可以重复退却”直接等价于“固定原库存无限出征”。金钱停战不直接减少普通生还兵装，但财力/人口事件仍是实际限制。

最快消耗累计序号的分配次数模型为：每次受袭耗两个，128次受袭的第二位为255，第129次第一位为256；或先主动创建255次，再一次受袭使两关联同场255/256。受袭不能由玩家菜单确定控制，需地理关系、军力候选和随机事件，不应称自然游戏可靠最短路线。

当关联255已经错配导致真将领仍state4时，下一次正常出征须选另一名可用散官；不能强行恢复前者状态后又声称全为正常游戏。至少两个备用散官即可跨过这两个边界，其他官员后续复用性取决于实际错配方向。

动态验收应至少完成两场同目标完整循环，记录c、官员链、目标统治/关系、中央库、体力、寿命、时间与计时49；然后累计到255/256，保留每一场原菜单创建与结算节点记录。现有代码证明重复路径与计数不受255上限截断，**尚未证明未改档自然开局257场端到端实玩已完成**，寿命、事件及财力是否在所选自然路线足够仍须本轮主线运行补齐。

## 正常出征后进入战场的时间与按钮链

底部控制条F=`u32(CC598)`，其vtable C318C 的+8=7E201、+2C=7DE8F。右下结束本次行动按钮是F+12指向的真实控件，构造矩形(0,456)..(16,480)。原入口 `7E201(F, u32(F+12), result)` 构造F+1E确认框，F+34写3；确认事件 `7DE8F(F, u32(F+1E), 1)` 经7E0D5写CC59C=2。原主循环随后销毁当前official screen并调用117E7(A)→11F7D时间推进→11895(A)构造宫廷。这是退出战争子菜单后结束整个官员行动，不应以写global标志替代真实事件。

宫廷P=`u32(CC588)` 的31948(P,event)在P+50=0、P+69=5走3251C→7F454(`u32(CCA78)`)→7F871。序列索引5由原跳转表32820直接核实，不是4。扫描器7EF3C初始化word+29=1；扫描7F887将C82CE[event_index*10]与行动进度C98DF比较，匹配才执行该事件。事件1的进度是0，代码为7F8DF，7F918将battle head赋current，并向CCA7E队列添加1。主循环112DB..11320消费非零队列并构造战場23。

所以创建后date进度1时，再结束当前官员行动到进度2，不保证立即出现战场；需完成下一个正常耗时1行动，使3行动边界归0，宫廷事件扫描才匹配事件1。可选正常休息以补足体力，不能直接写日期/进度0后称原菜单端到端。中间原事件消息仍须通过实际控件关闭，不能跳过宫廷扫描序列。

### 宫廷等待选择状态与输入事件

实测主线到P+50=2、P+51=101、P+69=8、无P+6/P+E/P+52子窗口时，对应正常等待玩家选择行动；P+16是鼠标悬停热点，不是已执行行动。33366读鼠标对象u32(CCD78)+4/+6坐标，在P+56、+5A、+5E、+62四张单bit平面中取位组合出热点行动ID，故不能任意写P+16=3代替正常选择休息。

31948状态2的328A6分支检查event.word+10==2，实际是左键新按下事件。输入1A5A2使用DOS鼠标INT33 AX3读取按钮，按钮bit0为左键；首次按下写原rawcode2，持续按下写8，释放写4，默认移动1。1D638将raw2映射type2，raw8映射4，raw4映射3，raw1映射1，raw16映射5；原1C2E4将第5实参复制至event.word+10。event坐标结构在+12由1C080复制，目标/转发指针+26亦由原构造传入，不能全设0而不区分事件来自哪个控件。

宫廷选择8/9仅行动进度1允许；进度2点击当前悬停8不会进入该行动。选择3（休息）走3296C跳表项3→328F2，无此进度禁用。因此可通过真实鼠标移动至遮罩组合3位置并左键新按下，再正常完成休息推进到阶段0。

正常无子窗口状态319D8..31A03重新启用37FD7(CC590)、7E613(F)，后者F.word+4设1并重绘结束按钮；宫廷构造明确用flag1创建F+12。若原控件的enabled处理接受，结束宫廷当前行动0的基础耗时也是1，可从进度2直接推进阶段0；这条空过路径仍需主线实际控件返回证实。可优先休息以同时补足出征体力，不以改global计时/状态代替输入事件。

### 排队后无需另点御案

扫描原设置current与CCA7E[0]=1之后，宫廷正常提示须继续关闭，不能因A.word0仍0就手动写场景。宫廷序列索引6的32564在进度0且head非0时，3257D设P+51=2并创建P+52消息ID2CF；32608设P+16=11、P+50=3。其正常提示回调334C0把P+51置101；31948状态3的33192见101返回11。main10970写A.word2=11，销毁宫廷并10A74调用完整11895构造官员界面，10A7C把CCA92游标置0。下一原main在行动11分支112DB读取非零队列1，11320调用3D82A(S,23)。这是原事件提示自动选择官员场景然后消费战斗队列，不需要造御案热点点击或写current/场景。关闭提示可用已经验证的完整原控件3039C路径；直接调用P回调的证据强度应另标受控回调。
