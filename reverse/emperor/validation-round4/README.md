## 本轮修正

unit+17按十进制计即+0x11，不是+0x17。精确为1时启用85系数，其它值不启用；应按用途命名，中文UI名称仍需直接证据。初始化和创建未写该字节的结论必须与完整对象的分配/复制路径分开。

谈判比例先存word，再按signed16比较；阈值也按signed16解释。概率函数严格比较roll<threshold，不钳制阈值，且即使阈值为0或>=100仍消耗随机数。外层直接成功/失败则不一定调用随机门。产出随机偏移是rand%10-5，即[-5,+4]，撤回旧“±5”的表述。

## 验证边界

完整原函数6668F的结算可无UI执行；6564E包含窗口销毁，链表删除和最终失败分流采用连续原指令片段，不能冒称完整战斗窗口退出流程验收。谈判测试停在消息UI前，验证真实军力重算、随机判断和决策结果；消息窗口、点击确认及所有成功副作用不是这些片段测试的覆盖对象。

最终结果以runtime/audit-summary.json列出的套件为准；初轮弃用夹具及错误断言记录单独保留，不以预测文件条数充当实际运行条数。
