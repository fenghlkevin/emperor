# 第三轮：特殊状态与事件调度

所有地址属于 KING 的 LE 重定位后虚拟地址；R=0xC990C+i*337 是完整地区对象，E 是全局 0xC9810 的对象指针。本目录为静态证据，DOS 运行验证由本轮主报告单独记录。附带片段文件虽名为 `health*.asm`，实际 E+2B8 不是皇帝健康；下面依据读写用途解释。

## 上轮需要纠正的命名

R+D3 **内乱状态**，R+D5 **暴动状态**，R+11B **饥荒状态**，不是特殊工程。证据链同时包含触发指令、地区状态码和真实 Big5 字符串，见 `civil_disorder.asm`、`famine.asm`、`tables.json`。状态表 C4D94 的 9=內亂、10=暴動、7=饑荒；事件消息 C7A9C / C7AA0 / C7AC0 对应“发生内乱”“发生暴动”“长期灾害引发饥荒”。状态 0=安定，1旱灾，2水灾，3蝗害，4瘟疫，5严寒，6地震，8战场，11全国抗税暴动。

R+D2 / D4 是内乱 / 暴动累计触发概率（u8）。R+DF / E3 / E7 / EB / EF 是内乱累计死亡、流民、开发损失、产出扣减和建筑损失；R+12E 是饥荒结束概率进度，R+143/147/14B 分别是饥荒死亡、流民和开发损失账。

另上轮表列 R+9E / A0 为民忠公式输入是不准确的：实际 3B9F1 读取 R+96，3BA52 读取 R+94。R+94 为地区民忠的额外修正，内乱/暴动爆发时减1、巡访完成时加2（5DEA3）；R+96 为民忠公式的另一输入（权重10/100）。不能把 94/96 平移成 9E/A0。R+9E/A0/A4 暂未取得足够业务字符串证据，继续保留未知/税收系数用途，不能凭相邻位置命名。

## 内乱 / 暴动完整状态链

81397 / 81596 对前30个地区按顺序检查，要求玩家统治，且相应状态为0。计算 s16(D(士兵*100,R+24))，要求<20；内乱要求安定 R+6E<50，暴动要求治安 R+70<50。符合条件时概率byte加10，然后调用随机百分比门 8A70E。第一次命中的地区设置状态1、触发概率归0、R+5C=9或10、R+94--；皇帝 E+25 通过3990B扣5；清该事件5个dword损失账，生成事件，立即返回，因此单次检查不会让多个地区同时新爆发。

每半月损失以13905和后续暴动分支的指令为准。注意上轮摘要把内乱损失账的偏移多写了20字节、产出扣减误写为2；实际内乱产出扣减每期1，暴动每期2。内乱解除由14D71检查：状态1且（兵占职业人口比>25 或安定>60），设2，R+5C=0。暴动同样要求兵比>25或治安>60。恰好25、60仍不解除；解除状态2随后在事件报告/消费路径清0（905C4等）。这构成带滞回阈值的状态机，不能把爆发和解除阈值写成同一个50。

## 饥荒完整状态链

81AE2 遍历30地区，**未检查玩家统治**。要求 R+11B=0、灾害类型 R+D7非0、灾害进度 R+D8>=30；以 R+D8 调8A70E，成功设饥荒1、R+5C=7、R+12E=0并清3个损失dword，记录原灾害类型到消息，首个成功后返回。进度检查使用灾害进度，不是积粮。

每半月13DB7执行：死亡=D(5*R+24,1000)，流民=D(R+24,100)，四开发各损失D(5*开发,1000)，结束概率R+12E加8并调用8A70E；成功状态=2且R+5C=0。显示解除消息后90674检查2并清0。非玩家地区在13825前部跳过玩家损失路径，因此“可触发饥荒”不意味着外邦经历同样的每旬人口损失。

## E+2B8 与 E+2CC

E+2B8 是外交/军事实力效果的0..100修正因子（概念可称国威，**精确UI标签未证实**）。39743增长并上限100，超过40清 E+2D0=1的低值事件闩锁；39961减少并下限0。军事外交成功分支4645C加5，失败分支4675E扣减；低于20且闩锁0，8017A设置闩锁1，挑外邦建立联合防御关系，消息为“国际签定联合防御合约”。因此绝不可写为皇帝健康。

E+2CC 国家军事力量聚合值，由39BC6重算，遍历 **0..30共31槽** 仅纳入玩家统治槽：

```
a = D(2 * Σ(R+82 + R+84 + R+86),3)
b = Σ D((R+88)*(R+22),50)
E+2CC = D(a + b + E+9E,50)
```

R+82/84/86 是前三装备word，不是四行业人口。E+9E 的精确用途应和中央军聚合代码联查。46AAE 将此值拷贝入军事外交对象+54；外邦军事负担R+12F入+58。47345将外邦友好度平方乘 D(E+2B8*己方力量,外邦力量)，再除10000，用作外交军事成功概率。80923也使用E+2CC作外部侵略评估分母，因此零值可能造成除零，修改测试务必保留非零国家力量。

## 事件检查调度

7F649使用对象+29作为1..60事件扫描游标，表 C8230 为61条×10字节的5word记录（第0条重复默认项）。记录+2与全局行动进度 C9843 相等才检查该事件；不匹配则游标递增直到60。0通常代表旬边界，2代表旬内行动阶段。

命中事件经805F2设对象+1A为事件号、+26为1，并将表的+0/+4/+6/+8四个word传7ED9C构建显示。805C8递增扫描游标；+26非0即返回，尚未命中则继续扫描。故这是**分批事件扫描 / 展示状态机**，不是每次行动一次性执行60种事件。`tables.json`逐条保留原始5word，未猜测未追踪的资源ID含义。3内乱、4暴动、5全国抗税、6饥荒、7..11旱灾/水灾/蝗害/瘟疫/严寒在行动进度0；12地震要求进度2，后续部分外交/个人事件也要求进度2。

## DOS差分的小场景与预测

1. 内乱解除阈值：保留状态1，R+24=10000，安定=60。兵2500保持1；兵2600改2且R+5C=0。另兵1000安定61改2。须在14D71执行后、消息消费前取内存；最终存档可已清0。
2. 暴动同样测试治安60/61。比较的是R+70，不能误改R+6E。
3. 饥荒触发：R+11B=0、D7=1、D8=29不会调用概率门；D8=100触发时状态1、R+5C=7、12E=0，并清143/147/14B。读档路径或灾害自身更新可能先改变进度，应以断点前内存为基准。
4. 内乱单旬损失：R+24=10000、四职业均2500，D3=1；死亡平摊总10，转民夫20，四行业总减30（平均职业损失按3B3DD舍入规则），民夫+20，四开发10000各减10，E7+40，128+1，EB+1；建筑为0排除随机建筑损毁。各职业剩余应在真实扣人口程序执行后核对，不能从总量直接假定均匀。
5. 饥荒单旬：R+24=10000、四职业均2500、四开发10000，11B=1、12E=0；死亡50、转流民100、四开发各-50、143+50、147+100、14B+200、12E+8。固定PRNG使8%结束门失败，再逐写对比。
6. 国家力量重算：只一玩家槽，装备[300,600,900]，兵1000、训练50、E+9E=3000；E+2CC=D(1200+1000+3000,50)=104。纳入中央第31槽与否做成对实验，可检验循环边界。

以上是机器码预测而非已运行的DOS结论；不将合成输入/指令解释器冒称实机验证。
