# 第三轮恢复与 DOS 原程序差分

本轮恢复特殊事件状态、战后结算、招降和七种停战分支，并在 DOSBox-X 中运行原始 EMPEROR.EXE、DOS4GW 与原函数进行内存/存档差分。原始安装包和存档未修改；测试仅操作 runtime/game 副本。

## 阅读入口

- [特殊字段、事件阈值和调度](special-fields/README.md)：内乱、暴动、饥荒、外交军事修正因子、军事聚合值及61条事件表。
- [战后结算](postwar/README.md)：胜负/原因矩阵、兵装回库、人口、领土、关系、官职与战斗链表清理。
- [招降、七种停战和主将](tactics/README.md)：真实消息表、军力权重、门槛概率、金钱与称臣副作用。
- [DOS 验证](runtime/README.md)：环境、原函数地址、受控输入和逐项实测边界。

上面三个专题以静态指令证据为基础；哪些条目已动态通过，应以 runtime 下的结果文件为准。

## 重要订正

完整地区运行对象 R 与磁盘加载字段基址相差2字节，所有偏移必须先核对基准。R+D3=内乱、D5=暴动、11B=饥荒；此前“特殊工程”命名撤回。民忠公式读 R+94、96，不是9E/A0；内乱五项账为 DF/E3/E7/EB/EF。内乱每半月产出扣减1，暴动2。E+2B8不是健康，其外交军事用途明确，中文UI名称尚未证实。

地区语义导出器已修正并重生成77字段描述，其中74字段可映射磁盘，三份存档共6882个语义值；原始字节保留。9E/A0不再以错误公式地址命名。

## 尚不能声称完整恢复

unit+17特殊标记、外国主将三属性的中文名、部分税收/全局字段仍未定名。未找到足够证据确认独立“计谋/远程攻击”动作，不能用招降停战分支替代所有计谋。最后属地失败的完整UI与战斗链表残留、全部外交概率边界、内乱饥荒每项损失，仍需进一步动态覆盖。此次验证不是物理DOS机器，也不是从菜单逐步玩到每个分支；是实际DOS环境下原始机器码函数的受控执行，无游戏逻辑替身。

存档末尾33字节的既有结论未改变：肖像已用标志前13字节与完整20字节的冗余副本，三个版本写出，加载路径不消费；详见原 tail33 报告。本轮未把无新增证据的尾部解释改为校验和或随机种子。
