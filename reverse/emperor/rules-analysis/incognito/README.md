# EMPEROR 微服出巡规则证据

2026-10-16；基准为 EMPEROR.EXE，哈希见既有 layout.json。静态证据使用项目已恢复的 LE 重定位指令；没有可用 REA 深度 provider。hotspots.json 导出 14 个热点及完整原始台词；乱码沿用原始 Big5 解码产物，不能当成现代改写。

## 主流程与数值

- 安排确认：0x69743..0x6976f 写 E+0x43=2，调用公共安排回调。无地区选择；次晨消息 0x115 提示换民服出京。
- 构造：0x8665c..0x869b4，入场即调用快乐辅助函数 0x39703 参数20，封顶100；寿元辅助函数0x3984f参数8。寿元字段 E+0x15 限低0，特殊模式全局0xccd69=1且参数<10时乘12（故8变96）。这不是日历耗时。
- 退出：scene14 完成标记→0x11156..0x11179→0x117e7→0x1181c→普通日历0x11f7d。没有巡游/狩猎使用的0x1349d强制下月，因此不能套用“所有出巡耗一个月”。
- 普通微服场景及各民情对话未见金钱、粮食、民忠、皇威、智慧等写入。基本收益是快乐及真实民情信息。公共安排消耗行16的第1子项为20，另见travel调查。

## 热点与条件

0返京确认；1赋税；2经济；3建设；4民伕；5军队；6生活；7预测寿命；8灾难；9疆域；10外交；11青楼；12孩童；13闲人。前10类按状态确定，不随机抽取。没有赌场热点。

条件与消息顺序见 hotspots.json。公式原字段精确定义：

- 税率为全局 byte[0xc8b9b]，档位<=8、9..16、17..25、26..31、>=32。
- 国内地区 R[i]=0xc99ae+i*0x151，R+0非零；地区总数E+0x2e；人口E+0x2f。经济均值为国内地区0xc9a48的word之和/地区数。landShare为累计人口*100/E+0x2f。**原经济分支0x86c21错误使用热点索引ec（2），不是地区循环索引f0，重复累加R[2]人口**；复刻修正必须标注项目修正。
- 建设均值为国内地区0xc9a1a/1c/1e/20/22/24六word总和/(地区数*6)，landShare在此正确循环累加地区人口。
- 民伕率为E+0x96*100/人口；军队率为国内地区0xc99ce加中央0xcc14c的word之和*100/人口。
- 生活均值是国内地区0xc9a0a之和/地区数。浮点常量3.5、3、2、1；原始条件保留在JSON。
- 寿命预测值=年龄E+0x0e+floor(剩余寿元E+0x15/48)。原条件存在35、45、55空档，会落到最终0x177台词；不要误写成连续区间。
- 灾难以国内地区0xc9a08==0的比例分>=90、>=50、其余。
- 疆域分数每国内地区+4；非国内但对应0xc9a64指针对象+0x1e==3则+2；阈值41/60/85/110。
- 外交为非国内地区0xc9a58友好度平均；全国30地区全占时强制90；阈值80/60。

## 特殊事件

青楼点击之前计数>=5才会检查随机（第6次及之后）。0x87332..0x87349调用0x8a7fe阈值50，即rand()%100<50；构造对话后0x8740e递增点击数。成功台词0x2d7，失败0x2d6。成功关闭对话后切换画面，并即时寿元−10、快乐+500（封顶100）、健康−20（最低0）；关闭0x2d8后结束本次出行。未发现收钱、选妃或新建后宫记录。闲人热点也以同一50阈值选择0x2da/0x2db；无属性变化。随机取模有轻微偏差，50%为名义比例。

## 现代项目适配
