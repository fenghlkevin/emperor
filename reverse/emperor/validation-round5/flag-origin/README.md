# unit+17 的来源：第五轮静态追踪

对象为 EMPEROR 的原始机器码；地址为重定位静态 VA。这里没有操作 DOS 桥，动态结果另由本轮运行目录记录。

## 完整创建路径的补齐

主动出征并非只执行 `84210`：菜单回调 `4967E` 在 `49DA4` 分配 0x704 字节、`49DD2` 调初始器，`49E66..49F52` 设置手工中央队伍；确认将军后 `4ABD7..4AC1F` 绑定官员关联序号、B 国别 30、另一将军序号 FFFF。`4AD2A` 最终调用 **84457(B)**，随后 `4AD32..4AD8A` 把战斗节点加入链表。因此过去只验证两个初始函数不足以覆盖全部创建。

自动入侵 `80BF6..80E5A` 分配节点及战斗，`80C22` 调 `84210`，设本地战标记、双方国别、外交战争状态、两位地方官关联序号，然后 **80DB3 调 8437E(B)**，最后加入链表。

最终建队调用树如下：

|入口|原函数调用|对特殊字节的静态检查|
|---|---|---|
|84457 主动出征收尾|84E0E 中国主帅；84CB4 敌主帅；85273 敌正规军；85BAC 装备防御；85942 攻击重算|所有显式单位写均未覆盖 +17|
|8437E 自动入侵收尾|84E0E、85484 本地军、84CB4、85273|所有显式单位写均未覆盖 +17|
|85484 本地军|84F54 分兵；849FF 建队；85BAC、85942|所有显式单位写均未覆盖 +17|
|85273 敌正规军|849FF|所有显式单位写均未覆盖 +17|
|8454C 援军补充|8462D 扫31国；849FF|所有显式单位写均未覆盖 +17|

主帅也不例外：84CB4 写 A 的国别、type3、兵员100、训练、word 防御(+15)，84E0E 写 B 对应字段；两者没有写尾字节。85BAC 的最终 word 写是单位 **+15..+16**（`85C2F: mov word ptr [edx+3DD],bx`），并没有跨越到 +17。手工编队防御写 49F33 也只有 +15..+16。

`9AC78` 是 new 包装：`9AC87` 转调 `9B4F5`，失败时调处理器重试。它不对返回的 0x704 用户块清零；对应 malloc 路径也没有用户块整块清零步骤。这支持堆遗留解释，但本报告不把静态的“未见清零”当成实际分配内容观测。

## 排除同偏移误命中与块复制误判

全 `56000..85C3B` 中 +76/+3DF 字面引用除4处战斗读取外，还出现 `81EE8`、`81EF1`、`81F91`：这些先取 `[C98AC]`，实际是皇帝对象的事件概率，并非战斗单位。`7EA3A` 的 +11 写属于另一类对象构造（字段包含复制字符串），也不能当成 unit 尾字节来源。

该范围看似唯一的 `60AF4 movsd` 位于 `60AF4..60B0F` 回调 switch 地址表，前有无条件跳转越过，按指令解析它是线性反汇编把数据错当指令；不能据此宣称存在部队整块复制。建队实际函数体没有 REP MOVS/STOS 或单位整块复制。限定负搜索不排除任意未追踪的间接别名写、异常越界写；完整路径 DOS 地址监视能进一步收紧结论。

确定存在的外部赋值渠道是存档加载：935B6 在937A6/93889分别读入两组810字节，每组45个18字节单位，+17原样恢复。第四轮90槽保存/加载实验已验证此渠道。普通创建链尚无可命名的主动赋1来源，暂保留“未初始化且值1启用85%损失系数的字节”。不得将之命名为伏兵、守备或计谋。

## DOS 精确监视建议

- 主动入口停在49DB1（malloc已返回），新 B 为 EAX；自动入口停80C10，亦为 EAX。
- 读90个地址：`B+76+i*12`、`B+3DF+i*12`，这里十六进制12=十进制18，i=0..44。
- 原分配结果采样后才可做毒值试验；毒值试验需明确属于人为夹具，不能冒称原游戏默认值。
- 用地址写监视捕获覆盖这些字节的宽写和间接写；代码断点/快照检查点是主动4AD2A、4AD2F、4ADC6，自动80DB3、80DB8、80E5A。仅快照相等不能排除中途写后恢复原值。
- 战斗开始后的援軍8454C/8462D须独立覆盖；完整自动入侵初始化可通过8437E原函数验证，主动中央编隊还需菜单路径。

`extract.py` 重建8份完整汇编证据与检查点 JSON；函数区间来自具体返回边界/实际调用核对，不把自动识别器的跨函数大区间直接当函数体。
