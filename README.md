# 皇帝

Electron 单机桌面游戏，共用 macOS / Windows 代码。当前完成本地创建角色、继续游戏、皇宫与朝堂场景、建筑及人物热点、功能弹窗、旬回合、状态栏、自动存档、JSON 存档导入与导出。

## 运行

需要 Node.js 22 或更新版本。

```sh
npm install
npm start
```

浏览器预览：`npm run dev`，访问 http://localhost:5173 。浏览器和桌面应用的存档分别保存。

## 打包

```sh
npm run build:mac
npm run build:win
```

建议在相应系统上打包。输出在 `dist/`。macOS 包未配置签名、公证；Windows 包未配置代码签名。Windows 应在 Windows 机器验收。

## 代码与数据约定

`src/game.mjs` 定义场景入口与游戏状态，`src/app.mjs` 处理导航、弹窗与存档，`desktop.cjs` 仅管理桌面窗口。目前已接入内政生产、财政流水、地方治理、官员、外交、九兵种套装军务、后宫、出行、炼丹与继位。跨旬执行各模块结算，不自动恢复健康与体力。本地角色入口不提供网络身份认证。

界面改为黑白素描风格，使用 ImageGen 生成的宫城与写实群臣素材 `assets/sketch-palace-focus.png`、`assets/sketch-court.png`。点击区域按画面位置校准，随窗口同比例缩放。旧版矢量绘制模块已不参与运行。`assets/` 中历史参考截图不参与运行和打包。当前存档为 `version: 2`、内政 `schemaVersion: 8`、九兵种军备 `troopKits.version: 1`；保留的存储键名 `emperor.save.v1` 不等于内容版本。只接受当前外层/内政版本及有效套装军备，同版本缺失字段按模块规则补全。本地自动存档使用 localStorage；重要进度可导出备份。创建角色、导入存档覆盖前会确认。

统一数据文档：[数据字典](docs/data-dictionary.md)、[类型声明](src/game-types.d.ts)、[存档版本兼容](docs/save-compatibility.md)、[旬结算顺序](docs/turn-settlement.md)。

验证：`npm test`（先运行真实状态类型契约检查，再运行业务单元测试）；单独检查声明：`npm run test:types`。

长线可玩性与平衡抽样：`npm run test:playability`，结果保存于 `outputs/balance-v1-2026-10-17/`；可用 `-- --mode=academy-capital-active --seed=1` 单独检查首都工程路线。平衡实际界面回归：`npm run test:balance-ui`。自然来敌与低属性恢复界面回归：`npm run test:crisis-recovery`。本轮调整与复验见[平衡规则1](docs/balance-v1-2026-10-17.md)，前次结果保留为历史对照。

桌面交互验收：`npm run test:desktop`，使用独立临时存档并生成 `/private/tmp/emperor-preview.png`。

朝堂共用 `CENTRAL_OFFICES` 的13个中央官职入口：宰相，户部/兵部/工部/吏部/礼部尚书与侍郎，刑部尚书及中央将军。各州刺史、将军按当前本国领土动态生成，不列入中央朝班；任职人员来自实际官员名册。

## 内政模块

从朝堂点击“户部侍郎”，或侧栏“内政”进入。先显示欧亚水墨舆图，点击本国查看全国汇总，放大后选择十州查看详情。包括全国总表、收支表、经济总表、民生总表、状况总表及经济细查。存档兼容范围见下列统一说明；结束本旬结算收支与粮食。地图疆域和数值为初始剧本，可继续调整。

详见 [内政数据模型](docs/domestic-model.md) 与 `src/game-types.d.ts`。桌面验收：`npm run test:domestic`。

地图剧本现为参考图范围：本国初始十州，其他 33 个具名地区各为独立小国。内政采用水墨地图与纸卷文字详情。起居注已移除，仅兼容保留旧存档字段。

礼部尚书现可办理外交：缔结或解除互不侵犯、防御同盟与保护条约；分别约定每旬出口收银和进口付银；送本国公主和亲或迎外国公主入宫；约定年度纳贡或索贿（每年正月上旬、36 旬一次）。状况表列出国情与协议，皇子公主表登记婚姻。谈判按官员能力、友善、威望与真实兵力等评议，可能被拒绝；贸易以银两额度结算，并记录应付与实付。礼部侍郎保留地图外交总表。

礼部祭祀：朝堂 → 礼部尚书 → 祭祀。花费 1,200 两，未来 12 旬本国各城天灾与人祸风险乘以 0.6，效果不叠加。全图 43 城每旬最多发生一种灾害，风险随地形、季节、人口密度、生活水平、体质、治安、安定与民忠变化。天灾包括洪涝、旱灾、山崩、疫病；人祸包括失火、盗匪、民乱。灾害扣除存粮与地方现金、降低安定，盗匪和民乱另降治安；灾害按类型持续 2–9 旬，期间暂停地方建设，结束当旬自动复工。祭祀页展示下一旬概率与最近 200 条灾情；本国受灾时顶部提示。判定由存档种子、城市和旬序决定，读档不会重掷；旧存档自动补充默认记录。验证：`npm test`、`npm run test:ritual`。

灾害周期与营建：失火 2 旬，山崩/盗匪 4 旬，民乱 5 旬，洪涝/疫病 6 旬，旱灾 9 旬；发生旬计入周期，结束旬可复工。受灾期间不叠加新灾。工部尚书可开设地方工程，每城同时一项，开工一次拨款，正常旬推进，灾害期间进度冻结且暂停地方建设预算，不重复拨款。灾情簿显示周期、剩余时间和结束状态，工部显示停工与复工。旧存档自动补充周期。

外交接见流程：朝堂召见礼部尚书，选择国家并颁发国书 → 下一旬开始弹出外臣抵京通知 → 退朝返回皇城 → 点击礼明殿进行面对面会谈。会谈锁定受邀国家，暂时离殿保留来访；点击“礼毕 · 送使出宫”结束后可重新邀请。邀请和候见状态随存档保存，祭祀仍由朝堂礼部尚书办理。验证：`npm run test:envoy-visits`。

皇帝属性与后宫：右下角面板、体力限制、独寝与相伴休息、宫廷修习、千人美人录、100种名分与留用已接入；覆盖地图34地区，服饰按地域设计，使用独立脸型、发式、衣装、饰品、物品和鞋履部件组合，并在首次相见时固定形象。智慧/武术影响制举选才。规则与素材范围详见 [皇帝与后宫](docs/emperor-harem.md)。桌面验收：`electron tests/emperor-desktop.cjs`。

### 回合与体力

每旬回合包含早上（早朝）、上午、中午、下午、傍晚、夜晚六阶段。离开一间宫殿推进一个阶段；朝堂内召见多位官员仍算同一阶段，退朝才推进。夜晚只能独寝或回后宫，离屋后结算下一旬。

办事消耗体力，除体力耗尽时仍可进入金龙殿外，进屋要求体力大于0。白天尚有体力时可以独寝或到后宫恢复，离屋后继续进入其他宫殿。体力降至0立即晕倒，强制进入下一回合、恢复体力，并在正常回合寿元消耗外额外损失30点寿元（寿元以旬计）。顶部显示当前阶段；兼容范围内缺少阶段字段的存档从早上阶段开始。

### 皇城四时

皇城按游戏月份展示春（1—3月）、夏（4—6月）、秋（7—9月）、冬（10—12月）四幅季节原画：春季新绿与花树、夏季浓荫、秋季金黄落叶、冬季屋顶和庭院积雪。每幅原画按当前六阶段切换晨曦、上午、正午、午后、晚霞和月夜光照，合计24种组合；傍晚与夜晚亮宫灯。天气与光照强弱按存档、回合和阶段随机组合，春夏可见晴、云、雾或雨，秋季可见风吹落叶，冬季可见飘雪、阴云或雪后晴；重绘与读档不重新随机。点击位置和界面清晰度保持一致，减少动态效果的系统设置会停用飘雪动画。

界面验证：`npm run test:palace-atmosphere`。

外国使臣美术使用完整固定立绘：33 个外国各 3 位，共 99 张。人物与服饰一体绘制，不再按部件拼装。每次来访选定一位后存档，切换议题、暂离和读档保持一致。旧分层配方自动迁移为本国固定立绘；旧美术素材保留但不打入正式包。素材与生成说明见 `docs/envoy-art/README.md`。

外交会面显示：33 国各三张完整横版场景，左侧完整显示使臣、桌案与屏风，右侧独立放置功能与对话。图片按原比例包含显示，不裁切、不渐隐，关系信息位于图片下方。当前正式素材目录为 `assets/envoys/wide/`。
